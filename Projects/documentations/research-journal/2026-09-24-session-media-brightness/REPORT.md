# CFW / Companion 6.9.8 검증 보고

## 변경과 원인

GPS 페이지 전환에는 나가는 페이지와 들어오는 페이지, 링·시계·거리·아이콘·사진 전환이 함께 그려진다. GPS 격자만 검사하면 통과해도 전체 EVE display list가 8KiB를 초과할 수 있었다. 수정 전 격자를 같은 전체 화면 시험에 넣었을 때 8,244B에서 초과를 재현했다.

GPS 격자를 실제 거리 기준 100px 간격으로 배치하고 가장자리 페이드를 세 단계로 정리했다. 경로의 48개 점, 이동·회전·줌·보간은 유지한다. 선분 좌표를 투영 영역 안에 잘라 EVE 정점 범위 초과를 막는 기존 수정도 유지한다. 드라이버의 한도를 늘리거나 일부 프레임을 성공으로 처리하지 않았다. GPS 영역은 336×236px, 화면 Y=149…384로 아래까지 넓혔다. 최신 위치가 끊기면 기존 궤적과 `Waiting for phone GPS`를 표시한다. 폰의 강제 종료 상태에서 새 위치를 얻는 기능을 주장하지 않는다.

이번 IGN 세션의 유효 UART 속도로 최고속도와 시간 가중 평균을 계산한다. 최고속도는 링의 두꺼운 막대, 평균은 링 폭과 같은 22px 점이다. 정차 시간도 유효 표본이면 평균에 포함하며 1초를 넘는 표본 공백은 적분하지 않는다. 확정된 종료 이벤트에서 초기화하고 기존 1초 OFF 유예를 유지한다. ODO·TRIP A/B와 정비 누계는 이 초기화의 대상이 아니다.

PH9는 HIGH/LOW 모두 100ms 연속 안정화를 거친다. 입력 허용과 좌측 상태 표시는 같은 안정화 결과를 사용한다. 차단 중 누르고 있던 버튼은 다시 놓았다 눌러야 한다. 복구 제스처는 일반 입력 차단과 분리된 기존 경로를 유지한다.

음악 아티스트는 20→24px로 키우고 재생 바와의 간격을 조정했다. 제목 28px와 스크롤 정책은 유지한다. Quick Settings에서 수동 밝기의 Brightness 제목을 삭제했고, 설정 이동 경고의 30초 링은 22px로 맞췄다.

음악 메타데이터 확인 주기는 200ms다. 480px 앨범아트의 JPEG 압축은 별도 단일 작업자로 옮겼으며 최신 요청과 결과만 보존한다. 곡 변경 후 늦게 완료된 결과는 폐기한다. 상태 조회는 5Hz로 제한하고 제어·메타데이터를 이미지보다 우선한다. 새 CJK 음악 타일은 capability 0x4000을 협상한 경우 kind 9 무손실 RLE로 보낸다. 기존 16바이트 헤더·CRC·세대 검증을 유지하고 기존 버퍼를 재사용한다. 구 CFW에는 kind 7 원본 형식을 사용한다. SPP를 유지하며 AVRCP를 추가하지 않았다.

밝기 설정은 Graphics의 저장값과 BSP PWM이 동일한 경로로 갱신되도록 연결했다. 수동 모드에서 현재 PWM을 그대로 반환하던 동작을 저장된 수동 설정의 재적용으로 고쳤다. 자동 모드의 순정 단계→전기적 PWM 매핑, 안정화·변화 제한, 센서 오류 시 수동 복귀는 유지한다. 공장 조도 임계값을 PWM 퍼센트로 해석하지 않는다. 실제 광학 밝기와 센서 정상 동작은 이번 시험에서 측정하지 않았다.

## 검증

- Android 단위 시험 273개 통과. APK 빌드·lint 실행, Error/Fatal 없음. 기존 서명키와 동일한 서명, versionCode 21 / versionName 6.9.8 확인.
- 실제 Cortex-M4 C 코드로 PH9 채터·타이머 wrap·해제 후 재입력, 세션 평균·최고값·공백·종료, 밝기·OFF 사진·GPS 모델을 O0/Os/Oz에서 각각 1,205개 assertion으로 검사했다.
- 실제 LVGL/EVE 화면 코드·폰트·자산을 사용한 전체 프레임 시험 2,016회 통과. 두 480px 사진의 혼합 프레임 1,728회, 라이트/다크, 최대 길이 경로, 페이지 전환, 링 표시, 움직이는 아이콘 바, 상태 아이콘, PH9 배지와 토스트를 포함했다. 최대 display list는 **7,804 / 8,192B**였다. 이는 시험한 조합의 상한이며 임의의 미래 UI에 대한 보장이 아니다.
- 별도 GPS 좌표 시험은 최적화 수준별 648개 회전·줌·위치 조합을 통과했다. 범위 밖 정점 0개. EVE 상태 복원, Dashboard 모델, Companion 명령, PhoneVisual 회귀 시험도 통과했다.
- Android가 생성한 실제 대만 한자 타일을 MCU 디코더에 주입하고 원본 픽셀과 비교했다. CRC 오류·잘린 데이터·오래된 세대·페이지 만료 처리도 검사했다. 예제 원본 11,184B가 언어별 2,422…3,994B로 줄었다. 내용에 따라 압축률은 달라진다.
- 현재 APK의 실제 패키지 읽기 코드로 6.9.8 / 6.9.7 / 6.8.1 / 6.4 ZIP 수용 검사를 통과했다. 새 패키지의 Gate·Bootstrap·순정 복구본·외장 자산·삭제용·진단용 이미지는 직전 배포본과 바이트가 같다.

최종 플래시 여유는 Release 66,868B, Debug 35,100B다. 일반 SRAM 여유는 각각 53,216B / 54,136B이며 CCM 여유는 16,320B다. 상세 수치는 함께 배포하는 `verification-summary.json`에 기록했다. Release 64KiB, Debug 32KiB, 일반 SRAM 32KiB 여유 기준을 유지한다. LVGL CCM 48KiB·FreeRTOS 힙·스택·통신 큐를 줄이지 않았다. 플래시에서는 진단 로그의 전체 소스 경로를 컴파일 시 파일명으로 바꿔 중복 문자열만 줄였다. 로그의 파일명·행·함수·수준·본문은 유지한다.

이번 시험은 물리 I/O를 모의한 소프트웨어 시험이다. 연결된 벤치에는 접근하지 않았고 실차 RF 지연, 실제 LCD 프레임, FPS, 광학 밝기, Android 제조사별 잠금/절전 동작을 측정하지 않았다. 새 기능의 실차 검증 완료로 해석하면 안 된다.

## 적용

APK와 대응 ZIP을 함께 사용한다. 이미 CFW가 설치된 기기는 주행 연동을 수동 종료하고 일반 CFW 업데이트를 사용한다. Gate 변경이 없어 순정 복귀와 Bootstrap 재설치는 필요하지 않다. 정상 확정 이후의 기존 설정·CFW 사진 초기화 정책은 그대로다. 배포 파일의 SHA256은 SHA256SUMS.txt로 확인한다.
