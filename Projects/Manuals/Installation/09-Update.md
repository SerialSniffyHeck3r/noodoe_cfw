# 이미 설치된 CFW 업데이트

**0.11.1 베타:** [현재 설치 순서·언어팩 안내](../User/35-Languages.md). 펌웨어 정상 실행 확인을 먼저 끝낸 뒤 언어 자원을 설치하세요.

**전원 유지가 필요한 구간:** 구형 CFW에서 데이터 유지 순정 복귀를 요청하는 도중 상시 전원이 끊기면, 새 복구 코드가 실행되기 전에 부팅이 멈출 수 있습니다. 이 구간은 자동 복구를 보장하지 않습니다. 순정 복귀·재설치가 끝날 때까지 상시 전원을 유지하고 시동 모터를 돌리지 마세요. IGN OFF는 상시 전원 분리가 아닙니다. 이미 멈춘 경우 재부팅만으로 반드시 복구된다고 가정하지 말고 진단 정보와 함께 문의하세요.

## 일반 업데이트

1. **0.11.1 APK를 기존 앱 위에 설치**하고 앱 데이터·로그·백업을 유지합니다.
2. 올바른 누도를 선택하고 **주행 연동을 중지**합니다.
3. 같은 릴리스의 **0.11.1 ZIP**을 선택해 일반 CFW/Product 업데이트를 시작합니다. 실행 중인 구 CFW에 순정 5.14·5.16 조건을 적용하지 않습니다.
4. 전송·검증·본체 승인·재시작 안내를 따릅니다. Gate와 자원이 이미 맞으면 기본 전송 대상은 384KiB Product APP입니다.
5. 실제 새 `CFW UPDATE` 화면을 앱에서 확인합니다. 같은 기기·후보로 재연결하고 최소 5초의 정상 실행 확인을 거쳐 영구 확정될 때까지 기다립니다. 현재 후보의 최대 기한은 5분이며, 구버전은 기기가 보고하는 기한을 따릅니다.

## 중단 후 이어가기

같은 기기와 같은 ZIP으로 **현재 기기 확인 → 마지막 작업 확인 → 이어가기**를 실행합니다. 완전히 받은 이미지는 무결성 확인 뒤 재사용할 수 있습니다. COMMIT/RESET 응답을 잃었다고 변경 요청을 반복하거나 다른 ZIP·앱 데이터 삭제로 미확인 기록을 우회하지 않습니다.

0.11.1에서 수동 재시작 문구가 나오면 [복구 절차](10-Recovery.md)를 따릅니다. **업데이트 전 구버전이 첫 재시작을 수행하므로 그동안은 `Paused. See phone help.` 같은 예전 문구가 보일 수 있습니다.** 새 문구 자체가 모든 설치 실패 원인을 해결한 것은 아닙니다.

## 롤백과 데이터

일반 업데이트와 실패 롤백은 설정·라이더 이름·사진·트립·정비 기준점을 보존합니다. 명시적 새로 시작·초기화·완전 삭제는 별도 선택입니다. 매번 전체 NOR를 백업하거나 모든 파일을 재생성하지 않습니다.

후보 실행이나 확인이 실패하면 이전 정상본으로 복귀를 시도합니다. 정상본이 없거나 복귀도 실패하면 Gate에서 복구합니다. **전송 100%와 새 버전의 영구 확정은 다릅니다.** [문제 해결](11-Troubleshooting.md).

이제 앱이 CFW 업데이트 전후 설정을 저장·복원합니다. [설정 보존 안내](../User/30-Sharing-Settings.md)를 확인하고 완료 전에 앱 데이터를 지우지 마세요.

## 0.11.1: IGN을 켜거나 꺼도 언어팩 설치 계속

APK와 펌웨어 ZIP을 모두 0.11.1으로 업데이트하세요. 이번 새 Gate를 처음 넣을 때는 위의 순정 복귀·재설치 경로를 사용해요. 언어 자원만을 위해 초기화하거나 앱 데이터를 지울 필요는 없어요. CFW UPDATE와 펌웨어 설치 확정을 먼저 확인한 뒤 언어 자원 설치를 선택하거나 **언어 자원 설치 / 이어가기**를 사용하세요.

언어 검사·선택한 FONT 복구·전송·검증·저장·자동 재시작까지 IGN ON/OFF를 설치 조건으로 사용하지 않아요. 도중에 시동을 켜거나 끄고 차량 데이터가 사라져도 작업을 대기·취소·재시작하지 않아요. IGN 전환 뒤 5초 대기도 없앴어요. 실제로 3km/h 이상의 최신 속도가 들어오는 경우에는 확정 전 작업이 대기하므로 정차해서 진행하세요. 작업 중에는 IGN을 꺼도 절전으로 들어가지 않아요. 배터리와 모듈의 상시 전원은 유지하세요.

전송 100% 뒤에도 실제 파일·인덱스 검사 → 저널을 통한 저장 → 자동 재시작 → 자원 준비 확인이 남아요. 마지막 확인까지 기다려 주세요. 블루투스 단절이나 진행 시간 초과로 중단됐다면 같은 메뉴에서 이어가세요. 이미 기록한 후보 데이터는 실제 페이지 해시가 맞는 부분만 재사용해요. 메타데이터 확정을 시작한 구간은 마무리하거나 Gate에서 복구한 뒤 일반 파일 접근을 재개해요.

새 언어 ZIP은 **NewDoe-LANGUAGE-B-0.11.1.zip**이며 문구 TEXT.PAK과 공통 폰트 FONTS.PAK을 분리했어요. 두 부분을 합친 기기 자원은 이전과 같으므로 정상 설치된 기존 팩은 재전송하지 않아요. 직접 켠 **English only**는 유지되니, 한국어로 쓰려면 이를 끄고 앱 언어 따르기 또는 한국어를 선택한 뒤 재시작을 확인하세요. 펌웨어 설치 완료와 언어 자원 준비 완료는 별개예요.


0.11.1은 저장 설정을 복원한 뒤 본체가 직접 언어를 준비합니다. 앱은 재시작 후 실제 메뉴 준비 상태를 확인합니다. 언어 자원은 문구·공통 폰트로 분리 배포하며, 기존 팩의 내용이 같으면 재전송하지 않습니다.
