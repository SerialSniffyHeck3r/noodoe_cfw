# 문제 해결과 진단 자료

**APK / Product 0.9.62 · Manual revision 2 · 2026-10-07**

[설치 목차](README.md) · [English](11-Troubleshooting.en.md)

## 설치가 멈춘 것처럼 보일 때

앱의 전체 단계·현재 작업 바이트·마지막 응답·파일/섹터/offset과 본체 화면을 함께 봅니다. 전송·해시 계산·NOR 소거·순정 설치기·후보 부팅은 별도 작업입니다. 퍼센트만으로 남은 시간이나 벽돌 여부를 판단할 수 없습니다.

| 표시 또는 증상 | 의미와 다음 행동 |
|---|---|
| 전송 전 호환성 확인에서 중단 | [지원 범위](07-Compatibility.md)의 HW 0·BL 0.10~0.19·순정 5.16 및 APK/ZIP 조합 확인. 모델명·PCBA는 제한하지 않음. 이 검사에서 멈췄다면 아직 Bootstrap을 보내지 않음 |
| `The current operation cannot continue` / `Installation success or cancellation not confirmed` | 이전 변경 작업의 결과가 미확인. 같은 기기·ZIP으로 마지막 작업을 먼저 조회 |
| Stage 6/8 · Code 6 / Phase 4 · `Paused` / `See Phone Help` | 코드만으로 성공·벽돌을 단정할 수 없음. 화면과 로그를 보관하고 [설치 정지 복구](10-Recovery.md) 확인. 0.9.62 오류 화면에는 UP+O 3초 안내가 표시됨 |
| 전송 100% 또는 `NOODOE INSTALLER` | 파일 전송/순정 기록 단계. 실제 새 CFW 화면이 나오기 전 완료 확인하지 않음 |
| `CFW UPDATE` / `Checking the new version` | 실제 화면 확인 → 같은 후보 재연결 → 최소 5초 정상 실행 → 영구 확정. 현재 최대 5분, 구버전은 기기 기한 적용 |
| `Update wasn't confirmed` | 후보 확인 실패. 이전 정상본 롤백 또는 Gate 상태 확인 |
| 순정 화면인데 앱은 CFW를 기다림 | `본체에서 순정으로 돌아왔어요 · 확인`으로 실제 순정 응답 대조 |
| Gate에서 Bluetooth가 안 보임 | 정상적인 역할 차이. Gate에는 Bluetooth가 없으므로 로컬 메뉴 사용 |
| Bootstrap에 이미 진입했는데 폰이 못 붙음 | 다시 순정 전송하지 말고 실제 역할·주소 확인 및 Android 페어링 승인. [연결 복구](12-Connection-Recovery.md) |
| `00050006` 또는 파일 검증 오류 | 파일 번호·phase·offset을 보관. file 3 / phase 9.2는 사진 컨테이너 검사 문맥. 코드만 보고 NOR 포맷하지 않음 |

0.9.59에서 사용자가 순정→CFW 설치와 연료 경고 음영 정상 동작을 확인했습니다. 이는 모든 CFW→CFW 이관이나 Code 6 / Phase 4의 원인이 같다는 증거가 아닙니다. 이전 버전에서 시작한 업데이트는 첫 재시작까지 구버전 동작을 따릅니다.

## 사용 중 증상

| 증상 | 확인할 것 |
|---|---|
| 일반 화면 버튼 무반응 | 계기판/Noodoe 선택 스위치와 파란 계기판 표시, 눌린 키 해제, 정차 제한 |
| ODO에서 값 적용 불가 | Settings → Vehicle → ODO check에서 IGN ON·유효한 정차 5초를 확인. Back/O 길게로 나가기. ODO*는 저장 기준 보정이며 차량 원본 변경이 아님 |
| LCD만 이상 | 빠른 설정에서 표시부 재초기화. [MCU 재시작과의 차이](10-Recovery.md) |
| GPS Waiting / 지도 없음 | 정밀 위치 권한·서비스·IGN·새 GPS 수신, 가져온 지역과 양쪽 지도 설정 확인 |
| 음악/앨범아트 지연 | 알림 접근·재생 앱 MediaSession·백그라운드 제한 확인. 동일 곡 캐시와 새/누락된 콘텐츠 전송을 구분 |
| 전화 Permission Denied | 연락처·통화기록·발신·동반 통화 제어 권한은 별도 승인 |
| 화면은 정상인데 Storage error | 저장 상태와 마지막 저장 성공 확인. 실패한 저장 다시 시도 후 결과 조회. 화면 동작이 영구 저장 성공을 뜻하지 않음 |

## 기록을 유지하며 복구

앱의 연결 상태 초기화는 소켓·임시 선택을 정리합니다. 본체 ABORT/RESET을 자동으로 보내거나 미확인 작업을 취소 완료로 표시하지 않습니다. 앱 데이터 삭제·NOR 포맷·다른 ZIP·다른 기기 식별로 기록을 우회하지 않습니다. [복구 경로](10-Recovery.md)를 실제 화면에 맞춰 사용합니다.

`진단 자료 공유`로 ZIP을 내보내고 다음을 함께 적으세요: **차량 모델, 모듈 HW/PCBA/부트로더/순정 버전(확인 가능할 때), 이전·새 APK/CFW 버전, 기기 문구·Stage·Code/phase, IGN 상태와 누른 버튼, 마지막 파일/섹터/offset**. 민감한 기기 식별값은 공개 글에 그대로 올리지 마세요.

일반 이벤트 로그에는 알림 본문·곡명·정밀 좌표·페어링 비밀키를 기록하지 않지만 복구 증거에는 기기 정보가 포함될 수 있습니다. 폰 내부 원본은 보존됩니다. 필수 저널을 저장할 공간도 필요합니다. 일반 APK는 앱에서 내보내기 기능을 사용하고, 개발용 APK의 `run-as` 절차와 구분하세요.
