# 6.10.0 구현 및 검증

## 구현

`odometer_guard`는 UART 원시 거리와 표시 거리를 분리한다. 세 번 이상 새 표본이
3초간 연속해서 역행·급증을 보고할 때 확인을 요청한다. 끊기거나 오래된 표본은
확인을 진행시키지 않는다. 불연속 뒤 큰 증가도 검토 대상으로 삼는다.
저장값 유지는 첫 이상 표본을 기준으로 후속 원시 증가량을 더하며 `ODO*`로 표시한다.
차량 계기판 ODO에는 쓰지 않고, 원시 거리만 트립 보정에 사용한다.
마지막 정상 표시값을 IGN OFF에도 유지한다. 기준점은 기존 CFG의 비환경설정 필드
0x0204에 명시적 48-byte 버전 형식으로 저장한다. 저장 실패를 성공으로 처리하지 않고
재시도 간격을 둔다. 손상 기록은 정상 0으로 바꾸지 않는다.

SettingsRemote는 기존 설정 카탈로그와 영구 필드 ID를 사용한다. 휴대폰은 값을
읽은 뒤 변경하고, 이전값/연결 세대가 어긋난 요청을 거절한다. 숫자·선택·날짜·시간·
라이더 이름·명시적 BT/정비 동작을 지원한다. 저장소 접근은 기존 StorageTask가 맡고,
폰은 수락·적용·영구 저장을 구분한다. 기기의 5초 정차/IGN/설치 상태 조건을 검사한다.
끊어진 세션의 설정 객체는 더 이상 명령을 접수하지 않고 열린 부모 창도 종료한다.
재접속 시 예전 설정을 자동 전송하지 않는다.

계기판 UART 조도 보정은 독립 필드 0x1008의 −5…+5 값이다. 원시 조도 단계에
더한 뒤 0..9로 제한한다. 원시값/가중치/송신값을 진단에 남기며 누도 PWM 정책은
원시 단계를 그대로 사용한다. 숫자 단계를 높이는 것과 실제 광학 밝기를 혼동하지 않는다.

앱의 현재 설치·복구·컴패니언·권한·설정 흐름은 710개 공용 리소스를 사용한다.
영어/한국어/간체/번체/일본어/스페인어를 제공하며 기존 공용 리소스의 스페인어도
보완했다. 시스템과 수동 언어 선택은 서비스 소켓을 재생성하지 않는다.
기기의 고정 UI 글꼴이나 순정 BL 문구를 번역한 것은 아니다.

설치 마지막 단계는 실제 Product 후보의 UID/버전 해시를 확인하고 사용자 화면
확인까지 기다린다. 승인은 기기·패키지·설치 시도·트랜잭션·후보 세대/해시에 묶인다.
새 0x9c 명령은 현재 연결의 화면 확인만 기록하며 기존 0x5c, 30초 정상 실행,
BT 확인, 부팅 후 180초 제한을 대체하거나 연장하지 않는다.

## 자원

| 자원 | Release | Debug |
|---|---:|---:|
| APP 사용 | 327,608 B | 359,424 B |
| APP 여유 | 65,608 B | 33,792 B |
| 일반 SRAM 여유 | 52,504 B | 53,480 B |
| CCM 여유 | 16,320 B | 16,320 B |

설정 내부 카탈로그는 ARM에서 24→16바이트 항목으로 바꾸고 안정적인 전송 형식은
유지했다. 같은 폰트 문자표를 공유하고 SDRAM 비트맵 연결은 공용 표 순회로 처리한다.
RAM 직렬화의 정해진 little-endian 정수 접근을 Cortex-M4용 memcpy로 통합했다.
폰트 11종의 모든 bitmap/metric 배열과 외장 자산 해시는 이전과 동일하다.
FreeRTOS 힙/스택/큐 및 메모리 합격 기준은 줄이지 않았다.

## 검증 범위

- Android 291개 시험 통과, lint 오류 0(경고 95), 기존 APK 서명 및
  6.10.0/6.9.9/6.8.1/6.4 ZIP importer 통과.
- 6개 언어 홈 화면 렌더링, 재생성 후 언어 유지, API23 호환성 검사.
- ARM O0/Os: ODO 33개 assertion, 설정 원격 27개, UI/동작 331개;
  UART 보정 경계/실제 프레임, 설치 30초/180초와 후보·연결 경계.
- 기존 NOR 저널·설정·누계·사진·설치 시험, 중단 주입과 별도 trial 설정 초기화 시험.
  ODO 필드가 trial view 및 preference reset 이후 보존되는지 검사했다.
- 자산 로더/설치: 699개 중단 경계, A 보존, CRC/헤더/버전/누락 검사.
- 실제 Debug LVGL 객체를 사용한 EVE 전체 화면 전환 2,016프레임:
  최대 7,808/8,192 B. 새 ODO 모달 3,332 B. 하드웨어 렌더링 속도 측정은 아니다.
- Project layers 시험: Product/Integrated/Graphics 소스 선택, include/linker 복원,
  반복 적용 동일성, Core/IOC 불변. 실제 GUI Generate Code는 수행하지 않았다.

연결된 ST-LINK/UART/ADB, 실제 RF, 실차, GUI에는 접근하지 않았다. 실제 화면·29fps·
RTOS 실행 중 최저 힙·물리 전원 차단까지 통과했다고 주장하지 않는다.
Bootstrap/Gate/순정/자산/삭제 및 진단 이미지 payload는 이전 배포와 동일하다.
APK와 Product만 갱신하며 기존 OpenNoodoe와 순정 BL/공장 데이터는 수정하지 않는다.

기계 판독 결과는 verification-summary.json, 명령 형식은 PROTOCOL.md에 남긴다.
