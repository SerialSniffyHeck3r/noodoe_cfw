# CFW + Companion 0.10.6 beta — ignition-independent language installation

Install **NoodoeCompanion-0.10.6.apk** and **NoodoeInstaller-CFW-0.10.6.zip** together. Keep app data. Language inspection, transfer, verification and saving no longer require ignition OFF or a five-second ON dwell. Actual progress and cached verification from 0.10.5 remain. Gate, Bootstrap, firmware-update admission, pairing and the language archive are unchanged.

## 0.10.6: language installation with ignition ON or OFF

Update both the APK and firmware ZIP to 0.10.6. Matching-Gate 0.10.x devices use the existing CFW-to-CFW route. This language-pack fix needs no stock return, formatting or app-data deletion. Confirm CFW UPDATE and firmware completion first, then accept the resource offer or use **Install / resume language resources**.

Ignition ON/OFF is ignored throughout language inspection, optional FONT repair, transfer, verification, saving and automatic restart. Switching ignition or losing vehicle telemetry does not pause, cancel or restart the operation. No five-second ignition admission wait remains. A fresh speed of at least 3km/h still pauses uncommitted work; keep the vehicle parked. The active installation keeps the module awake even with ignition OFF. Keep its permanent power supply connected.

Transfer 100% is followed by real file/index verification, journaled saving, automatic restart and resource-ready confirmation. Wait for that final confirmation. If Bluetooth disconnects or progress times out, use the same resource menu to resume; recorded candidate pages are reused only after physical hash comparison. Committed metadata finishes or recovers through Gate before normal filesystem access resumes.

The unchanged language archive is **NOODOE-LANGUAGE-B-0.10.1.zip**. A healthy installed pack is reused. An explicitly enabled **English only** preference is preserved; turn it off, select Follow app or the desired language and accept the restart. Firmware completion and language-resource completion remain separate.

## 0.10.6: IGN을 켜거나 꺼도 언어팩 설치 계속

APK와 펌웨어 ZIP을 모두 0.10.6으로 업데이트하세요. 같은 Gate의 0.10 계열은 기존 CFW→CFW 업데이트로 진행합니다. 이 문제 때문에 순정 복귀·초기화·앱 데이터 삭제를 할 필요는 없어요. CFW UPDATE와 펌웨어 설치 확정을 먼저 확인한 뒤 언어 자원 설치를 선택하거나 **언어 자원 설치 / 이어가기**를 사용하세요.

언어 검사·선택한 FONT 복구·전송·검증·저장·자동 재시작까지 IGN ON/OFF를 설치 조건으로 사용하지 않아요. 도중에 시동을 켜거나 끄고 차량 데이터가 사라져도 작업을 대기·취소·재시작하지 않아요. IGN 전환 뒤 5초 대기도 없앴어요. 실제로 3km/h 이상의 최신 속도가 들어오는 경우에는 확정 전 작업이 대기하므로 정차해서 진행하세요. 작업 중에는 IGN을 꺼도 절전으로 들어가지 않아요. 배터리와 모듈의 상시 전원은 유지하세요.

전송 100% 뒤에도 실제 파일·인덱스 검사 → 저널을 통한 저장 → 자동 재시작 → 자원 준비 확인이 남아요. 마지막 확인까지 기다려 주세요. 블루투스 단절이나 진행 시간 초과로 중단됐다면 같은 메뉴에서 이어가세요. 이미 기록한 후보 데이터는 실제 페이지 해시가 맞는 부분만 재사용해요. 메타데이터 확정을 시작한 구간은 마무리하거나 Gate에서 복구한 뒤 일반 파일 접근을 재개해요.

언어 ZIP은 기존 **NOODOE-LANGUAGE-B-0.10.1.zip**을 그대로 사용해요. 정상 설치된 팩은 재전송하지 않아요. 직접 켠 **English only**는 유지되니, 한국어로 쓰려면 이를 끄고 Follow app 또는 Korean을 선택한 뒤 재시작을 확인하세요. 펌웨어 설치 완료와 언어 자원 준비 완료는 별개예요.

## Limits

Software checks only; no physical scooter, Bluetooth timing or power-cut qualification was performed. IGN independence does not mean battery disconnection is harmless. The previously accepted legacy stock-return power-interruption limitation remains. Devices on 0.9.x or an older Gate still use the documented keep-data stock-return/reinstallation route; automatic recovery in that old-code interval is not guaranteed.
