# 외장 NOR 백업 · 파일 탐색기

0.9.18부터 앱의 **꾸미기 → NOR 파일 탐색기 / 백업**에서 사용할 수 있습니다. 대응하는 최신 APK와 CFW를 함께 설치하고 주행 연동으로 연결하세요.

## 필요한 파일만 가져오기

1. **FAT / 파일 목록 읽기**를 누릅니다.
2. 폴더를 열고 원하는 파일을 선택합니다. **FONT 폴더 보기**로 글꼴 폴더를 바로 찾을 수 있습니다.
3. **백업**을 누릅니다. 작업은 화면을 닫거나 폰 화면을 꺼도 연결 서비스에서 계속됩니다.
4. 끝나면 **최근 백업·증거 ZIP 내보내기**로 저장 위치를 선택합니다.

IGN ON/OFF 모두 사용할 수 있고, 음악·GPS·알림 전송에 우선권을 양보합니다. 파일 복사 취소는 누도를 재부팅하지 않습니다. 기존 절전으로 연결이 종료되거나 Android가 앱을 강제 종료하면 미완료 상태로 남습니다.

파일 내용뿐 아니라 양쪽 FAT·디렉터리·클러스터 번호와 물리 주소를 함께 보관합니다. `file.bin`은 파일 내용, `clusters.raw`는 원래 저장된 바이트, `metadata-주소.raw`와 `manifest.properties`는 분석용 근거입니다. 내용 재대조와 메타데이터 검사를 통과해야 검증 완료가 됩니다. 계속 기록 중인 파일은 변경 때문에 실패할 수 있습니다.

읽기 전용입니다. 파일 삭제·덮어쓰기·포맷·자동 FAT 복구는 없습니다. 파일명은 FAT 짧은 이름으로 표시합니다. 손상된 체인이나 다른 파일과 겹치는 파일은 이유를 표시하고 추출을 거절합니다. 손상 흔적까지 보존하려면 전체 백업을 사용하세요.

## 외장 NOR 전체 128MiB 가져오기

**IGN OFF에서만 시작할 수 있습니다.** 전체 백업은 긴 작업이며, 펌웨어 업데이트와 소요 시간이 다릅니다. 실차 전송 시간은 아직 측정하지 않았습니다. 폰에 최소144MiB와 내보낼 ZIP을 위한 여유 공간을 준비하세요.

- **전체 NOR 백업 · IGN OFF → 시작 / 검증하며 이어받기**를 누릅니다.
- 설정·주행 기록의 저장을 마친 뒤 기기 NOR 쓰기를 정지하고 전용 백업 화면으로 전환합니다. 음악·GPS·알림 등 일반 연동도 중지합니다.
- 누도에는 현재 단계와 복사한 바이트, 앱에는 진행률·전송량·속도가 표시됩니다.
- 폰에 저장된 파일을 다시 읽어 검사하고 기기의 전체 SHA-256과 대조합니다. 성공하면 `nor.raw`와 검증 기록이 남고 누도가 재시작됩니다.
- **O를 완전히 놓았다가 새로3초 유지**하거나 앱에서 취소할 수 있습니다. PH9 차단 상태에서도 취소할 수 있습니다.
- IGN ON/상태 미확인, 통신60초 단절, 진행5분 정체, 준비30초 초과, 읽기 오류도 안전하게 정리한 뒤 시스템 재시작으로 끝납니다.

짧은 단절 뒤 같은 동결 세션으로 돌아오면 이미 받은 부분을 해시로 대조해 이어받습니다. 재부팅했다면 byte0부터 새 스냅샷을 검증합니다. 서로 다른 시점의 덤프를 한 파일로 몰래 섞지 않습니다. 미완료 파일은 `.partial`로 남으며 완료본으로 취급하지 않습니다.

전체 백업은 **외장 NOR만** 포함합니다. MCU 내부 순정 부트로더·공장 영역의 백업은 아닙니다. 물리 바이트 순서 그대로이며 파일 탐색기의 논리 파일과는 바이트 쌍 순서가 다를 수 있습니다. 원본 ZIP과 manifest를 함께 보관하세요. 내보내도 앱 내부 원본은 유지됩니다.

## 검증 범위

128MiB 모의 전송·단절·이어받기·해시, 손상 FAT, 취소/IGN/시간 제한과 기존 전원 경로를 시험했습니다. 표시 화면은 실제 펌웨어 LVGL/EVE 경로의 소프트웨어 캡처입니다. 실제 차량 Bluetooth 속도와 소비전력은 실측하지 않았습니다.
