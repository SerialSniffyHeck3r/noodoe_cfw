# Companion 0.9.67 · 실제 순정 응답 우선

앱 데이터를 지우지 않고 APK를 업데이트하세요. **Android 앱만 수정**했습니다. 본체 Product는 0.9.66이고 0.9.67 설치 ZIP은 0.9.66과 바이트 단위로 같습니다. 이미 0.9.66이 정상인 본체는 다시 플래시할 필요가 없습니다.

기기 확인·연결 복구·Bootstrap 연결·재페어링 검증에서 선택한 Bluetooth 주소의 유효한 순정 응답을 받으면 바로 순정 설치 화면으로 돌아갑니다. 이전 Bootstrap 대기·페어링 복구·이관 안내·앱의 업데이트 잠금을 정리합니다. 순정 판별에 ZIP이나 과거 단계 검사는 필요 없습니다. 선택한 ZIP과 과거 증거는 보관합니다. 실제 설치는 기존대로 순정 5.14·5.16, 선택 주소, IGN ON 정차 상태를 새로 검사하며 HW·부트로더 버전·모델·PCBA 화이트리스트는 없습니다.

별도로 저장하던 VERIFY·STOCK 페어링 단계를 연결 확인 하나로 합쳤으며 구버전 설정도 이어집니다. 페어링 안내의 **현재 펌웨어 확인**은 과거 초기화 단계를 완료하지 않아도 실행할 수 있습니다. 실제 Bootstrap이라면 휴대폰 등록 삭제 및 본체 페어링 초기화 후 보안 연결·새 키 저장 검증은 그대로 필요합니다.

과거 시도는 기록으로 보관합니다. 순정 판별은 과거 플래시/NOR 기록의 성공·취소를 뜻하지 않고, 자동 전송·삭제·본체 리셋을 하지 않습니다. 오래된 설치 버튼 동작은 순정 확인까지만 수행하며 새 설치는 다시 직접 시작합니다. 무응답·거부 응답·다른 주소를 순정으로 간주하지 않습니다.

보고된 경우 같은 폰에 APK 0.9.67을 설치하고 **현재 펌웨어 확인 / 기기 확인**으로 순정 화면에 돌아오세요. 진단은 보안 연결 후 NDCP 식별 응답이 없는 반복을 보여주지만 최초 Bootstrap 전송 실패는 담고 있지 않습니다. 앱의 과거 상태에 갇히는 문제를 수정한 것이며 최초 무선·전환 실패 원인을 확정한 것은 아닙니다.

Stage 6/4에서 요구하면 **UP + O를 함께 3초** 누르고 놓은 뒤 앱의 결과 확인을 기다립니다. 본체 재시작 문제는 그대로입니다. F4 순정 5.14·5.16 설치 허용은 모든 차종의 실기 호환성 검증을 의미하지 않습니다.

실제 순정 프레임·NDCP 시뮬레이션, 설치 기록·화면 상태 시험, APK 서명, 실제 ZIP 가져오기 및 Product 해시를 검증했습니다. 휴대폰·Bluetooth·LCD·차량 실기 시험은 하지 않았습니다.
