# 0.9.73 발신자 표시와 주행 연결 복구

[사용 설명서](README.md) · [English](34-Call-Reconnect.en.md)

안드로이드가 전달한 발신번호를 보조 통화 감지에서도 유지합니다. 연락처 권한과 해당 연락처가 있으면 이름으로 표시합니다. 번호가 제공되지 않은 통화의 신원을 만들어 내지는 않습니다. 통화가 끝나거나 새 전화가 오면 이전 번호가 남지 않습니다.

지도·통화 화면 등의 데이터 전송 위치나 세션 오류가 발생하면 기존 Bluetooth 연결을 정리하고 새 연결에서 현재 상태를 다시 동기화합니다. 재연결 간격은 2초, 5초, 이후 최대 10초이며 차량을 찾지 못했다는 이유로 횟수를 소진하여 중지하지 않습니다. 사용자가 주행 연동을 직접 중지했거나 페어링/권한 문제가 있으면 기존 안내에 따라 조치해야 합니다.

통화 종료·받기·발신 등의 버튼 동작을 재연결 후 자동으로 반복하지 않습니다. 지도는 연결 복구 후 다시 준비되므로 잠시 로딩될 수 있습니다. 처음 문제가 난 데이터의 위치와 기기의 수신 위치를 진단에 기록하며 전화번호·이름·메시지 본문을 기록하지 않습니다.

**설치:** 앱 데이터를 유지한 채 APK 0.9.73을 덮어 설치하세요. Product와 대응 설치 ZIP은 0.9.71/0.9.72와 바이트까지 같습니다. 이미 해당 CFW가 실행 중이면 본체 펌웨어를 다시 설치할 필요가 없습니다. 첫 설치, 설정 보존, Stage 6/4 수동 재시작과 Bootstrap 연결 절차는 기존과 같습니다.

검증은 소프트웨어 모의 시험입니다. 실제 전화·Bluetooth·차량에서의 검증 결과를 의미하지 않습니다.
