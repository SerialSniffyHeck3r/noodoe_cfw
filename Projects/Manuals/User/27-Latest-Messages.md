# 0.9.65 · 최신 알림과 위치·음악 답장

누도가 알림 그림을 받는 동안에도 새 메시지를 버리지 않습니다. 폰에는 최신 내용을 유지하고 아직 보내지 않은 중간 갱신은 합칩니다. Android 대화형 알림은 대화의 마지막 메시지를 사용합니다. 이전 그림의 전송이 뒤늦게 끝나도 최신 알림을 덮어쓰지 않습니다.

스마트폰 요약에서 **DOWN**을 누르면 최신 알림으로 갑니다. 첫 번째 알림 페이지는 새 도착 내용을 따라갑니다. 이전 기록을 선택했거나 답장 메뉴를 열었으면 선택한 대화에 머무릅니다. 새 메시지를 받았다는 정보는 왔지만 그림이 아직 준비되지 않았으면 **Updating...**을 표시한 뒤 최신 그림으로 교체합니다. 이전 문구를 최신 것처럼 표시하지 않습니다. 실제 전송·렌더링 시간은 필요하며 연결 해제·권한 차단 중 즉시 수신을 보장하지 않습니다. 폭주 중 중간 알림은 상세 카드 최대 9건에서 생략될 수 있으며 미확인 집계는 별도로 유지합니다. 알림 접근을 켜기 전 Android 알림창의 기록은 가져오지 않습니다.

알림 내용 갱신과 표시 트리거를 분리했습니다. 팝업의 10초 알림 구간 안에 도착한 내용은 팝업을 다시 트리거하지 않습니다. HOME에서는 기존 20초 구간을 늘리거나 수동 건너뛰기를 취소하지 않고 최신 내용으로 갱신합니다. 상단 휴대전화 아이콘의 2초 펄스도 연장하지 않습니다. 팝업 필터는 메시지 수신을 막지 않습니다.

## 빠른 답장

답장 가능한 알림에서 **O 길게**, UP/DOWN으로 선택, **O 짧게** 전송합니다. O 길게 또는 Back은 취소입니다. 기존 속도·시동 조건은 유지합니다. 해당 알림에 Android 직접 답장 액션이 있어야 합니다.

| 슬롯 | 기능 |
|---|---|
| 1–8 | 고정 위치의 사용자 문구. 빈 슬롯은 전송하지 않습니다. |
| 9 | 현재 위도·경도와 누르면 지도를 여는 Google Maps 링크. |
| 10 | 현재 듣고 있는 아티스트와 곡명을 포함한 문장. |

위치와 음악은 메뉴를 만들 때가 아니라 **O로 전송을 확정할 때** 읽습니다. 위치는 5초 이내의 실제 GPS, 정확도 30m 이내, 유효한 좌표가 필요합니다. GPS 테스트 위치는 보내지 않습니다. 위치가 없거나 오래됐으면 전송하지 않습니다. 링크는 지원되는 환경에서 Google Maps 앱, 그 외에는 웹 지도를 엽니다([공식 Maps URL 안내](https://developers.google.com/maps/documentation/urls/get-started)).

음악은 Android MediaSession에서 실제 재생 중이며 아티스트와 제목이 모두 있어야 합니다. 일시정지·정지·정보 없음 상태에서는 보내지 않습니다. 유효한 모든 답장에는 설정한 서명을 붙입니다. 기존 9·10번 문구는 앱 설정에 보존하지만 새 메뉴에서는 쓰지 않습니다. 내용·대상이 바뀌거나 삭제·권한 해제된 알림에는 다른 수신자로 몰래 바꿔 보내지 않습니다. `Reply handed to app`은 Android에 인계했다는 뜻이며 상대방 수신 확인이 아닙니다. 정보가 없으면 전송하지 않고 `Reply not confirmed`가 표시됩니다.

**같은 0.9.65 APK와 ZIP**을 사용하고 업데이트 시 앱 데이터를 유지합니다. 최초 설치는 순정 **5.14·5.16**을 허용하며 HW·부트로더 버전·모델·PCBA 화이트리스트는 없습니다. 이것이 모든 모델의 전기적 호환성 검증을 의미하지는 않습니다. Bootstrap 수동 재페어링 절차와 Gate·Bootstrap 바이너리는 그대로입니다. Stage 6/4에서 RESET을 요청하면 UP+O를 함께 3초 누르고 놓은 뒤 앱의 결과 확인을 기다립니다. 해당 근본 문제가 해결됐다고 주장하지 않습니다.

이번 릴리스는 소프트웨어로 검증했습니다. 차량 실기·실제 메시지 앱 전송·무선 지연 측정은 하지 않았습니다.
