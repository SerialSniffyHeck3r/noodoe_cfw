# NewDoe 0.13.2 beta

지도 궤적 색상을 선택할 수 있습니다. **설정 → 화면 → 궤적 색상(Trail color)** 에서 고정 색상 7개 또는 **속도에 따라(By speed)** 를 고르세요. 휴대폰의 기기 설정에서도 바꿀 수 있습니다.

속도 모드는 각 구간을 지날 당시의 계기판 속도를 기록합니다. 파랑에서 청록·초록·노랑·주황을 거쳐 빨강이 되며, **설정 → 차량 → Ring maximum** 이 빨강의 기준입니다. 그 이상도 빨강이며, 속도를 알 수 없었던 구간은 회색입니다. 기본값은 기존 빨강입니다.

1. NewDoe-0.13.2.apk를 기존 앱 위에 설치하세요.
2. 차량을 정차하고 앱에서 **현재 상태 확인** 후 **업데이트**를 선택하세요. 펌웨어가 APK에 포함되어 있습니다.
3. 기존 B 언어팩도 사용할 수 있습니다. 새 설정 이름까지 번역하려면 앱에 포함된 B 언어팩 0.13.2를 설치하세요. A 기기는 영어를 사용합니다.

Gate와 Bootstrap은 변경하지 않았습니다. 이미 호환 Gate를 사용하는 0.12.x·0.13.x 기기는 일반 CFW 업데이트 경로를 사용하세요. 구형 Gate 기기는 앱이 안내하는 데이터 보존 순정 복귀·재설치 절차를 따르세요. 기존 구형 코드가 실행하는 순정 복귀 구간의 전원 차단 제한은 남아 있습니다.

## English

Choose one of seven fixed trail colors or **By speed** under **Settings → Display → Trail color**, on Noodoe or in the phone device-settings editor. The default remains red; changes apply without restarting.

Each leg retains its recorded dashboard speed. The spectrum runs blue → cyan → green → yellow → orange → red. **Settings → Vehicle → Ring maximum** determines the red endpoint; higher speeds stay red. Unknown-speed legs are gray. Maps, compass, trip counters and ODO remain available.

Install the APK over the existing app, check the actual device status, then update the device using the included firmware. The included B language pack 0.13.2 translates the new labels; older packs remain usable with English fallback for new labels. A devices use English. No external downloads are needed for normal installation.

Gate and Bootstrap are unchanged. Devices already using the compatible Gate follow the normal CFW update path. Older Gate devices follow the app's keep-data stock-return/reinstall guidance. The previously accepted power-interruption limitation in already-installed legacy stock-return code remains.
