# FuckNudo 사용 설명서

**대상: CFW 6.10.0 / Companion 6.10.1.** APK 6.10.1은 사용 설명서 바로가기를 추가한 버전이며, 대응 펌웨어는 6.10.0입니다. 

**주의! 본 설명서의 내용은 예고 없이 달라질 수 있습니다. 자세한 것은 Android App의 설명란을 참고하십시오.**

**iPhone, iPad OS는 지원하지 않습니다. Hardware 상에서는 MFI를 지원하지만, 본인은 Apple의 과하게 진보주의적임과 동시에 비윤리적인 기업 가치를 반대하기 때문에 앞으로 지원할 생각이 없습니다.**



그니까... 2027년 KYMCO는 AK550, Xciting 400을 비롯한 자사의 모터사이클에 약 5년이 넘는 주기 동안 탑재되어 발매된 Noodoe 시스템의 서비스를 완전히 종료했습니다. 
해당 서비스는 KYMCO가 배포한 순정 App과 그 서버에 의존하므로, 이것이 종료될 경우 앞으로 KYMCO 이륜차의 계기판 내 환경 설정이나 의도된 기능을 전혀 사용할 수 없습니다.
이것은 그야말로 말도 안되는 개 헛소리라고 볼 수 있으며 이는 본인의 IOT 혐오 성향에 기름을 부었으며 이에 따라 아예 순정 펌웨어를 대체한 Custom Firmware를 개발하게 된 계기가 되었습니다. 

FuckNudo는 Noodoe 화면을 속도 링, 트립 컴퓨터, 휴대전화 알림·음악·전화, 폰 GPS 궤적, 사진 배경으로 사용하는 커스텀 펌웨어입니다. 기존의 Noodoe의 하드웨어가 가진 포텐셜을 충분히 활용하여 '원래 Noodoe는 이렇게 나왔어야 했다!' 를 충실히 실현한 커스텀 펌웨어 프로젝트입니다. 시도해서 나쁠 것은 없으니 본인이 AK550 오너라면 한번쯤 깔아 보십시오. 

본 펌웨어는 Android 휴대전화 한 대와 Classic Bluetooth SPP로 연결합니다. 전화 음성·음악 소리는 휴대전화와 기존 헤드셋에서 재생됩니다.

## 처음 사용한다면

1. [앱과 휴대전화 준비](02-Phone-Setup.md)를 읽고 권한을 설정합니다.
2. 순정 기기는 [최초 설치](08-First-Install.md), 이미 CFW인 기기는 [업데이트](09-Update.md)를 따릅니다.
3. [버튼과 공통 화면](01-Controls.md)을 익힌 다음 각 화면을 확인합니다.
4. 문제가 생기면 재전송부터 반복하지 말고 [문제 해결](11-Troubleshooting.md)과 [순정 복귀](10-Recovery.md)를 봅니다.

**설치 완료는 전송 100%와 다릅니다.** `NOODOE INSTALLER`는 설치 중 화면입니다. 새 CFW의 `CFW UPDATE` 화면을 확인하고 앱의 화면 확인을 완료한 뒤, 정상 실행·Bluetooth 재연결·영구 확정까지 끝나야 제대로 설치가 된 것입니다.

반드시 설치 도중 휴대전화의 전원과 차량의 전원을 유지하십시오. 설치 도중에는 차량의 엔진 시동 상태를 절대로 전환하지 마십시오. 차량의 셀 모터가 회전하여 BOR이 걸릴 경우 JTAG를 통한 Firmware Reflash가 필요할 SUDO 있습니다.
