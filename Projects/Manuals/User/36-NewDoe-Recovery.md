## 0.11.12: 주차 절전 보완

**APK와 0.11.12 펌웨어 ZIP을 함께 설치해야 적용됩니다. APK만 업데이트하면 누도의 절전 코드는 바뀌지 않습니다.** 같은 Gate를 사용하는 0.11.4 이후 기기는 기존 CFW 업데이트를 사용합니다. 더 오래된 Gate는 앱의 기존 데이터 유지 순정 복귀·재설치 안내를 따르세요. Gate, Bootstrap, 언어팩과 페어링 절차는 이번에 바꾸지 않았습니다. 구버전 순정 복귀 구간의 전원 중단 한계도 남아 있습니다.

**설정 → 시스템 → 전원 순서 → 장기 주차 전원 끄기**에서 끄기 / 2일 후(기본) / 3일 후 / 7일 후를 고릅니다. 기존 설정은 보존합니다. 화면 유지 60분 → Bluetooth 유지 60분 → 깊은 절전이라는 기본 순서도 그대로입니다. 마지막 절전 단계를 건너뛰거나 장기 주차를 끄면 해당 보호가 동작하지 않으므로 저장된 설정을 확인하세요.

장기 주차 시간은 정상 화면이 표시되지 않아도 StorageTask에서 셉니다. 화면 오류로 설정을 복원하지 못하면 정상 설정 기록의 장기 주차 값을 읽고, 기록을 읽을 수 없으면 기존 기본값인 2일을 사용합니다. 정상 기록에 저장한 ‘끄기’는 그대로 존중합니다. 소프트웨어 재시작에는 경과 시간을 유지하고, IGN ON·실제 전원 투입·손상된 타이머 기록에서는 기존처럼 다시 셉니다.

시간이 되면 새 설정·주행 스냅샷 저장을 시도합니다. 30초가 지나도 화면 오류 등으로 새 스냅샷을 만들 수 없으면 마지막 정상 저장본을 보존하고 종료 준비를 진행합니다. 이 경우 아직 저장하지 못한 최근 변경은 남지 않을 수 있습니다. 이미 시작한 NOR 기록은 끝까지 완료하며, 펌웨어·언어팩 기록을 중간에 끊지 않습니다. 저장소가 정리되고 정지 확인까지 끝난 뒤에는 Bluetooth·화면 종료 응답이 없어도 10초 후 전원 종료 신호를 요청할 수 있습니다. 실제 저장 작업이 진행 중이면 이 제한 시간으로 건너뛰지 않습니다.

RTC를 쓸 수 없으면 CPU가 바쁜 루프를 돌지 않고 일반 Sleep을 사용합니다. 깊은 STOP보다 소비전류가 클 수 있습니다. 계기판 송신은 1초 동안 완료를 기다린 뒤 오류 정리를 진행합니다. DMA 오류의 격리 상태는 지우지 않으며, 실제 DMA가 정지한 것을 확인한 경우에만 절전을 허용합니다.

전원 종료 신호를 보냈다는 사실은 전원 회로가 실제로 차단됐다는 측정 결과가 아닙니다. 전원이 남아 있으면 가능한 주변장치를 끄고 깊은 절전을 시도하며, IGN ON에서 Gate부터 재시작합니다. 종료하지 못한 DMA를 정상이라고 가장해 STOP에 들어가지는 않습니다. 이 상태에서는 휴대폰 접근 연결·웰컴 라이트를 기대하면 안 됩니다.

**화면이 꺼졌다고 소비전류가 충분히 낮다는 뜻은 아닙니다.** 누도는 차량 배터리 전압을 측정해 자동 차단하는 보호기가 아닙니다. 실제 대기전류·하드웨어 전원 차단·일주일 유지 시간은 이번 소프트웨어 시험으로 확인하지 않았습니다. 배터리 전압이 심하게 낮다면 충전과 배터리 점검을 먼저 하고, 불안정한 전원으로 설치하지 마세요. 절전 단계가 지난 뒤 누도 연결/분리 상태의 배터리 측 대기전류를 비교해야 방전 원인을 구분할 수 있습니다.

## 0.11.4 Gate 업데이트

이번에는 Gate가 바뀝니다. **0.11.3을 포함한 이전 버전에서는 데이터 유지 순정 복귀 후 0.11.4를 재설치하세요.** 0.11.4 APK를 기존 앱 위에 설치하고 같은 버전 ZIP을 선택한 뒤, 앱의 Gate 교체 안내를 따릅니다. 일반 Product 업데이트만으로 새 Gate를 적용할 수 없습니다.

1. 주행 연동을 중지하고 **CFW 데이터 유지 → 순정 복귀 → 현재 기기 확인**을 진행하세요.
2. **NewDoe-CFW-0.11.4.zip**으로 설치하고 Bootstrap에서 **저장된 데이터 복구**를 선택하세요. 연결이 안 되면 기존 연결 도움말에 따라 수동 재페어링 후 **현재 기기 확인 → 계속하기**를 사용합니다.
3. 정상 실행 후 실제 **CFW UPDATE** 확인과 앱의 펌웨어 확정을 끝내세요.
4. **NewDoe-LANGUAGE-B-0.11.2.zip**은 이번에도 그대로 사용합니다. 이미 검증된 같은 팩은 다시 보내지 않습니다. 0.11.3의 언어 안정성 수정도 유지됩니다.

작은 글씨와 버전 글씨를 메인 메뉴 크기 이상으로 키우고 메뉴를 중앙 정렬했습니다. Dashboard는 값과 상태를 각각 줄로 나눴습니다. 정상 펌웨어의 실행 검증이 끝나면 백업 검사 중에도 **Start NewDoe**를 선택할 수 있습니다.

확인되지 않은 부팅 실패가 **연속 3회** 누적되면 자동 복구로 들어갑니다. 정상 부팅 확인은 횟수를 초기화하고, 전원 차단·BOR로 중단된 마지막 시도는 실패로 세지 않습니다. 펌웨어나 저장소 검증 실패는 손상된 코드를 실행하지 않도록 즉시 복구로 들어갈 수 있습니다. 실제 DOWN/O 입력을 확인한 경우에만 버튼 요청이라고 표시하고, 다른 진입은 부팅 중단·저장된 복구 상태·오류로 구분합니다.

**순정 복귀·재설치 중 상시 전원을 유지하고 스타터를 돌리지 마세요.** 기존에 수락한 구버전 순정 복귀 구간의 전원 중단 한계는 남아 있습니다. 새 Gate의 BOR 처리가 구버전 설치 코드까지 고치는 것은 아닙니다.

실기 확인: 부팅 버전 V0.11.4 → 메뉴 글씨·중앙 정렬 → More/Dashboard → 복구 검사 중 Start 활성화 → 정상 부팅 후 다시 켰을 때 불필요한 복구 진입 여부를 확인하세요. 고의로 설치 중 전원을 끊어 시험하지 마세요. 소프트웨어 ARM 실행과 화면 명령 검증을 완료했으며, 이번 변경의 실기 전원·LCD 시험은 수행하지 않았습니다.

# NewDoe 0.11.4: 부팅, 복구, 장기 주차

APK와 펌웨어 ZIP을 모두 0.11.4로 맞춰 주세요. 앱 서명과 기존 설정은 유지됩니다. 이번에는 Gate가 바뀌므로 **0.9.x, 0.10.x, 0.11.0/0.11.1 모두 데이터 유지 순정 복귀 후 재설치**가 필요합니다. Product 업데이트만으로 Gate를 덮어쓰지 않습니다. 이후 같은 Gate를 사용하는 버전끼리는 일반 CFW 업데이트를 사용할 수 있어요.

## 설치 순서

1. 기존 앱 위에 APK 0.11.4를 설치하고 앱 데이터와 백업을 보존하세요. 같은 기기와 0.11.4 ZIP을 선택하고 주행 연동을 중지합니다.
2. **CFW 데이터 유지 → 순정 복귀 → 현재 기기 확인**을 진행합니다. 순정 5.14/5.16 지원은 그대로이며 모델·부트로더 제한을 새로 추가하지 않았습니다.
3. 새 ZIP의 Bootstrap을 보내고 **저장된 데이터 복구**를 선택하세요. 연결이 안 되면 연결 도움말을 열어 Android에서 페어링 삭제, Bootstrap 페어링 초기화, 재페어링을 한 뒤 **현재 기기 확인 → 계속하기**로 진행합니다. 재페어링 완료를 기록하는 새 의무 상태는 없습니다.
4. 설치 후 정상 부팅과 실제 **CFW UPDATE** 확인까지 완료하세요. 전송 100%만으로 펌웨어 설치가 확정되지는 않습니다.
5. 정상 B 언어 자원은 계속 사용할 수 있습니다. **NewDoe-LANGUAGE-B-0.11.2.zip**은 9개 시스템 언어에 장기 주차 설정 번역을 추가합니다. 일본어/CJ/이모지 글리프는 그대로입니다. 새 항목도 번역하려면 펌웨어 확정 후 언어 자원을 갱신하세요. 이전의 정상 팩에서는 새 항목만 영어로 표시됩니다. 영어 전용 설정은 보존합니다.

순정 상주 부트로더는 바꾸지 않습니다. **순정 복귀·재설치 내내 상시 전원을 유지하세요.** 구버전 코드가 순정 복귀 요청을 기록하는 중 전원이 끊기면 새 Gate가 실행되기 전에 멈출 수 있으며, 이 구간의 자동 복구는 보장하지 못합니다. IGN OFF는 상시 전원 차단과 다릅니다. 설치 중 스타터 조작은 피하세요.

## 부팅·업데이트 화면

첫 화면은 가운데 NewDoe 투명 워드마크와 그 아래 **V0.11.4**만 약 2초 표시합니다. 버전은 Product 내부 플래시에 있는 길이·체크섬 검증된 기록에서 읽습니다. 기록이 없거나 잘못되면 버전 글씨는 생략합니다.

검사가 시작되면 위에 **SYSTEM STARTUP...**, 가운데 워드마크, 아래 현재 단계와 민트색 원형 도트 8개를 표시합니다. 도트는 전체 작업 진행률을 나타냅니다. 완료된 도트는 계속 켜지고 현재 도트는 250ms 켜짐/250ms 꺼짐으로 초당 두 번 깜빡입니다. 단계 문구와 도트, 도트끼리의 간격을 넓혔습니다. 완료 시 8개가 모두 켜집니다.

업데이트 재시작은 첫 로고 대기를 건너뜁니다. Gate가 펌웨어를 설치하는 동안 **UPDATING SYSTEM...** 아래에 정상 그림 또는 브레인랏 그림 하나를 골라 표시합니다. 한 번 고른 그림은 그 부팅 동안 유지됩니다. 둘 다 240×168 투명 이미지이며 Gate 내부 플래시에 압축 저장합니다. 단계와 도트는 그대로 표시합니다. 휴대폰에서 Product로 전송하는 단계의 화면·프로토콜은 유지됩니다.

전원 투입 후 DOWN을 누르고 부팅하거나 로고 구간에서 1초 누르면 복구로 들어갑니다. 기존 O 진입도 유지됩니다. 오류가 감지되면 해골 화면으로 넘어갑니다.

## 오류·복구

해골 아래에 기존 오류 번호를 **0x0000** 형식으로 크게 표시하고 **PRESS ANY KEY... 30**을 카운트합니다. 새 버튼 입력이나 실제 화면 표시 후 30초가 지나면 복구 메뉴로 갑니다. 이 입력으로 메뉴 항목이 실행되지는 않습니다. 진입 사유는 **[코드] [짧은 설명]**, 수동 진입은 코드 없이 표시합니다.

고정된 8개 항목은 **Start NewDoe / Check again / Reinstall firmware / Restore previous / Return to stock / Details / More / Restart**입니다. 사용할 수 없는 항목은 회색입니다. UP/DOWN으로 이동, O로 선택합니다. 기록을 바꾸는 복구와 재시작은 O를 놓았다가 새로 2초 눌러 확인하며 UP/DOWN으로 취소합니다. 정상 부팅 검사와 시험 부팅 제한은 우회하지 않습니다.

일반 순정 복귀가 불가능하면 같은 위치에서 **Try recovery anyway**를 제공합니다. 다른 FAT 경로, 연속된 백업 영역, 이미 완성된 순정 스테이징 이미지를 찾아 기기 식별·대상·전체 SHA를 검증한 뒤 복구합니다. 손상된 바이트를 무시하거나 없는 펌웨어를 만들어내지는 않습니다. 대기 중 언어/FONT 작업이 복구 공간을 점유하면 이를 포기하는 별도 확인을 받습니다.

이번 시도의 실패 표시는 재부팅 또는 Check again으로 초기화하되, 영구 부팅·업데이트 기록의 검증은 유지합니다. 일시적 읽기 오류만으로 복구 불가라고 단정하지 않습니다. 깊은 검색까지 소진되거나 강제 복구가 실패한 경우 복구 불가 안내를 표시하며, O를 눌러 메뉴로 돌아가 다시 시도할 수 있습니다. 도움말에는 GitHub 주소와 분해 후 프로그래머 복구 또는 수리 불가능 시 교체 안내가 있습니다.

**More → Help / Dashboard / Play game / Back**을 제공합니다. Dashboard는 수신된 속도·누적 거리·연료를 표시합니다. 데이터가 없거나 오래되면 임의의 0 대신 미수신 상태로 표시합니다. 기존 통신 응답 외에 계기판 값을 쓰지는 않습니다. Pong은 UP/DOWN으로 패들을 움직이고 현재 점수만 표시하며 O로 나갑니다. Gate에는 Bluetooth, LVGL, SDRAM, 외장 폰트 의존성이 없습니다.

하드웨어 재시작 방법: **IGN OFF → UP + O 누르기 → 놓기 → IGN ON**. IGN OFF에서는 꺼진 것처럼 보일 수 있으며 IGN을 다시 켜면 Gate부터 시작합니다. Gate나 화면 자체가 실행되지 않는 고장에서는 안내를 표시할 수 없습니다.

## 장기 주차·배터리

**설정 → 시스템 → 전원 순서 → 장기 주차 전원 끄기:** 끄기 / 2일 후(기본) / 3일 후 / 7일 후. 앱의 기기 설정에서도 같은 값을 고를 수 있습니다. 연속 IGN OFF 시간은 소프트웨어 재시작을 거쳐 유지되고 IGN ON 또는 실제 전원 투입 시 초기화됩니다. 타이머 기록이 손상되면 일찍 끄지 않고 다시 셉니다.

시간이 되면 설정·주행 기록 저장, 저장소 정리, 주변장치 절전 응답을 기다리고 IGN을 다시 확인한 뒤 전원 끄기를 요청합니다. 업데이트·언어 기록을 중간에 끊지 않습니다. 회로가 계속 전원을 공급하더라도 화면과 Bluetooth를 끈 깊은 대기로 남으며 다음 IGN ON에서 재시작해 Gate로 들어갑니다. 이 상태에서는 휴대폰 접근 재연결과 웰컴 라이트가 작동하지 않습니다. 그 전까지의 연결 유지 설정은 그대로입니다.

기존 전원 순서와 대기 시간도 유지됩니다. Gate 역시 IGN OFF 상태에서 방치하면 화면을 끄고 RTC STOP 대기를 사용합니다. 버튼으로 깨울 때는 메뉴를 바로 선택하지 않습니다. RTC 대기를 사용할 수 없으면 짧은 일반 슬립을 사용합니다.

검증 범위는 소프트웨어 상태 전이·중단 복구·화면 명령입니다. 실제 대기 전류나 일주일 배터리 수명을 측정한 것은 아닙니다. 실기에서 절전·장기 주차 이후 전류와 IGN/버튼 복귀를 확인해야 합니다. Product Debug·Release 내부 플래시 여유는 각각 최소 **512바이트**이며 기존 힙·스택·폰트·아이콘과 컴파일 정책은 유지됩니다.
