# 순정에서 최초 설치 · 0.9.61 / 설명서 2판

**2026-10-07 개정** · [호환 모델과 설치 조건](07-Compatibility.md) · [English](08-First-Install.en.md)

[목차](README.md) · [이미 CFW라면 업데이트](09-Update.md)

## 주의사항

휴대전화 배터리와 차량 전원을 충분히 확보하고 설치 앱을 실행한 상태로 유지하세요. 불필요한 앱은 정리해도 되지만 설치 앱·Bluetooth 서비스를 강제 종료하지 마세요.

차량을 정차하고 안정적인 전원을 유지하며, IGN 조작은 기기와 앱 안내를 따르세요.

설치·기록 중에는 앱을 강제 종료하거나 스타터를 조작하지 마세요.


## 준비

0.9.61 최초 설치 허용 범위는 **F4/HW0·순정 5.16·부트로더 0.10~0.19**입니다. 모델명·SAA1AA·PCBA로 제한하지 않습니다. 기기별 부트로더 캡처·원본 백업·해시 검증은 유지합니다. [English procedure](08-First-Install.en.md).

최신 APK와 **그 릴리스에 함께 제공된 설치 ZIP**을 받습니다. ZIP을 임의로 풀어 BIN 하나를 골라 보내지 않습니다. 앱에서 기기를 선택하고 ZIP을 선택한 뒤 설치 마법사를 진행합니다. 실제 기기 정보와 패키지 호환 검사를 통과해야 합니다. 오류를 없애려고 다른 기기의 기록을 가져오거나 기기 정보를 바꾸지 마세요.

키 신호와 상시 12V는 다릅니다. 설치 화면이 키 OFF 후에도 유지될 수 있습니다. 충분한 전원과 폰 배터리를 준비하고 설치 중 차량 배터리를 분리하지 마세요. 완료 시간을 보장된 고정 분수로 보지 마세요. 아래 캡처는 단계별 안내용 상태 주입이며 실측 전송 시간표가 아닙니다.

## 1. 순정 → Bootstrap 전송

![Bootstrap 전송](../images/install-01-stock-transfer.png)

앱은 순정 프로토콜로 설치 도구를 보냅니다. 사용자 기기의 순정 정보와 주소를 확인합니다. 이 단계는 이미 설치된 CFW의 업데이트와 다릅니다.

## 2. 순정 설치 완료·Bootstrap 부팅

![키 조작·부팅](../images/install-02-stock-reboot.png)

앱이 전송 검증 완료와 키 조작을 안내한 뒤 **상시 전원은 유지하고 IGN OFF → Bootstrap 화면 확인 → IGN ON** 순서로 진행합니다. 검증 전에는 IGN을 먼저 조작하지 않습니다. `NOODOE INSTALLER`가 보이면 **아직 순정 설치기가 기록 중**입니다. Bluetooth가 잠시 끊기는 것은 재시작 때 발생할 수 있으며 앱이 새 역할을 확인해 재접속합니다.

## 3. Bootstrap 식별

![연결 확인](../images/install-03-connect.png)

![해당 단계의 누도 화면](../images/boot-connect.png)

![Bootstrap 시작](../images/boot-welcome.png)

Bootstrap은 `FuckNudo Bootstrap / Welcome`과 설치 메뉴를 표시합니다. 앱은 실제 Bootstrap 역할·이미지·기기 ID를 확인합니다. Android가 페어링 확인을 요구하면 **직접 승인**하세요. 연결 확인은 파일 설치 완료가 아닙니다. Bluetooth test는 진단 메뉴이며 설치를 대신하지 않습니다.

## 4. 저장소 검사

![저장소 검사](../images/install-04-audit.png)

![해당 단계의 누도 화면](../images/boot-audit.png)

Bootstrap에서는 IGN OFF여도 설치가 계속될 수 있습니다. IGN OFF는 설치 취소나 상시 전원 차단이 아닙니다. 각 단계에서 요구하는 IGN 상태는 앱과 본체 안내를 따릅니다.

FAT와 파일 할당을 읽어 순정 파일·예약 영역과 겹치지 않는 위치를 찾습니다. 손상·교차 연결·출처 불명 파일을 무조건 덮어쓰지 않습니다.

## 5. 변경 메타데이터 보관

![원본 보관](../images/install-05-backup-metadata.png)

변경할 FAT/디렉터리 원본과 계획을 폰에 보관합니다. 최신 일반 경로는 전체 128MiB를 반복 다운로드하지 않습니다. 전체 NOR 백업은 별도 정밀 진단입니다.

## 6. CFW 파일 준비·기록·검증

![파일 기록](../images/install-06-file-resource.png)

![해당 단계의 누도 화면](../images/boot-prepare.png)

순정 복구본, 글꼴/BT 자산, 설정·사진·로그 파일, 업데이트 A/B를 준비합니다. 실제로 기록한 내용을 읽어 검증합니다. 기존 순정 사진은 보존하며 기본 새 설치의 CFW 설정·사진 슬롯은 초기화합니다.

**A/B는 사진 두 장이 아닙니다.** 업데이트 후보와 이전 정상 펌웨어를 보존하기 위한 두 슬롯입니다. 성공 확인 전까지 이전 정상본을 지키는 목적입니다.

## 7. 최종 대조

![최종 대조](../images/install-07-preserve.png)

![해당 단계의 누도 화면](../images/boot-verify.png)

FAT, 파일 범위, 필요한 이미지와 자산을 다시 대조합니다. 검증 실패를 단순한 느린 전송으로 취급하지 마세요. 앱의 상세 오류와 기기의 Help code를 보관합니다.

## 8. 설치 이미지 준비

![이미지 전송](../images/install-08-stage.png)

![해당 단계의 누도 화면](../images/boot-transfer.png)

현재 진행률은 해당 전송/검증 작업의 바이트입니다. 전체 진행률은 단계 완료 비율이며 남은 시간 비율이 아닙니다. 파일 순서·섹터·검증 위치가 표시되는 구간에서는 그 값도 함께 보세요.

## 9. 누도에서 Install CFW? 승인

![로컬 승인](../images/install-09-confirm.png)

![해당 단계의 누도 화면](../images/boot-confirm.png)

누도의 `Install CFW?` 안내에서 승인합니다. O를 누르고 있었다면 먼저 놓으십시오. 위 아래 키로 Install CFW를 선택한 뒤 OK를 누르십시오. 반드시 화면에 표시된 조작을 따릅니다. 전송이 끝난 뒤 승인된 설치는 폰 연결이 끊겨도 기기에서 진행될 수 있습니다. 폰의 실패 팝업만 보고 곧바로 파일을 처음부터 다시 보내지 마십시오.

## 10. 설치와 재시작

![설치 중](../images/install-10-reboot.png)

![해당 단계의 누도 화면](../images/boot-install.png)

기기 화면이 순정 설치기로 전환되고 연결이 끊겼다가 돌아올 수 있습니다. 앱은 마지막 확인 상태와 재연결 대기를 표시합니다. `NOODOE INSTALLER`에서는 완료 확인을 누르지 않습니다.

## 11. 새 CFW 화면 확인과 Bluetooth 시험

![정상 실행 확인](../images/install-11-health.png)

![해당 단계의 누도 화면](../images/cfw-confirm.png)

**누도에 새 CFW의 `CFW UPDATE` 화면이 실제로 보일 때** 앱의 해당 화면 확인 버튼을 누릅니다. 앱은 연결된 기기·후보 버전을 재확인한 뒤 Bluetooth 확인을 진행합니다. 정상 태스크 실행 최소 5초와 BT 초기화/앱 재연결 확인이 모두 필요합니다.

후보 부팅 후 확인 기한은 **현재 버전은 최대 5분**이며, 화면 확인을 눌러도 무한히 연장되지 않습니다. Bluetooth를 못 붙였다고 정상 확인을 수동으로 건너뛰지 않습니다. 실패하면 이전 정상 CFW로 롤백하거나, 첫 설치처럼 이전 정상본이 없으면 독립 복구 화면으로 갑니다.

## 12. 완료

![완료](../images/install-12-done.png)

앱이 정상 실행과 영구 확정을 확인하면 완료입니다. 최초 새 설치·명시적 `새로 시작`은 새로운 설정과 사진 슬롯을 준비합니다. 데이터 유지 후 재설치에서 `보관 데이터 복원`을 선택하면 호환 기록을 복원합니다. **이미 사용 중인 CFW의 일반 업데이트는 설정·사진·트립·정비 기준점을 보존**하며, 새 설치와 같은 초기화를 하지 않습니다.

## 취소·오류

Bootstrap의 설치 세션 중 **O를 놓았다가 새로 3초 유지**하면 안전 취소를 요청합니다. 기록 중이면 안전한 경계까지 기다리고 이미 확정된 설치를 억지로 끊지 않습니다. IGN OFF만으로 설치 메뉴에서 나가지 않습니다. 취소 완료와 결과 미확인은 다릅니다. 오류는 [문제 해결](11-Troubleshooting.md)을 따르세요.

## 재시작에서 정지한 경우

0.9.61의 `INSTALLATION PAUSED`와 수동 재시작 안내가 보이면 [설치 정지 복구](10-Recovery.md)를 따릅니다. Stage·Code/phase를 기록하고 UP+O를 함께 3초 유지한 뒤 버튼을 놓고 같은 기기·ZIP으로 상태를 확인합니다. 이전 펌웨어가 실행 중이면 예전 문구가 보일 수 있습니다. 전송 중이라는 이유만으로 이 조작을 적용하지 않습니다.
