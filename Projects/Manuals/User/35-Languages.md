## 0.11.3 언어 안정성 업데이트

0.11.2를 사용 중이면 **0.11.3 APK + NewDoe-CFW-0.11.3.zip**으로 CFW 업데이트하세요. Gate는 0.11.2와 동일하므로 이 경로에서는 순정 복귀가 필요하지 않습니다. 더 오래된 Gate는 기존의 데이터 유지 순정 복귀 안내를 따릅니다.

- 언어팩은 **NewDoe-LANGUAGE-B-0.11.2.zip**을 그대로 사용합니다. 파일명이 이전 버전이어도 맞습니다. 이미 설치된 팩의 실제 해시가 같으면 다시 보내지 않습니다.
- 이전 팩이 있으면 갱신 여부를 따로 묻습니다. 나중에를 선택하면 현재 팩과 언어 선호도를 유지합니다.
- 전송 완료 → 검증·저장 → 자동 재시작 → 실제 메뉴 언어 확인을 구분합니다. 저장 뒤 마지막 응답이 끊겨도 다시 연결해 기기 상태를 확인하며, 펌웨어를 다시 설치하지 않습니다.
- 언어를 바꿀 때는 영어 전용을 끄고 원하는 언어를 선택한 뒤, 정차 상태에서 기기의 재시작 안내를 확인하세요. 앱 따르기는 앱의 언어를 다음 부팅에 적용하고, 직접 선택한 언어는 재연결로 바뀌지 않습니다.
- 부팅 중 일시적 읽기 오류는 두 차례 더 읽어봅니다. 검증을 통과한 번역·글자 캐시는 재검사 때문에 갑자기 영어로 바뀌지 않습니다. 지속적인 오류는 영어로 대체하고 선호도를 보존합니다. 자동 폰트 복구는 하지 않습니다.

확인 순서: 한국어 선택 → 기기의 재시작 확인 → 앱을 누르지 않고 한국어 설정 화면 확인 → 일본어로 같은 과정 반복 → 전원을 다시 켜도 선택 언어가 유지되는지 확인. 이미 현재 팩이 설치돼 있다면 언어 자원 설치/이어가기에서 재전송 없이 실제 적용 언어가 표시돼야 합니다. 읽기 오류가 계속되면 진단을 보존하고 언어 자원 설치/이어가기로 다시 확인하세요. 펌웨어 완료와 언어 자원 오류는 별개입니다.

주행 중에는 설치하지 마세요. IGN ON/OFF는 설치를 취소하지 않지만 상시 전원은 유지해야 합니다. 실제 저장 공간이 부족하거나 폰트 손상이 확정되면 기존 선택 안내를 따릅니다.

# 기기 언어와 글자 표시 · 앱·CFW 0.10.7

[English](35-Languages.en.md) · [사용 설명서](README.md)

**앱·CFW 0.10.7 베타 · 2026-10-17.** 소프트웨어 검증을 통과했으며 아래 구버전 전환 제한을 포함합니다. 실물 전원 차단·RF 검증 완료를 뜻하지 않습니다.

**전원 유지가 필요한 구간:** 구형 CFW에서 데이터 유지 순정 복귀를 요청하는 도중 상시 전원이 끊기면, 새 복구 코드가 실행되기 전에 부팅이 멈출 수 있습니다. 이 구간은 자동 복구를 보장하지 않습니다. 순정 복귀·재설치가 끝날 때까지 상시 전원을 유지하고 시동 모터를 돌리지 마세요. IGN OFF는 상시 전원 분리가 아닙니다. 이미 멈춘 경우 재부팅만으로 반드시 복구된다고 가정하지 말고 진단 정보와 함께 문의하세요.

## 지원 범위

F4 계열 Noodoe의 **언어팩 B**에서 기기 메뉴를 영어·독일어·스페인어·프랑스어·이탈리아어·그리스어·한국어·베트남어·일본어로 표시합니다. 영어는 기존 문구·Lato 글꼴·배치를 유지하고, 일본어는 새 언어팩 글꼴을 사용합니다.

Android 앱은 위 9개 언어와 중국어 간체·번체를 지원합니다. 앱을 간체·번체로 설정한 상태에서 기기 언어를 ‘앱 언어 따르기’로 두면 기기는 영어를 사용합니다. 중국어 글리프는 음악·알림에 사용할 수 있지만 B의 시스템 언어 선택에는 없습니다.

언어팩 A는 이번 다국어 기능의 지원 범위 밖입니다. 기기는 기존 영어 화면을 유지하며 B용 순정 폰트를 읽지 않습니다. 차종명만으로 A/B를 판단하지 않습니다.

최초 설치의 순정 버전 조건은 **5.14 또는 5.16**입니다. HW 번호·부트로더 버전·모델명·PCBA만으로 차단하지 않지만, 실제 기기 확인·저장소 검사·정차 조건은 그대로 적용합니다. 모든 차종과 하드웨어 리비전의 실기 검증이 끝났다는 뜻은 아닙니다.

## Companion / CFW 0.10.7 설치 흐름

APK와 펌웨어 ZIP을 모두 0.10.7로 갱신하세요. 앱 데이터와 설정은 유지합니다. 0.10 계열은 같은 Gate에서 일반 CFW 업데이트를 사용하고, 0.9 계열은 데이터 유지 순정 복귀 후 재설치합니다.

펌웨어 설치·CFW UPDATE 화면 확인·정상 실행 확정이 끝나면 앱이 **언어팩을 설치할까요?**라고 묻습니다. **설치**를 선택하면 맞는 언어팩을 자동 다운로드·검증·전송하고, **나중에**를 선택하면 영어로 계속 사용할 수 있습니다. 정상 설치된 팩은 재전송하지 않습니다.

이미 설치를 마친 기기는 앱 상단 **기기 언어 · 언어팩 설치 → 주행 연동 중지 → 언어 자원 설치 / 이어가기**에서 시작하세요. 현재 본체와 맞는 0.10.7 펌웨어 ZIP이 선택되어 있어야 합니다. 별도 언어 ZIP을 직접 내려받을 필요는 없습니다. 오프라인 사용을 위한 수동 언어 ZIP 선택은 설치 탭에 남아 있습니다.

언어 전송 중단은 펌웨어 설치 실패가 아닙니다. 같은 기기·ZIP으로 언어팩만 이어가며 순정 복귀나 펌웨어 재설치를 요구하지 않습니다. 배포 파일은 NOODOE-LANGUAGE-B-0.10.7.zip입니다. 내부의 TEXT.PAK에는 9개 언어 문구가 모두, FONTS.PAK에는 공통 글리프와 이모지가 들어 있습니다. 기기에서는 기존 Gate의 중단 복구를 유지하도록 하나의 LANGUAGE.PAK으로 저장합니다. 이미 정상 설치된 내용이 같으면 다시 보낼 필요가 없습니다.

## 완료와 언어 준비

전송 100% 이후에도 파일 검증·저장이 끝나야 합니다. 저장이 확인되면 자동 재시작하며, 앱은 재연결 후 저장된 팩 검사와 메뉴 글꼴 준비까지 진행 상태를 보여줍니다. ‘메뉴 언어 준비 완료’와 ‘영어로 계속 사용’을 구분합니다. 통신이 끊겼다면 같은 기기로 다시 연결해 결과를 확인하세요. 폰 앱의 다른 버튼을 눌러야 언어가 적용되는 절차는 아닙니다.

IGN을 켜거나 꺼도 설치·검증·저장이 계속됩니다. 모듈의 상시 전원은 유지하세요. 실제 이동 속도가 수신되면 기존 정차 제한이 적용됩니다. 언어 변경 후의 기존 재시작 확인 절차는 유지하며, 기기 언어 목록에는 Deutsch·한국어·日本語처럼 각 언어의 이름을 표시합니다.

업데이트로 팩 내용이 달라질 때는 일치하는 기존 블록을 NOR에서 읽어 새 영역으로 복사합니다. 서로 다른 블록만 블루투스로 받고, 새 파일을 검증한 뒤 교체합니다. 기존 파일을 먼저 지우거나 다른 파일을 삭제하지 않습니다.

## 순정 폰트 검사

정상 기기에서는 폰트 복구 선택이 나오지 않습니다. 이번 기능에 필요한 순정 파일의 누락·잘림·구조 오류가 확정됐을 때만 다음 중 하나를 고릅니다.

- **폰트 복구 후 계속:** 검증된 B 백업에서 문제가 있는 파일만 원래 FONT 위치로 복원합니다.
- **영어로 계속:** FONT를 바꾸지 않고 기존 영어 화면과 휴대전화 렌더링을 사용합니다.

파일 해시가 다르거나 특정 문자가 없는 것만으로 복구를 권하지 않습니다. 공간이 부족하거나 저장소 구조가 손상됐다면 다른 파일을 임의로 지우지 않습니다. 영어를 선택해도 설치에 필요한 기본 저장소 검사를 건너뛰지는 않습니다.

## 언어 바꾸기

앱의 **기기 언어**에서 ‘앱 언어 따르기’ 또는 원하는 언어를 고르세요. 기기 설정에서도 바꿀 수 있습니다. 직접 고른 언어는 재연결할 때 앱 언어로 덮어쓰지 않습니다.

현재 표시 언어가 달라지는 선택에는 누도에서 재시작 안내가 나옵니다. 정차한 뒤 확인하세요. **나중에**를 고르면 선택은 저장되고 다음 재시작 때 적용됩니다. 설정과 주행 기록 저장이 끝나기 전에 재시작하지 않으며, 그사이 이동·경고·전원 전환이 시작되면 수락한 재시작도 취소됩니다.

한 번 부팅할 때 한 언어만 준비합니다. 메뉴를 움직이는 동안 언어를 바꾸거나 매 프레임 외장 플래시에서 글자를 읽지 않습니다.

## 음악·알림 글자 표시

**음악·알림 글자 표시**에서 다음 중 하나를 고릅니다. 앱과 기기의 설정은 같은 저장값을 사용합니다.

- **휴대전화에서 렌더링 — 기본값:** 폰이 지원하는 문자와 컬러 이모지를 그대로 사용할 수 있습니다. 그림 준비와 전송에 시간이 걸릴 수 있습니다.
- **기기 글꼴 사용:** 내장 글리프와 언어팩으로 글자를 그려 전송량을 줄입니다. 일부 문자와 조합은 지원하지 않으며, 지원하지 않는 항목은 □로 표시합니다. 새 단색 이모지는 이 모드에서 사용합니다.

음악 페이지·HOME·알림 상세·알림 팝업에 적용합니다. 통화와 빠른 답장의 표시·전송 경로는 기존대로입니다. 이모지의 피부색·국기·가족 같은 지원 조합은 하나의 글리프로 처리하며, 지원하지 않는 조합은 □ 하나로 표시합니다.

## 오류와 복구

**영어 전용**을 켜면 기존 영어 UI와 휴대전화 렌더링을 사용합니다. 이전 언어 선호도는 보관됩니다. 직접 켠 영어 전용은 자원이 복구돼도 자동으로 꺼지지 않습니다.

언어 자원 오류·공간 부족·메모리 확보 실패도 영어 표시로 복귀합니다. 번역이 없는 문구는 영어로, 개별 미지원 문자는 □로 표시합니다. 언어 자원 실패를 펌웨어 설치 실패로 취급하지 않습니다.

설치 화면이 수동 재시작을 요청하면 **UP + O를 함께 3초** 누르고 손을 떼세요. 다시 연결한 뒤 같은 ZIP으로 현재 기기와 설치 결과를 확인하세요. Stage 6/4 자체가 설치 성공이나 벽돌을 뜻하지 않습니다.

Bootstrap에 자동 연결되지 않으면 휴대전화 Bluetooth 설정과 Bootstrap의 수동 메뉴에서 기존 페어링을 지우고 다시 페어링한 뒤 **현재 기기 확인 → 여기서부터 계속하기**를 사용하세요. 앱 데이터를 지워 진행 기록을 없애지는 마세요.

## 글꼴 라이선스

단색 이모지는 해시를 고정한 **Noto Emoji 3.002 Regular 400**에서 생성합니다. OFL 1.1에 따른 저작권·라이선스 고지를 언어 배포물과 앱 라이선스 목록에 포함합니다. 기존 시스템 아이콘은 교체하지 않습니다.
