# 0.9.41 설치 상태와 작업 진단

0.9.40과 버튼 조작은 같습니다. 위+O를 함께 3초 누르면 MCU를 재부팅합니다.
아래+O 퀵 세팅에서 위 길게는 LCD 복구, 아래 길게는 Super Nite입니다.

정상 CFW로 롤백이 확인됐고 실제 기록·확정 작업이 없다면 새 ZIP을 선택할 수
있습니다. 이전 실패 기록은 남습니다. 안내를 O 짧게로 닫는 것은 기록 작업
취소나 설치 확정이 아닙니다. 안내 확인의 저장을 기다리지 않고 화면은 닫힙니다.

앱에서 현재 상태 확인을 실행하면 기기 역할·실행 이미지·부팅 결과와 설치 기록을
대조합니다. 읽기 검사는 대기 5초 / 전체 60초 상한이며, 상세 진단은 작업 소유자,
단계, 차단 이유와 마지막 진전 이후 시간을 구분합니다. 저장 작업 때문에
기다리는 경우를 Bluetooth 인증 실패로 취급하지 않습니다.

상태를 확인하지 못한 작업은 완료로 처리하지 않습니다. 진단 기록을 보존하고
기존 연결 복구 또는 Gate 메뉴를 사용하세요. 응답이 없는 구버전 기기에 새 APK만
설치해도 본체의 입력 코드가 교체되지는 않습니다.

0.9.40 Gate 지원 기기는 일반 Product 업데이트로 진행합니다. 이전 Gate의
명시적인 데이터 유지 이관 절차는 그대로입니다. 같은 릴리스 APK·ZIP을 사용하세요.
