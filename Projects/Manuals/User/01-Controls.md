# 1. 버튼과 공통 화면

## 세 버튼

`UP`은 위, `O`는 가운데, `DOWN`은 아래 버튼입니다. 일반 UI에서 길게 누르기는 **0.8초**입니다. 설치 취소 3초와 순정 복귀 승인 2초는 별도이며 줄어들지 않습니다. 한 번 누른 뒤 놓아야 다음 조작으로 인식합니다.

| 화면 | UP/DOWN 짧게 | O 짧게 | 길게 누르기 |
|---|---|---|---|
| 홈 | 배경 / 날짜 / 큰 속도+날짜 순환 | 다음 주 메뉴 | O: 하단 거리 모드 순환 |
| 트립 | TRIP A/B/TODAY/SINCE REFUEL | 다음 주 메뉴 | O: TRIP A/B 초기화. UP/DOWN: 하단 거리 모드 |
| 휴대전화 | 최근 알림 선택 | 다음 주 메뉴 또는 열린 답장 선택 | O: 가능한 알림의 빠른 답장 |
| 음악 | UP: 재생/일시정지, DOWN: 다음 곡 | 다음 주 메뉴 | UP: 이전 곡 |
| 전화 | 목록 선택 | 다음 주 메뉴 | O: 발신/받기, DOWN: 거절/종료 |
| GPS | UP 확대 / DOWN 축소 | 다음 주 메뉴 | O: 북쪽 위 / 진행 방향 위 전환 |
| 퀵 세팅 | 밝기 또는 자동 보정 조절 | 다음 주 메뉴 | O: 정차 조건 충족 시 전체 설정 |
| 전체 설정 | 항목 이동/값 조절 | 선택·편집·적용 | 모든 메뉴의 Back으로 이전 단계 |

주 메뉴는 **홈 → 트립 → 휴대전화 → 음악 → 전화 → GPS → 퀵 세팅** 순으로 한 방향으로 이동합니다. 수신 전화, 경고, 설정, 설치 화면에서는 해당 화면의 동작이 우선합니다. 음악 페이지의 가운데 버튼 길게 누르기는 현재 한 대 연결 버전에서 휴대폰 전환 기능을 수행하지 않습니다.

## 계기판 조작 스위치

차량의 계기판/Noodoe 선택 스위치가 계기판 쪽이면 일반 CFW 버튼을 막습니다. 왼쪽에 **짙은 파란 원 안의 계기판 아이콘**이 계속 표시됩니다. 버튼을 눌러도 토스트를 반복하지 않습니다. Noodoe 쪽으로 돌린 뒤 누르고 있던 버튼을 놓고 다시 누르세요. 스위치에는 100ms 안정화가 적용됩니다. 긴급 복구·설치 취소는 이 일반 UI 차단과 별개입니다.

## 속도 링과 시계

![큰 속도 홈](../images/home-speed.png)

- 중앙 위 시계는 `HH:MM`. 시계 값과 날짜는 설정에서 바꿀 수 있습니다.
- 외곽 링은 **차량 UART 속도**를 표시합니다. GPS 속도로 대체하지 않습니다.
- 링 범위는 `Ring maximum` 설정입니다. 움직임은 화면 보간으로 부드럽게 보입니다.
- 얇은 노란 막대는 이번 IGN 세션의 최고속도, 낮은 타원은 평균속도입니다. 확정된 새 시동 세션에서 초기화됩니다.
- 최고/평균은 유효한 UART 표본으로 계산합니다. 수신 공백을 정상 정차로 계산하지 않습니다.
- 시동 복귀 시 링이 한 번 차올랐다가 돌아오는 동작은 시작 애니메이션입니다.

## 상단 아이콘과 버튼 힌트

Bluetooth 상태 아이콘은 폰 연결 상태를 나타냅니다. 새 알림은 빨간색 점멸, 미확인 알림은 10분 안쪽 빨간색·그 이후 노란색, 확인 후에는 무채색으로 표현됩니다. 통화 중에는 초록색 전화기 아이콘으로 바뀝니다. 위치 아이콘은 폰 GPS 전송의 활성 상태이며 회색은 비활성입니다.

가운데 아이콘 줄은 현재 주 메뉴를 가운데 크게 표시합니다. 홈에서는 메뉴 전환 후 5초가 지나면 숨습니다. 오른쪽 세 버튼 힌트는 입력 시 나타나고 시간이 지나면 숨으며, 음악·통화에서는 해당 기능을 안내합니다. 점은 짧게, 길쭉한 표시는 길게 누르기를 뜻합니다. 입력 중 파란색, 길게 누르기 도달 시 빨간색 피드백이 보입니다.
