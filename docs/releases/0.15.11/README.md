# NewDoe 0.15.11 beta / Android 160

Install the matching APK over your existing app, then use Device → Check current status to review and install the included firmware. Existing app data and vehicle settings are retained. Do not uninstall the app. The APK contains all supported A/B language variants; the standalone default ZIP is B-English for expert use.

- HOME/MAP share manual/AUTO information. TRIP A/B/F/T is available in the information strip.
- Connected calls take priority in the one-line strip; two-line HOME keeps playing music.
- Song changes update without a page animation. Long toasts scroll and frequent messages are shorter.
- Phone HOME includes a weather summary and forecast link, with the instrument artwork/colors. Navigate includes the map and controls together.
- Manual weather refresh works without a bike connection. Automatic fetching still requires connection; viewing a screen alone does not fetch.
- No-weather state shows a slashed cloud and larger waiting text.

한국어: 기존 앱 위에 APK를 설치하고 기기 → 현재 상태 확인에서 같은 버전의 펌웨어 업데이트를 진행하세요. 앱 삭제나 데이터 초기화는 필요하지 않습니다. MAP은 HOME 정보 설정을 따르고, TRIP 항목·통화 우선 표시·두 줄 음악 고정·긴 토스트 스크롤을 제공합니다. 앱 HOME에 날씨 요약을, 내비게이션 탭에 지도를 추가했습니다. 날씨 수동 갱신은 미연결 중에도 가능하며 자동 조회는 연결 조건을 유지합니다.

See the included Korean/English illustrated manual for controls, API setup and offline map/navigation setup. All weather examples use test data; verification is software-only. Physical LCD, Bluetooth and power-loss testing were not performed. Gate and NOR layout are unchanged. The legacy stock-return power-interruption limitation remains; it is not claimed fixed. Google Play signing migration is separate from this APK release.
