# AK550: Noodoe–차량 계기판의 3개 CN 관측과 기능 분류

> **2026-09-11 갱신:** 사용자가 12V 두 접점 중 하나를 IGN으로 식별해 ON/OFF 문제를 해결했다. 또한 사용자가 현재 **CN3이라 부르는 6핀 커넥터**의 1번에서 리셋 계통 반응을 확인했다. 아래 과거 문서의 임시 명칭은 6핀=CN1이므로 번호 혼동에 주의한다. [새 관측·번호 대응·리셋 후보 기록](2026-09-11-ign-cn3-reset-candidate.md).

2026-09-10. 사용자가 구입한 2017 AK550 차량 계기판과 별도 Noodoe 모듈 사이 연결부를 조사했다. 최신 보고는 6핀 CN, 가로 14핀 CN, 세로 14핀 CN의 전압과 버튼 반응이다. 이는 사용자의 실물 관측이며 분석 도구가 직접 측정한 결과는 아니다. 아래 CN1/2/3은 사용자의 설명 순서이며, PCB 실크의 공식 커넥터 번호와 일치하는지는 별도이다.

## 최신 구성: 전원과 UART 외에 버튼 신호 존재

| 사용자 명칭 | 핀 수/배치 | 직접 보고한 관측 | 현재 분류 |
|---|---|---|---|
| CN1 | 6핀 | 계기판–Noodoe 연결 시 4핀에서 3.3V. Noodoe 분리 후 계기판 쪽 해당 핀들은 0V | Noodoe 연결 여부에 의존하는 3.3V 노드. 전원인지 풀업된 신호인지 미확인 |
| CN2 | 가로 배치 14핀 | 모든 핀에서 0V | 측정 조건에서 LOW/0V인 핀들. 기구용·더미 판정 보류 |
| CN3 | 세로 배치 14핀 | 12V 라인 2개, 5V 상태에서 버튼을 누르면 LOW가 되는 선 3개, 5V UART 115200/8N1 | 주 연결부. 12V 라인, **액티브 로우 버튼 관련 신호 3개**, UART |

이전의 **'12V/5V/3.3V 전원과 UART뿐이며 다른 신호가 없다'는 분류는 최신 버튼 관측으로 수정한다.** 버튼에 연동하는 5V 세 선은 전원 레일로 취급하지 않는다. 전원처럼 보이는 정적 전압이 실제로는 풀업된 신호의 유휴 레벨일 수 있다.

CN1에서 분리 후 계기판 측 3.3V가 사라진 것은 연결 상태에 의존한다는 근거다. Noodoe 쪽에서 전원 또는 풀업이 공급되는 구조와 맞지만, 분리로 인한 기동 조건 변화도 가능하므로 생성 위치나 공급 방향을 확정하지 않는다. 4핀이 동일 전원 네트라는 증거도 아니다.

CN2의 전부 0V는 GND, 풀다운된 입력, LOW 출력, 미활성 신호 등의 상태와 구분되지 않는다. 기구적 지지용 접점이라는 결론에는 전원 OFF 상태의 GND 연속성·실제 PCB 패턴 추적 같은 별도 근거가 필요하다. GND에 연결돼 있어도 그것만으로 기구적 역할만 한다고 단정하지 않는다.

CN3의 세 선은 버튼 동작에 따른 active-low 상태가 확인됐다. 각각의 버튼 이름, 한 버튼당 한 선인지, 물리 접점인지 다른 회로의 출력인지, 어느 보드가 풀업하거나 읽는지, STM32 GPIO에 직접 연결되는지는 미확인이다. 같은 5V 레벨이라는 이유로 UART와 같은 네트라고 보지 않는다. 12V 두 선도 서로 동일 네트인지, 어느 쪽이 공급하는지, 허용 부하는 별도이다.

공통 GND는 앞선 벤치 측정·UART 수신 과정에서 사용됐다. 각 GND 접점의 개수·위치는 이번 보고에 제시되지 않았다.

사용자가 확보한 세 CN의 구분과 핀 동작 관측을 현재 정보로 반영한다. 각 접점의 실제 번호와 관찰 방향은 이 문서에 아직 수록되지 않았다. 물리 위치 파악과 각 핀의 전기적 역할 확정은 구분하며, 나머지 핀의 기능·공식 번호를 추측해서 채우지 않는다.

## 기존 UART 검증과의 결합

**후속 IGN 비교 조건:** 사용자가 Noodoe를 분리한 계기판측 모든 접점을 IGN ON/OFF로 비교했으며, 전압 변화가 없고 12V 두 선도 OFF에서 공급이 유지됐다고 보고했다. 원래 연결 상태에서는 계기판을 끄면 Noodoe도 꺼졌다. 분리 측정에는 Noodoe 측 풀업·부하·연결 상호작용이 빠지므로, 이 결과만으로 연결 상태의 IGN 관련 신호 부재를 판정하지 않는다. 현재의 독립 전원 구동과도 다른 시험 조건이다. 연결 상태 전압·전환 파형·UART 연속 캡처는 아직 미확인이다. [전원 상태 분석의 후속 관측](2026-09-10-noodoe-power-state-and-sleep.md).

사용자가 앞서 붙인 파일/위치 명칭 기준:

| 기존 명칭 | 확인한 기능 | 근거 |
|---|---|---|
| UPPERPIN | Noodoe TX → 차량 계기판 RX | 정상 A1 송신 프레임과 V5.16 코드 |
| LOWERPIN | 차량 계기판 TX → Noodoe RX | 정상 21 프레임, 실물 ODO·연료 표시 대조 |

UART 조건은 **115200 baud, 8N1**이다. 위 UPPER/LOWER 명칭을 새 커넥터의 공식 번호나 특정 관찰 방향으로 임의 변환하지 않는다. 그 대응은 사용자의 완성된 핀맵을 받아 기록한다.

## 연구에 반영할 결정

1. 이 연결부에는 **전원 관련 노드, 액티브 로우 버튼 신호, UART**가 있다. 차량 상태와 버튼 입력을 모두 UART만으로 처리한다고 가정하지 않는다. 기존 UART의 CMD01이 버튼 비트라는 근거도 이번 관측만으로 생기지 않는다.
2. **이전의 커넥터 내 SWD/JTAG 탐색 우선순위 하향 판단을 철회한다.** 이번 상세 근거는 정적 전압과 버튼 반응이므로, 분류되지 않은 CN1/CN2 핀에서 디버그 기능을 배제하지 못한다. 반대로 6핀이라는 모양이나 전압만으로 CN1을 SWD 커넥터라고 지정하지도 않는다. 식별된 MCU 디버그 핀과의 실제 연결을 추적해야 한다.
3. SPEED·FUEL 등 차량-계기판 하네스 입력과 계기판-Noodoe 연결부는 구분한다. 온도 TEMP 입력은 앞선 UART 무반응 관측에 따라 활용 보류 상태를 유지한다.
4. Noodoe 단독 구동 전원은 전압이 관측됐다는 이유로 모두 외부 공급하지 않는다. 특히 CN3의 버튼 선은 상태 신호다. 공급 방향과 활성 조건을 구분해 전원 구성을 정한다.

SWD 정적 전압 해석의 1차 근거: STM32F429 계열이 포함된 [ST RM0090 §8.3.1](https://www.st.com.cn/resource/en/reference_manual/rm0090-stm32f405415-stm32f407417-stm32f427437-and-stm32f429439-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)은 리셋 후 PA13/SWDIO의 pull-up, PA14/SWCLK의 pull-down 상태를 설명한다. **정지 상태의 HIGH/LOW가 전원/더미라는 증거는 아니라는 예시**이며, 해당 CN 핀과 PA13/PA14가 이어진다는 증명은 아니다. 실제 칩 형번·패키지의 다리 번호는 여전히 별도 확인 사항이다.

이 결과는 해당 AK550 세트의 조사 기록이다. 다른 연식·모델 전체에 같은 물리 핀맵을 자동 적용하지 않는다.
