# Noodoe Companion / CFW 6.3

기기 미설치 후보. OpenNoodoe 원본, 순정 BL, RecoveryGate, Bootstrap 바이너리를 변경하지 않았다. 실제 연결된 Android 기기 없음. 이 기록의 시험은 ARM 코드 모의실행·Android Robolectric/Skia·빌드·패키지 검사이며 실차 RF/버튼/주행 성공을 뜻하지 않는다.

## 설치와 사용

1. `NoodoeCompanion-6.3.apk`로 기존 설치 포크 앱을 업데이트한다(동일 패키지/서명, versionCode2). 앱의 **주행 연동 → 빠른 답장과 문자 표시**에서 최대5문구, 서명, 폰 이름, 일본어/대만 번체 지역을 설정한다. 알림 접근 권한과 허용 앱을 설정한다.
2. 이미 CFW인 기기는 `vehicle015-final/installer.zip`을 선택하고 **새 CFW로 업데이트 / 전송 이어가기**를 사용한다. 기존60초 정상실행/앱확인·실패롤백을 유지한다. 확인되지 않은 COMMIT을 다시 보내지 않는다.
3. Bootstrap인 기기는 실행 중 Bootstrap과 원래 설치 ZIP의 SHA 일치가 필요하다. 이번 ZIP은 이전 installer-flow Bootstrap을 그대로 포함한다. 불일치하면 검사를 우회하지 않는다.
4. 정상 업데이트 확정 시 기존 정책대로 CFW 환경설정·CFW사진 슬롯이 초기화된다. 사진3슬롯 전송은 그대로 제공한다. 순정 앨범/주행누계/정비/페어링·복구 기록은 이 변경에서 삭제하지 않는다.
5. 폰 화면은 처음에 배터리·폰 아이콘/이름만 보인다. 위/아래로 최대10개 알림을 연다. O 길게 → 답장 선택 → O 짧게 전송, Back으로 취소한다. Android RemoteInput을 제공하는 알림만 답장할 수 있다. 기본 서명은 `Sent from my Noodoe dashboard.`이며 수정/비우기가 가능하다.

## 구현

- 일본/대만 Noto Sans CJK를 APK에 포함했다. 음악 제목·아티스트, 알림 앱명·제목·본문·폰 이름·빠른 답장을 폰에서 렌더링한다. 제목은 굵고 크게, 본문은 최대2줄, 영역 안에서 줄임표 처리한다. 스크롤 없이 실제 글꼴 높이까지 맞춘다. Google Material Round 배터리/폰 아이콘, 각 앱의 실제 알림 작은 아이콘을 사용한다.
- CJK 지역 auto/jp/tc, 이름 변경은 연동 재시작 후 적용한다. JP/TC 각44,810 codepoint cmap. JIS X0208 기반 EUC-JP 검사 한자6,356개, Big5 검사 한자13,063개 모두 누락0. 비한자4종의 Android fallback도 별도 시험한다. **CNS11643 전체의 희귀/인명 확장·PUA·모든 IVS 지원을 검증한 것은 아니다.** 검증 범위는 `font-coverage.json`이다.
- 두 OTF 합32,903,620B는 폰에만 저장한다. MCU에는 새 한자 폰트 전체를 넣지 않는다. 참고로44,810글자를32px 정사각4bpp로 저장하면 한 크기/한 형태만21.88MiB(메트릭·패딩 제외),JP/TC 두 형태43.76MiB다. 현재는 표시용18KiB 패널만 SPP로 전송한다.
- 알림 최대10개, 본문1,024/제목256 UTF-16 code unit 상한, 삭제된 알림은 읽기만 가능. 읽던 알림은ID로 고정해 새 알림이 오더라도 다른 수신자로 답장하지 않는다. 답장 ID/revision/config/epoch 및 실제 Android 활성 알림 재검사를 거친다. intent는 보내기 전 디스크에 기록한다. ACK 유실 시 자동 재전송하지 않는다. 결과는 ‘메시지 앱에 전달’, 상대방 수신 확인이 아니다.
- GPS 최신 위치를 중앙에 고정하고 궤적을 그린다. 마지막 이동 방향으로 화살표를 표시한다. 시동 세션 시작에서 초기화하고 일시적인 연결 공백은 보존한다. UART 속도는 GPS로 대체하지 않는다.
- 음악 버튼과 사진3슬롯 전송은 유지했다. 독립 휴대폰 원격 조작 메뉴는 다시 추가하지 않았다.

힙·스택·큐 또는 기존 예산 기준을 줄이지 않았다. 폰 패널13개는 고정 SDRAM239,616B, 화면에 쓰는 두 마스크는36,864B이며 음악과 재사용한다. 전환 중 GPU가 참조 중인 버퍼는 swap 완료 후에만 갱신한다.

GPU 캐시112KiB. 제공 Lato/D-DIN 전체 글리프+모든 아이콘+두 패널 및 정렬 상한109,766B →4,922B 여유. 원본480×480 RGB565 사진 두 bank 유지. 캡처를480×8행/7,680B stripe로 변경해 사진/폰트/캡처 비중첩을 유지한다. 완성본은 SDRAM에서 다운로드하고2초 취소/IGN/소유권 반환 정책을 유지한다. 캡처 실제 기기 소요시간은 미계측이다.

`verification-summary.json`에 시험수·최종 SHA·ELF 예산·원본 시험 결과를 고정한다. 알림10개/업데이트/삭제·실제 RemoteInput envelope·서명·오래된 답장 거절·중복 명령·CRC/epoch·고정 캐시 보존·텍스처 fence·1,000회 탐색·GPS 중앙/날짜변경선·캡처60stripe 조립/취소/timeout·음악 제어·기존 프로토콜/설치 시험을 수행했다. 실제 Android Canvas/StaticLayout/Skia 렌더 결과는 `preview/`에 있다. 누도 화면 캡처는 아니다.

최종ZIP은 실제 Android production importer와 확보한 실차0.15 식별값 대조를 통과했다. 순정 BL0.15 자체의 물리 중단 복구를 새로 검증한 것으로 해석하지 않는다. Gate/Bootstrap은 이전과 바이트 동일하다. 자산ID도 기존과 동일하여 일상 APP 업데이트 경로를 유지한다.

아직 이번 버전으로 실기기 무선·Android 실제 메시지 앱·백그라운드 GPS·장시간 부하·29fps 검증을 하지 않았다. 라이더 이름 CFWTEXT 영구 문자 캐시, CDM 자동 서비스 시작, 새 Gate/자산을 교체하는 일상 업데이트는 기존 미완료 범위로 남는다. 이번 폰 화면 변경을 과거 전체 컴패니언 계획 완료로 보고하지 않는다.

라이선스 원문은 APK 안의 Noto SIL OFL와 Material Apache2.0 메뉴에서 확인할 수 있다. 원본 출처/해시는 `font-coverage.json`, `icons.json`을 따른다.
