# NewDoe 사용·설치 설명서

**현재 기준: 앱·기기 펌웨어 0.11.15 / B 언어 자원 0.11.2 · 2026-10-19 개정**
[English](Guide.en.md) · [다운로드](https://github.com/SerialSniffyHeck3r/noodoe_cfw/releases/latest)

이 설명서는 전자공학 지식 없이 Android 휴대폰과 차량 버튼으로 진행하는 사람을 위한 것입니다. 정상 설치에는 분해, 납땜, ST-Link가 필요하지 않습니다. 문서에 나오는 **[폰]**은 휴대폰 화면, **[누도]**는 차량의 동그란 Noodoe 화면과 버튼을 뜻합니다. 순정·설치·복구 화면은 영어이므로 실제 영어 문구도 함께 적었습니다.

## 1. 내 기기에 설치할 수 있나요?

| 확인할 것 | 현재 지원 범위 |
|---|---|
| 휴대폰 | Android 6.0 이상. iPhone용 앱은 없습니다. |
| 본체 | STM32F4 계열 KYMCO Noodoe. MCU 이름을 직접 알아낼 필요는 없으며 앱의 현재 상태 확인으로 시작하세요. |
| 순정에서 최초 설치 | 순정 펌웨어 **5.14 또는 5.16**. 다른 버전의 검사를 억지로 우회하지 마세요. |
| 차량 이름 | AK550 전용으로 차단하지 않습니다. 모델명·PCBA·HW 번호·순정 부트로더 버전의 화이트리스트는 없습니다. |
| 이미 NewDoe/이전 CFW 사용 중 | 순정 버전 조건을 CFW 번호에 적용하지 않습니다. [CFW 업데이트](#update)로 진행합니다. |
| 기기 메뉴의 다국어 | 순정 언어팩 **B**만 지원합니다. A는 이번 범위에서 영어 메뉴를 유지합니다. 앱이 실제 자원을 확인하므로 국가나 차량명으로 추측하지 마세요. |

**설치가 허용되는 것과 모든 차종에서 시험을 마친 것은 다릅니다.** 다른 차량의 배선·계기판 데이터 차이로 속도·ODO·버튼 전환이 다를 수 있습니다. AK550 사용 경험을 모든 F4 리비전의 보증으로 보지 마세요. 설치 검사를 통과하지 못하면 오류를 기록하고 문의하세요.

5.14에서 설치했더라도 **순정 복귀에는 동봉된 5.16 펌웨어**가 사용됩니다. 설치기가 내 기기의 원래 5.14 전체를 복제해 두는 것은 아닙니다.

## 2. 버튼과 용어부터 알아보기

| 표시 | 뜻 |
|---|---|
| UP / 위 | 차량의 위 버튼 |
| O / OK | 가운데 확인 버튼. 숫자 0이 아닙니다. |
| DOWN / 아래 | 차량의 아래 버튼 |
| 짧게 누르기 | 눌렀다가 바로 놓기 |
| 길게 누르기 | 일반 화면은 약 0.8초. 설치·복구에서 2초 또는 3초가 나오면 그 안내를 따릅니다. |
| IGN ON | 차량 키/전원 스위치를 ON으로 하기. **시동 모터를 돌리라는 뜻이 아닙니다.** |
| IGN OFF | 키/전원 스위치를 OFF로 하기. 누도에는 별도의 상시 전원이 남을 수 있습니다. |
| 순정 / Stock | KYMCO 원래 펌웨어 |
| Bootstrap | 순정에서 새 CFW를 설치할 때 잠시 실행되는 설치 도구 |
| CFW / Product | 평소 사용하는 NewDoe 본체 펌웨어 |
| Gate / Recovery | 본체 시작 검사와 복구 메뉴. **Bluetooth 연결 기능은 없습니다.** |
| APK | 휴대폰에 설치하는 앱 파일 |
| CFW ZIP | 앱이 누도로 보내는 펌웨어 설치 묶음 |
| 언어 ZIP | 번역·글꼴·단색 이모지 자원. CFW ZIP과 다른 파일입니다. |

누도/일반 계기판을 고르는 스위치가 있는 차량은 **누도 쪽**으로 두세요. 버튼을 누른 채 다음 화면으로 넘어갔다면 먼저 모두 놓고 새로 누릅니다. 위와 아래를 동시에 누르라는 조작은 없습니다.

## 3. 받을 파일과 설치 전 준비

### 파일 세 가지를 구분하세요

[공식 Latest 다운로드 페이지](https://github.com/SerialSniffyHeck3r/noodoe_cfw/releases/latest)를 휴대폰으로 엽니다. 이 설명서의 기준 파일은 다음과 같습니다.

| 파일 | 언제 필요하나요? |
|---|---|
| `NewDoe-0.11.15-manual-r2.apk` | 휴대폰 앱. 설명서 개정 APK도 본체 0.11.15와 사용합니다. |
| `NewDoe-CFW-0.11.15.zip` | 본체를 새로 설치하거나 0.11.15로 업데이트할 때 |
| `NewDoe-LANGUAGE-B-0.11.2.zip` | B 기기의 다국어 자원이 없거나 이전 자원을 갱신할 때. **0.11.2라는 파일명이 맞습니다.** |

언어팩은 앱에서 내려받는 경로도 제공합니다. 수동 가져오기를 쓰려면 위 ZIP을 받아 두세요. 라이선스·검증 보고서·relink 파일은 일반 설치에서 선택할 파일이 아닙니다. **ZIP을 풀거나 안의 BIN 파일을 직접 고르지 마세요.** APK만 설치하면 누도 본체의 버전은 바뀌지 않습니다.

### 설치를 시작하기 전에

1. 주행을 끝내고 안전하게 주차합니다. 설치 중에는 이동하지 않습니다.
2. 차량 배터리가 정상이고 휴대폰에 충분한 배터리가 있는지 확인합니다. 이미 심하게 방전됐거나 전원이 불안정하면 먼저 충전·점검을 받으세요. 설치 중 스타터를 돌리거나 배터리·누도 전선을 분리하지 않습니다.
3. 휴대폰 Bluetooth를 켜고 차량 가까이에 둡니다. 설치 중에는 NewDoe 앱을 앞에 띄워 두고 카메라·다른 Bluetooth 앱으로 전환하지 않는 편이 좋습니다. 카메라 실행 시 끊김은 실차에서 해결 여부를 아직 확인하지 못했습니다.
4. 이미 앱을 쓰고 있다면 새 APK를 **기존 앱 위에 설치**합니다. 앱 삭제·데이터 삭제는 하지 않습니다. 설치 기록과 백업이 이어가기에 필요합니다.
5. Android가 이 출처의 앱 설치를 묻는 경우, 직접 받은 공식 APK인지 확인하고 허용합니다. 메뉴 이름은 휴대폰마다 다릅니다. 설치 후 NewDoe를 엽니다.
6. **[폰] 권한·연동 준비**에서 Bluetooth/주변 기기 등 앱이 요구하는 연결 권한을 허용합니다. 음악·전화·GPS 권한은 [설치 뒤 설정](#phone)에서 구분해 설명합니다.
7. 다른 앱이 누도에 연결 중이라면 그 연결을 종료합니다. 정상 연결 중인 기기의 페어링을 미리 지울 필요는 없습니다.

처음 페어링이 필요하면 **[폰] 새 기기 페어링 / 누도 페어링하기**로 Android Bluetooth 설정을 엽니다. 순정 본체에서는 차량의 순정 안내에 따라 페어링 대기를 켜고 해당 Noodoe를 선택합니다. 이름만 같다고 옆 차량을 고르지 말고 주소 끝자리도 확인하세요. 이미 등록된 내 누도라면 다시 등록하지 않습니다.

**시간은 고정된 몇 분으로 보장하지 않습니다.** Bluetooth·저장소 상태에 따라 다릅니다. 진행률이 천천히 움직이는 것과 오류 화면이 뜬 것은 다릅니다.

## 4. 순정에서 처음 설치하기

전체 순서는 **폰 앱 준비 → 순정 확인 → Bootstrap 전송 → 본체 메뉴 확인 → CFW 준비·설치 → 새 CFW 화면 확인 → 선택적으로 언어팩 설치**입니다.

### 4-1. 내 누도와 설치 파일 고르기

1. **[누도]** IGN ON으로 화면을 켭니다. 엔진은 걸지 않습니다.
2. **[폰]** 앱의 기기 목록에서 내 누도를 선택합니다. 안 보이면 Android에서 페어링한 뒤 **기기 목록 새로고침**을 누릅니다.
3. **[폰] 현재 상태 확인** 또는 **현재 기기 확인**을 누릅니다. 앱이 순정이라고 확인하는지 봅니다. 기기 확인은 펌웨어 설치가 아닙니다.
4. **[폰] 설치 ZIP 선택** 안내에서 `NewDoe-CFW-0.11.15.zip`을 고릅니다. 언어 ZIP이 아닙니다. 파일 선택 창에서 다운로드한 위치를 열고 ZIP 자체를 누릅니다.
5. 순정에서 설치하는 버튼을 누릅니다. 앱이 기기 정보와 설치 조건을 확인한 뒤 Bootstrap 전송을 시작합니다. 호환성 오류가 뜨면 이 단계에서 멈추고 [문제 해결](#troubleshooting)을 봅니다.

### 4-2. Bootstrap이 실제로 켜질 때까지 기다리기

1. **[폰]** Bootstrap 전송·검증이 끝났다는 안내를 기다립니다. 전송 중에 미리 키를 끄지 않습니다.
2. **[누도]** 순정 화면과 앱이 안내할 때 IGN OFF로 합니다. **배터리나 누도 전선을 빼지 않습니다.**
3. 순정의 **NOODOE INSTALLER** 같은 설치 화면은 아직 기록 중일 수 있습니다. 버튼을 반복하거나 완료했다고 판단하지 말고 기다립니다.
4. **NewDoe Bootstrap 메뉴가 실제로 나타난 뒤 IGN ON**으로 합니다.
5. **[폰] 현재 상태 확인**을 누릅니다. 이 구간은 앱이 알아서 재연결할 때까지 기다리는 절차가 아닙니다. Bootstrap 파일을 다시 보내지 않습니다.

### 4-3. 본체에서 설치 시작하기

1. **[누도]** UP/DOWN으로 **Install CFW**를 선택하고 O를 누릅니다. 앱이 선택을 기다리는 경우 이 본체 조작이 필요합니다.
2. **Reset Bluetooth?**가 나오면 정상 연결을 유지하려는 경우 **기본 선택 No → O**입니다. 이 질문에는 자동 선택 시간이 없습니다.
3. **Yes**는 실제로 저장된 페어링을 지웁니다. 연결 문제 때문에 직접 초기화하려는 경우에만 선택하고 [양쪽 재페어링 순서](#connection)를 따릅니다. 정상 설치에서 무조건 Yes를 누르지 마세요.
4. **[폰]** 준비가 확인되면 같은 연결에서 검사·설치를 이어갑니다. 정상 경로에서 옛 설명서의 ‘세 번째 앱 버튼’을 추가로 찾을 필요는 없습니다. 문제 해결 화면으로 들어갔다면 그 화면의 **마지막 작업 상태 조회 → 검사 후 설치 이어가기**를 따릅니다.
5. 이전 CFW 데이터가 발견되어 복원 여부를 물으면, 기존 설정·트립·사진을 유지하려는 사람은 **저장된 데이터 복구 / 보관 데이터 복원**을 고릅니다. **새로 시작**은 기존 CFW 환경을 초기화하려는 경우입니다. 첫 설치에서 복원할 데이터가 없으면 이 선택이 나오지 않을 수 있습니다.

### 4-4. 두 진행 막대가 움직이는 동안

앱과 본체가 저장소 검사, 원본 정보 보관, 순정 복구본 준비, CFW·자원 기록과 검증을 수행합니다. 본체 설치 화면에는 **전체 진행과 현재 작업의 막대 두 개**가 표시되며 퍼센트 숫자는 표시하지 않습니다. 현재 막대는 다음 작업으로 넘어가면 다시 시작할 수 있습니다. 전체 막대는 전체 작업을 나타냅니다.

이 단계에서 하는 일은 ‘내 기기의 모든 데이터를 통째로 폰에 백업’하는 것이 아닙니다. 설치에 필요한 원본 정보와 변경할 저장소 기록을 보관하고, 순정 복구용 펌웨어를 본체에 준비합니다. 별도 전체 NOR 백업과는 다릅니다.

- 진행 중에는 IGN을 임의로 반복 조작하지 말고 화면 안내를 따르세요. Bootstrap에서 IGN OFF 자체가 설치 취소는 아닙니다.
- 오류가 없는데 오래 걸린다는 이유만으로 강제 재시작하지 마세요.
- 취소하려면 설치 화면의 안내에 따라 O를 놓았다가 새로 3초 유지합니다. 기록을 안전하게 멈출 수 있는 지점까지 기다리며, 이미 확정된 설치를 되돌리는 버튼은 아닙니다.

### 4-5. 마지막 INSTALL CFW? 확인

모든 준비가 끝나면 **Everything’s ready / INSTALL CFW?**와 가로로 놓인 **Back / Install CFW**가 나옵니다. 앞의 메인 메뉴에서 설치를 시작한 것과 별개의 최종 확인입니다.

- 바로 진행: **Install CFW** 선택 → O.
- 자동 진행: 아무 조작이 없으면 **30초 뒤 설치**를 선택합니다.
- 멈추고 돌아가기: UP/DOWN으로 카운트다운을 멈춘 뒤 **Back → O**.

이 30초 자동 진행은 **Reset Bluetooth? 질문에 적용되지 않습니다.** 연결·검증 오류를 자동 승인하는 기능도 아닙니다.

### 4-6. 재시작과 새 화면 확인 — 꼭 해야 합니다

1. **[누도]** 설치와 재시작을 기다립니다. Bluetooth가 잠시 끊기고 Gate의 **UPDATING SYSTEM...** 또는 **SYSTEM STARTUP...**이 보일 수 있습니다. 이것만으로 완료한 것은 아닙니다.
2. **[폰]** 설치 앱을 유지합니다. 앱이 새 CFW로 다시 연결하고 화면 확인을 요청합니다.
3. **[누도] CFW UPDATE 화면이 실제로 보이는지 확인합니다.** Bootstrap 메뉴·NOODOE INSTALLER·검은 화면을 보고 확인 버튼을 누르지 마세요.
4. **[폰] CFW UPDATE 화면을 확인했다는 버튼**을 누릅니다. 팝업을 닫은 것만으로는 확인되지 않습니다. 팝업을 놓쳤다면 진행 화면의 확인 버튼을 찾습니다.
5. 앱이 **정상 실행과 설치 확정 완료**를 표시할 때까지 기다립니다. 새 버전의 시험 부팅에는 최대 5분의 확인 기한이 있으며, 이전 버전이 실행 중이면 그 버전의 기한을 따릅니다. 화면 확인 후에도 실제 연결·정상 동작 확인이 이어집니다.

기한 안에 확인하지 못하면 이전 CFW로 돌아가거나, 이전 정상본이 없는 첫 설치에서는 복구 메뉴로 갈 수 있습니다. 이는 언어팩 전송을 기다리는 시간이 아닙니다. **CFW 확정을 먼저 끝내세요.**

### 4-7. 언어팩 선택과 설치 완료 기준

정상 CFW 확정 후 앱이 언어 자원 설치 여부를 묻습니다. B 기기에서 한국어 등 메뉴를 쓰려면 설치를 선택하고 [6절](#language)을 따릅니다. **나중에**를 선택해도 펌웨어 설치는 완료이며, 언어팩이 없는 상태에서는 영어로 사용할 수 있습니다.

마지막으로 앱의 버전·기기 상태를 확인하고 HOME이 열리는지 봅니다. 정차 중 차량 속도 0은 정상일 수 있지만 `------`나 미수신 표시는 숫자 0과 다릅니다. ODO·버튼·연결이 이상하면 무리해서 주행 시험하지 말고 내용을 기록합니다.


### Bootstrap의 다른 화면

처음 들어갈 때 **Checking install files**와 가로 로딩 막대 하나가 나옵니다. 이후 메뉴는 **Bluetooth test / Install CFW / Back to stock / Help / Developer's message**입니다. Ambient Sensor는 제거됐습니다. UP/DOWN으로 선택하고 O로 엽니다. 개발자 메시지는 UP/DOWN으로 스크롤하고 O로 돌아오며, 읽지 않아도 설치할 수 있습니다. 설치가 시작되면 두 막대의 설치 화면이 진행을 담당하므로 처음 파일 검사 화면과 번갈아 나타나는 것이 정상 절차는 아닙니다.

## 5. 이미 CFW를 쓰는 사람의 업데이트

### 내 경로 고르기

| 현재 본체 | 0.11.15로 가는 경로 |
|---|---|
| 일반적인 0.11.4~0.11.15, 설치 ZIP과 Gate가 일치 | **CFW 업데이트 / 이어가기**. 순정 복귀 불필요. |
| 0.9.x, 0.10.x, 0.11.0~0.11.3 등 이전 Gate | **CFW 데이터 유지 순정 복귀 → 순정 확인 → 새 ZIP 재설치**. |
| 버전이나 Gate가 불명확 | 앱의 현재 기기 확인과 ZIP 비교 결과를 따릅니다. 버전 숫자만으로 검사를 우회하지 않습니다. |

Gate는 시작·복구 담당 코드입니다. 새 Product 업데이트만으로 Gate를 바꾸지 않습니다. Bootstrap도 일반 CFW 업데이트로 교체하는 상주 앱이 아니며, **순정에서 설치할 때 선택한 ZIP**의 설치 도구가 실행됩니다.

### 같은 Gate의 일반 업데이트

1. 새 APK를 기존 앱 위에 설치합니다. 앱 데이터는 유지합니다.
2. 차량을 세우고 앱의 상단 **일시정지** 또는 **주행 연동 중지 · 업데이트 준비**로 주행 연결을 중지합니다.
3. **[폰] 설치·현재 상태 페이지**에서 내 기기와 `NewDoe-CFW-0.11.15.zip`을 선택합니다.
4. **CFW 업데이트 / 이어가기**를 누릅니다. 설정 보관·전송·검증·설치·재시작을 기다립니다. 오류를 없애려고 다른 ZIP을 번갈아 선택하지 않습니다.
5. [4-6절](#first-install)의 **실제 CFW UPDATE 화면 확인 → 정상 실행 확정**까지 마칩니다.
6. 언어팩 안내가 나오면 현재 팩 상태에 따라 선택합니다. **정상인 B 0.11.2 팩은 펌웨어 번호가 달라졌다는 이유만으로 다시 보낼 필요가 없습니다.**

일반 업데이트는 설정·밝기·사진·TRIP A/B·오늘/이번 주행·오일/벨트/정비 기록을 유지합니다. 오래된 ODO 보정 기능은 제거됐으며 보정 기록을 다시 적용하지 않습니다. 통신이 끊겼다면 같은 기기·같은 ZIP으로 결과를 확인하고 보관된 설정 복원을 끝내세요.

### 이전 Gate에서 넘어오기

1. 새 APK와 ZIP을 준비하고 **CFW 데이터 유지**를 선택해 순정으로 돌아갑니다. **완전 삭제**를 고르지 않습니다.
2. 본체가 실제 순정 화면으로 돌아온 뒤 **[폰] 본체에서 순정으로 돌아왔어요 · 확인** 또는 **현재 기기 확인**으로 순정을 확인합니다.
3. 같은 새 ZIP으로 [순정 최초 설치](#first-install)를 진행합니다.
4. 보관 데이터가 발견되면 **보관 데이터 복원**을 선택합니다.
5. 새 CFW 실행 확정 후 필요한 언어 자원을 설치합니다.

**구형 Gate의 순정 복귀 요청 기록 중 상시 전원이 끊기는 구간에는 자동 복구 한계가 있습니다.** 새 Gate가 실행되기 전의 옛 코드이므로 새 APK로 소급해서 고칠 수 없습니다. 이미 신형 Gate가 설치된 기기에는 미완성 기록 복구 처리가 있지만, 이것이 모든 전원 차단 상황의 실기 보증이라는 뜻은 아닙니다. 어느 경로든 복귀·설치 중 상시 전원을 유지하고 스타터를 조작하지 마세요.

## 6. 언어팩 설치와 언어 변경

### 무엇이 바뀌나요?

B 기기 메뉴는 **English / Deutsch / Español / Français / Italiano / Ελληνικά / 한국어 / Tiếng Việt / 日本語** 9개 언어입니다. 앱은 여기에 중국어 간체·번체를 더해 11개 언어를 지원합니다. 앱 언어를 중국어로 두고 본체가 앱 언어를 따르도록 하면 본체 메뉴는 영어로 표시됩니다. 중국어 글자는 음악·알림 등의 내용에 사용할 수 있습니다.

영어 메뉴는 기존 Lato 글꼴·배치를 유지합니다. B의 비영어 메뉴는 순정 글꼴을 재사용하고 일본어는 추가 글꼴을 사용합니다. 모든 지원 메뉴 번역과 공통 글꼴을 설치하며, 언어를 바꿀 때마다 파일을 새로 보낼 필요는 없습니다. 순정 언어팩 A는 영어 메뉴를 유지합니다.

### 처음 언어 자원 설치하기 / 이전 팩 갱신하기

1. **펌웨어 정상 실행 확정을 먼저 끝냅니다.** 펌웨어 설치 뒤 자동으로 나온 언어팩 질문에서 설치를 선택하거나, 나중에 앱의 **기기 언어 · 언어팩 설치 → 언어 자원 설치 / 이어가기**를 엽니다.
2. 앱의 다운로드 안내를 따릅니다. 수동 파일 선택을 쓰면 **언어 자원 ZIP 가져오기**에서 `NewDoe-LANGUAGE-B-0.11.2.zip`을 고릅니다. CFW ZIP을 고르지 않습니다.
3. 앱이 실제 기기·언어팩 상태를 읽습니다. 같은 정상 팩이 있으면 재전송 없이 상태를 확인할 수 있습니다. 이전 팩이면 갱신 여부를 묻습니다. **나중에**는 현재 팩과 언어 선호도를 유지합니다.
4. 필요한 순정 FONT 파일이 확실히 손상된 경우에만 **폰트 복구 후 계속 / 영어로 계속** 선택이 나옵니다. 정상 기기에서는 이 선택이 나오지 않는 것이 정상입니다. 복구를 고르면 검증된 백업의 해당 파일만 복원합니다. 영어를 고르면 순정 폰트를 고치지 않습니다.
5. **전송 → 검증·저장 → 자동 재시작 → 재연결 → 메뉴 언어 준비 완료** 순서로 기다립니다. **전송 막대 100%는 마지막 단계가 아닙니다.**
6. 공간 부족·저장소 손상이 나오면 다른 파일을 임의로 지우지 마세요. 영어로 사용할 수 있는 안내가 제공되면 그 경로를 선택하거나 오류를 기록합니다.

현재 언어 ZIP은 문구와 글꼴 부분을 나눠 담습니다. 앱이 필요한 전송을 관리하므로 사용자가 두 파일을 따로 순서대로 보낼 필요는 없습니다. 이전 팩의 일치하는 부분은 재사용할 수 있지만 마지막 저장·활성화까지 확인해야 합니다.

**0.11.15의 언어팩 전송·검증·저장은 IGN ON/OFF로 취소되지 않습니다.** 다만 차량은 정차한 채 두고, 모듈 상시 전원과 휴대폰 연결을 유지하세요. 실제 이동이 감지되는 경우의 제한까지 해제하는 뜻은 아닙니다.

### 한국어로 바꾸는 예

1. 정상 CFW로 연결된 상태에서 **[폰] 기기의 현재 설정 보기 / 변경** 또는 **[누도] 설정의 언어 항목**을 엽니다.
2. **영어 전용 / English only**이 켜져 있으면 끕니다.
3. **기기 언어 / Device language → 한국어**를 선택하고 적용합니다. 앱의 **앱 언어**만 바꾸는 것과 다릅니다.
4. **[누도]** 재시작 안내가 뜨면 정차한 상태에서 재시작을 확인합니다. **나중에**를 고르면 선택은 저장되지만 현재 화면은 이전 언어를 유지하며 다음 재시작에 적용됩니다.
5. 재시작 후 파란 상태 화면의 **Loading menu text / Preparing menu fonts**와 단계·개수를 기다립니다. 필요한 문구·글자가 준비된 뒤 HOME이 열립니다. 앱의 다른 버튼을 누르거나 IGN을 오래 껐다 켜는 것이 활성화 절차는 아닙니다.
6. 설정 메뉴가 한국어인지 확인합니다. 일본어 등 다른 언어도 같은 순서입니다. **직접 선택한 기기 언어는 재연결한다고 앱 언어로 덮어쓰지 않습니다.**

**앱 언어 따르기**를 선택하면 지원되는 앱 언어를 다음 재시작에 반영합니다. 재시작 확인 중 이동·경고·전원 전환이 생기면 재시작이 취소될 수 있으므로 다시 정차하고 화면 안내를 확인하세요. 설정·주행 기록 저장을 마친 뒤 재시작합니다.

### 매번 오래 검사하나요?

아니요. **팩 전체 무결성 검사는 설치·갱신 때만 합니다.** 이후 부팅은 작은 헤더와 저장된 식별 정보를 열고 **선택 언어의 문구·필요한 글자만** 불러옵니다. 사용하려는 데이터의 범위·형식·읽기 오류를 막는 기본 검사는 남습니다.

언어 변경·팩 갱신 뒤에는 별도 준비 안내를 보이고, 같은 언어의 다음 부팅에서는 일반 시작 화면을 사용합니다. 완전 재부팅은 RAM을 다시 채우는 시간이 필요하지만 팩 전체를 다시 검사하지 않습니다. STOP 절전에서 깨어날 때는 유지된 RAM을 사용합니다. 전체 팩을 화면 칩이나 RAM에 통째로 올리지 않습니다.

### 음악·알림 글자 표시 방식

| 설정 | 특징 |
|---|---|
| **휴대전화에서 렌더링** — 기본 | 폰이 글자를 그림으로 만들어 보냅니다. 폰이 지원하는 다양한 문자·컬러 이모지를 사용할 수 있지만 준비·전송 지연이 있을 수 있습니다. |
| **기기 글꼴 사용** | 적은 텍스트를 보내고 누도가 글리프로 그립니다. 전송량이 작지만 미지원 문자·조합은 □로 나올 수 있습니다. 추가 단색 이모지를 사용합니다. |

음악 페이지·HOME·알림 상세·알림 팝업에 적용하며, 통화·빠른 답장 경로는 별개입니다. **영어 전용**은 영어 UI와 휴대폰 렌더링으로 돌아가는 수동 선택입니다. 자원을 복구해도 사용자가 켠 영어 전용을 자동으로 끄지 않습니다. 오류 때문에 영어로 대체됐더라도 저장된 언어 선호도는 남습니다.

## 7. 연결이 안 될 때

### 먼저 구분하세요

- **Gate 복구 메뉴:** Bluetooth가 없으므로 폰으로 연결할 수 없습니다. 본체 버튼을 씁니다.
- **순정 설치기가 파일을 기록 중:** Bluetooth 연결을 기다리거나 초기화할 단계가 아닐 수 있습니다. 본체 화면을 먼저 봅니다.
- **Bootstrap 메뉴/연결 대기:** 아래 절차를 사용할 수 있습니다.
- **일반 CFW HOME:** 권한·선택 기기·주행 연결 상태부터 확인합니다.

### Bootstrap에서 Couldn’t pair / 연결할 수 없음

정상 경로에서는 **Reset Bluetooth? → No**입니다. 실제로 연결이 실패할 때만 다음을 진행합니다.

1. **[폰] 접속이 안 되나요? / Bootstrap 연결 도움말**을 엽니다. 파일 기록 중에는 초기화를 시작하지 않습니다.
2. 도움말의 **Bluetooth 설정 열기**로 이동합니다. 해당 도움말 작업을 선택하면 앱의 연결 시도가 멈춥니다.
3. Android Bluetooth 설정에서 **내 Noodoe만 등록 해제/페어링 삭제**합니다. NewDoe 앱 데이터·설치 ZIP은 지우지 않습니다.
4. **[누도] Bootstrap 연결 대기 화면**에서 UP으로 페어링 메뉴를 열고 해당 휴대폰을 고릅니다. O를 놓았다가 **새로 2초 유지**해 삭제를 확인합니다. **ALL**은 모든 폰을 지우므로 의도한 경우에만 선택합니다. 이미 **Reset Bluetooth? → Yes**로 본체 쪽을 지웠다면 그 화면 안내를 따라 진행합니다.
5. **PAIR YOUR PHONE** 안내 후 Android에서 Noodoe를 다시 검색해 페어링하고 확인 요청을 승인합니다.
6. NewDoe 앱으로 돌아와 같은 기기를 선택하고 **현재 상태 확인**을 누릅니다. Bootstrap 메인 메뉴라면 본체의 **Install CFW**를 선택합니다. 문제 해결 마법사가 표시되면 **마지막 작업 상태 조회 → 검사 후 설치 이어가기**를 따릅니다.

첫 설치에서 재페어링한 키가 최종 저장되기 전에 본체 전원을 재시작하면 다시 페어링해야 할 수 있습니다. 이 때문에 앱에 별도의 ‘재페어링 완료’ 표시를 강제로 만들거나 Bootstrap을 다시 보내지는 않습니다.

### 일반 CFW에서 끊김

상단 연결 버튼이 중지 상태인지, 기기 주소가 맞는지, Bluetooth/주변 기기 권한이 남아 있는지 확인합니다. 수동 중지를 하지 않았다면 일시적인 통신 오류는 자동 재연결을 시도합니다. Android에서 앱을 **강제 종료**했거나 권한을 철회했다면 앱을 다시 열고 재개해야 할 수 있습니다. 카메라 문제는 완치됐다고 확정하지 않았습니다. 설치 중에는 다른 앱 전환을 줄이고, 재현되면 진단을 남기세요.

### 본체가 수동 재시작을 요청할 때만

```text
Please manually reset.
Hold UP + O together
for 3 seconds.
```

1. 화면과 Stage/Code/Phase를 촬영하거나 적습니다.
2. 버튼을 모두 놓은 뒤 **UP + O를 함께 3초** 누르고 놓습니다.
3. IGN OFF라면 즉시 꺼진 것처럼 보일 수 있습니다. 버튼을 놓고 IGN ON으로 하면 Gate부터 시작합니다. 이 조합으로 잠들었다고 펌웨어 설치가 실패한 것은 아닙니다.
4. 같은 기기·같은 ZIP으로 다시 확인합니다. 실제 CFW UPDATE가 나오면 정상 실행 확정을 마칩니다. 복구 메뉴라면 [9절](#recovery)을 봅니다.

**진행 중인 기록·검증을 단지 느리다는 이유로 이 조작으로 끊지 마세요.** 앱 데이터 삭제·NOR 포맷·다른 기기의 덤프 적용은 일반 해결 방법이 아닙니다.

<a id="recovery"></a>
## 9. 폰 없이 복구 / 순정으로 돌아가기

### 신형 Gate 열기

차량을 세운 뒤 아래 방법 중 현재 상태에 맞는 것을 씁니다.

- 전원을 새로 켜 Gate의 NewDoe 로고가 나올 때 **DOWN을 약 1초 유지**합니다. 전원 투입 전부터 DOWN을 누르는 경로도 있습니다.
- CFW가 실행 중이라면 기존 진입 방법도 유지됩니다: **IGN OFF → O만 누르고 유지 → 누른 채 IGN ON → ON 후 최소 2초 유지 → 복구 화면이 보이면 놓기**.
- IGN OFF 뒤 UP+O로 화면이 꺼진 상태라면 버튼을 놓고 다시 IGN ON으로 Gate를 시작할 수 있습니다.

단순히 키를 다시 켜는 것이 항상 완전 재부팅은 아닙니다. STOP 절전에서 바로 돌아올 수도 있습니다. 메뉴가 나타나지 않으면 버튼을 놓고 현재 화면을 확인하세요. 배터리선을 뽑는 것을 기본 조작으로 안내하지 않습니다.

오류가 있으면 먼저 **해골 + 0x형식 오류 코드 + PRESS ANY KEY... 30**을 표시합니다. 아무 버튼이나 누르거나 30초를 기다리면 메뉴로 갑니다. 메뉴에 표시된 **코드와 짧은 진입 사유**를 기록하세요. 수동 진입은 오류 코드가 없을 수 있습니다.

### 복구 메뉴에서 선택하기

UP/DOWN으로 이동, O로 선택합니다. **회색 항목은 현재 사용할 수 없는 항목**입니다. 기록을 바꾸는 동작은 확인 화면에서 O를 놓았다가 새로 2초 유지해야 합니다. 화면의 확인 안내를 우선하세요.

| 메뉴 | 사용할 때 |
|---|---|
| Start NewDoe | 실행 검증을 마친 현재 CFW로 들어가기. 백업 검사 중에도 활성화되면 선택할 수 있습니다. |
| Check again | 저장소·복구 가능 상태를 다시 확인하기 |
| Reinstall firmware | 보관된 설치 이미지로 복구를 다시 시도하기 |
| Restore previous | 사용 가능한 이전 정상 펌웨어로 돌아가기 |
| Return to stock | 검증된 순정 복구 이미지로 돌아가기 |
| Try recovery anyway | 일반 순정 복구가 안 될 때 추가 위치를 찾아 복구 시도. 손상 검증을 무시하는 기능은 아닙니다. |
| Details | 오류·상태 상세 확인 |
| More | Help / Dashboard / Play game / Back |
| Restart | 본체 재시작 |

**순정 복귀가 목적이면 Return to stock → 확인 화면의 O 2초**입니다. 폰 연결은 필요하지 않습니다. 순정 화면이 나타날 때까지 상시 전원을 유지합니다. Gate에는 Bluetooth가 없으므로 기기 메뉴에서 처리 중일 때 폰의 연결 실패로 판단하지 마세요.

강제 복구도 실패하면 안내 화면에서 O로 메뉴에 돌아갈 수 있습니다. 재시작/Check again은 이번 시도의 실패 상태를 다시 평가하지만, 실제 손상된 파일을 정상으로 만들지는 않습니다. 모든 유효한 복구본을 사용할 수 없으면 분해 후 프로그래머 복구나 수리가 필요할 수 있습니다. 직접 다룰 자신이 없다면 [프로젝트 문의](https://github.com/SerialSniffyHeck3r/noodoe_cfw/issues)에 화면과 진단을 남기세요.


**Use recovery scratch**가 나오면 별도 확인 문구를 읽으세요. 복구 공간을 마련하기 위해 진행 중이던 폰트·언어 복구 데이터를 대체하는 선택입니다. 평소 설치에서 고를 항목이 아닙니다. 사유 화면을 보관하고 해당 미완료 복구를 포기하려는 경우에만 승인하세요. 다른 파일을 지우는 선택은 아닙니다.

### 앱으로 순정 복귀하기

**주행 연동 중지 → 순정으로 돌아가기 → CFW 데이터 유지**를 고릅니다. 기존 환경을 남기고 재설치할 목적이면 이 경로입니다. **CFW 데이터까지 완전 삭제**는 다른 선택이며, 삭제 도구의 본체 승인 후 CFW 소유 데이터를 제거합니다.

본체가 실제 순정으로 돌아온 뒤 앱의 **본체에서 순정으로 돌아왔어요 · 확인**으로 확인합니다. 나중에 재설치할 때 **보관 데이터 복원**을 선택해야 남겨 둔 환경을 이어갑니다. 데이터 유지 복귀는 외장 저장소를 공장 출하 바이트 전체로 되돌리는 작업은 아닙니다.

## 10. 설치 뒤 첫 사용과 권한

앱에서 내 기기를 선택하고 상단 **재생/연결** 버튼으로 주행 연동을 시작합니다. **일시정지**는 주행 연동 중지이며 오디오 플레이어의 일시정지와 다릅니다. 주행 기록 파일 저장도 별도의 선택입니다.

| 허용 항목 | 쓰는 기능 |
|---|---|
| Bluetooth / 주변 기기 | 연결·설치·업데이트 |
| 알림 접근 | 선택한 앱의 알림, 활성 음악 재생 정보 |
| 정밀 위치 및 앱이 안내하는 백그라운드 위치 | 지도·GPS, 휴대폰 화면 OFF 중 위치 전달 |
| 연락처·최근 통화·전화 관련 권한 | 이름·통화 목록·지원되는 통화 조작 |
| 앱 알림 | 연결 서비스 안내와 알림 |
| 동반 기기 등록·백그라운드 실행 설정 | 재연결·백그라운드 연동 보조 |

허용하지 않은 기능만 제한될 수 있습니다. 앱의 **권한·연동 준비**에서 필요한 항목을 하나씩 확인하세요. 통화 제어 지원은 Android/제조사에 따라 다릅니다. 권한이 있어도 휴대폰이 번호를 주지 않으면 Unknown caller가 나올 수 있습니다.

앱을 최근 앱 화면에서 치우는 것과 Android의 **강제 종료**는 다릅니다. 강제 종료 후에는 직접 앱을 다시 열어야 할 수 있습니다. 재연결이 필요하면 수동 중지 여부와 휴대폰의 앱 배터리 제한을 먼저 확인합니다.

## 11. 본체 조작과 설정

일반 화면에서 **O 짧게**는 HOME → 트립 → 음악 → 스마트폰 → 지도 → HOME 순환입니다. 알림·전화·경고가 떠 있으면 그 화면의 버튼 힌트가 우선합니다.

- **O + DOWN 짧게:** 빠른 밝기 설정.
- 빠른 설정에서 **UP/DOWN 짧게:** 밝기 조절. **O 짧게:** 닫기. **O 길게:** MAIN MENU.
- 빠른 설정에서 **UP 0.8초:** 표시부만 재초기화. 실행 중인 세션을 유지하며 펌웨어 재설치와 다릅니다.
- 빠른 설정에서 **DOWN 0.8초:** Super Nite 저밝기.
- 전체 설정은 UP/DOWN으로 이동·값 조절, O로 선택·적용, Back으로 이전 화면.

차량 속도가 정상 수신되면 정차 상태가 유지된 뒤 전체 설정을 엽니다. IGN ON이 확인됐지만 속도를 받지 못하는 경우에는 전체 설정 접근을 허용합니다. **속도 미수신이 안전한 정차라는 뜻은 아니므로 직접 주차하고 조작하세요.** 업데이트·기록 작업의 별도 조건은 유지됩니다.

상단 다섯 메뉴 아이콘은 HOME에서만 일정 시간 뒤 숨고 다른 일반 페이지에서는 유지됩니다. GPS는 유효한 위치가 없으면 회색, 새 위치를 받으면 **120ms 회색 펄스**를 보입니다. Bluetooth 아이콘은 폰 배터리 20% 미만 노랑, 15% 미만 빨강, 5% 미만 빨강/회색 교대입니다. 충전 중에는 부족 색상 대신 75% 미만 초록/회색 교대, 75% 이상 초록 고정입니다.

## 12. ODO·트립·정비 기록

**ODO는 계기판에서 지금 받은 유효한 누적 거리**입니다. 자체 ODO 보정·영구 저장·이전 값 대체 기능과 ODO check 메뉴는 제거됐습니다. 수신이 없으면 미수신으로 표시합니다. 키 OFF 화면의 마지막 ODO는 이번 실행의 RAM에만 남습니다.

TRIP A/B·TODAY·이번 시동의 주행·오일·벨트·정비 카운터는 유지합니다. 정비 카운터의 교체 후 주행거리와 교체 주기는 설정에서 확인·조정할 수 있습니다. 값을 초기화하거나 직접 바꾸기 전 실제 교체 이력과 맞는지 확인하세요. 이 조정은 계기판의 원본 ODO를 바꾸지 않습니다.

HOME AUTO는 새 알림을 우선 표시하고, 그다음 재생 중인 음악, 그 외 정보 순으로 동작합니다. 새 알림은 기본 20초, 길게 눌러 정보 화면을 직접 골랐을 때의 자동 복귀도 20초입니다. 음악이 없으면 다른 정보를 순환합니다. 알림 팝업을 닫는 것과 AUTO 정보 표시의 우선순위는 별개입니다.

속도 링은 GPS가 아닌 차량 속도를 사용합니다. 최고·평균 마커는 이번 시동 값이 5km/h보다 클 때 표시하며, IGN OFF에서는 회색입니다. 오일 표시의 남은 비율은 30% 이하 노랑, 15% 이하 빨강, 5% 이하 빨강 점멸입니다.

## 13. 음악·전화·알림·빠른 답장

음악 앱에서 재생을 시작한 뒤 알림 접근 권한과 주행 연결을 확인하세요. 음악 페이지에서 UP 짧게는 재생/일시정지, DOWN 짧게는 다음 곡, UP 길게는 이전 곡입니다.

스마트폰 페이지는 요약에서 시작합니다. UP은 최근 전화, DOWN은 최신 알림을 엽니다. 상세 화면·통화 상태에 따라 버튼 의미가 달라지므로 오른쪽 힌트를 확인하세요. 팝업을 닫는 조작과 실제 통화 종료는 다릅니다. 설치 전이나 주행 중 처음으로 통화 조작을 시험하지 말고 정차 상태에서 확인하세요.

연속 메시지가 와도 최신 내용을 유지합니다. 새 알림 아이콘의 빠른 점멸은 약 2초이며 그동안 새 알림이 와도 점멸 타이머를 계속 연장하지 않습니다. 준비 중에는 이전 메시지를 최신인 것처럼 표시하지 않고 Updating...이 보일 수 있습니다.

빠른 답장은 **1–7번 사용자 문구 / 8번 위치+이번 주행 정보+음악 / 9번 위치 / 10번 음악**입니다. 8–10번은 서명을 붙입니다. 위치에는 지도 링크를 포함하며, 음악을 재생하지 않으면 재생 정보 없음으로 표시합니다. 상대·현재 위치·전송 내용을 확인하고 실제 전송을 승인하세요.

**Dash blink alerts**는 계기판의 밝기를 잠시 높음/낮음으로 바꾸는 알림입니다. 설정 → Display에서 끌 수 있습니다. 전화·알림·경고 팝업은 0.5초 간격 4단계, 연료 부족은 8단계이며 토스트는 제외합니다. 누도 LCD의 밝기를 깜빡이는 기능과 다릅니다.

<a id="map"></a>
## 14. 지도와 자동 축척

앱의 지도 메뉴에서 필요한 지역의 **`.map` 파일**을 가져옵니다. 지도 데이터는 펌웨어 ZIP이나 언어팩과 다른 파일입니다. 지도 없이 GPS 궤적·이동 격자가 보이는 것은 정상적인 대체 표시입니다.

- 지도 화면에서 **UP 길게:** AUTO / MANUAL 전환.
- **AUTO:** 속도에 맞춰 축척을 정하고 UP/DOWN으로 −2(가까이)~+2(넓게) 선호도를 조절합니다.
- **MANUAL:** UP/DOWN으로 축척 변경. 자동 모드처럼 연속 확대·축소 애니메이션을 쓰지 않습니다.
- **O 길게:** 북쪽 위 / 진행 방향 위 / 나침반 전환.

처음 보는 지역은 준비·전송 시간이 필요합니다. 지도 화면 밖에서는 지도 준비·전송을 중지합니다. GPS 위치가 안 잡히면 폰 위치 권한·위치 서비스를 확인하세요. 현재 기능은 지도와 위치·궤적 표시이며, 목적지 검색·경로 안내가 모두 제공되는 내비게이션으로 설명하지 않습니다.

<a id="dashboard"></a>
## 15. 앱 홈·꾸미기·테스트 화면

앱은 **홈 / 꾸미기 / 설치·현재 상태**의 세 페이지로 나뉘며 좌우로 넘깁니다. 상단 재생/일시정지 버튼은 누도와의 주행 연동을 제어합니다.

홈의 지도·속도·ODO 영역과 트립·정비 영역은 구분됩니다. **트립 영역 자체를 눌러** 다음 정보로 넘깁니다. 정비는 가로 막대로 오일을 크게, 벨트·정비를 별도로 표시하며 남은 거리를 함께 봅니다. 순정 기기에 연결되면 트립·정비용 영역은 **수신된 순정 정보 표시**로 바뀝니다. 순정에 없는 값을 CFW 정비 데이터처럼 만들어 표시하지 않습니다.

꾸미기에서 배경 사진, 알림 앱·팝업, 빠른 답장, 전화 즐겨찾기와 기기 설정을 고릅니다. 사진·설치 작업 전에는 주행 연동을 중지하라는 안내를 따르세요. 폰 주행 기록 저장은 사용자가 별도로 시작하는 기능이며, 이를 끄더라도 본체 트립 계산까지 끄는 것은 아닙니다.

**UI 테스트 모드**는 기기와 연결되지 않은 상태에서만 사용합니다. 가상 속도·ODO·CFW/순정 상태를 넣어 화면을 확인하는 기능이며, 실제 차량 값이나 저장된 본체 설정을 바꾸지 않습니다. 사용 후 테스트 모드를 끄고 실제 연결 상태를 확인하세요.

<a id="parking"></a>
## 16. 시동 OFF·주차·배터리

키를 끄면 Ride Summary 뒤 설정한 전원 순서로 넘어갑니다. **Ride Summary의 배경 음영은 유지하고, 이후 OFF 사진 대기 화면에서는 음영을 풉니다.** O를 누른 채 키를 끄고 놓으면 키 OFF 후 최대 10분 사용 경로를 사용할 수 있습니다. 버튼을 계속 눌러 시간을 무한히 연장하는 기능은 아닙니다.

**설정 → 시스템 → 전원 순서 → 장기 주차 전원 끄기**에서 끄기 / 2일(기본) / 3일 / 7일을 선택합니다. 이미 사용자가 고른 값은 업데이트 후에도 유지하므로 실제 값을 확인하세요. 시간이 되면 저장 작업을 정리하고 전원 종료를 요청합니다. 다음 IGN ON에는 Gate부터 다시 시작합니다. 이 장기 주차 상태에서는 Bluetooth 접근 재연결·웰컴 라이트를 기대하면 안 됩니다.

**화면이 검다고 전력 소비가 0인 것은 아닙니다.** 이 기능은 배터리 전압을 감지해 차단하는 보호기가 아니며, 실제 대기전류나 모든 차량에서의 일주일 유지 시간을 보증하지 않습니다. 심한 방전 이력이 있다면 배터리·차량 대기전류 점검을 먼저 받으세요. 사용자가 전문 장비 없이 회로를 만지거나 방전된 차량에서 업데이트로 시험할 필요는 없습니다.

<a id="report"></a>
## 17. 문제 보고와 백업

문제가 반복되면 앱의 **문제가 생겼나요? · 복구와 진단 → 진단 자료 저장·공유**를 사용하세요. 다음 내용을 함께 남기면 원인을 좁히기 쉽습니다.

- 차량 모델·연식, 폰 모델, Android 버전.
- 앱 버전과 **본체 펌웨어 버전 각각**. 앱만 업데이트한 경우도 적어 주세요.
- 순정 최초 설치인지 CFW 업데이트인지, 시작한 이전 버전과 선택한 ZIP 이름.
- 현재 누도 화면 사진, Stage/Code/Phase 또는 0x 오류 코드.
- 마지막으로 한 조작과 IGN ON/OFF, 재연결 후 달라진 점.
- 언어 문제라면 영어 전용·기기 언어·앱 언어와 언어 자원 상태.

진단 파일은 저장한 뒤 내용을 확인하고 공유하세요. 앱 데이터 삭제로 기록을 지우지 마세요. 전체 NOR 백업은 별도 고급 기능이며 설치할 때 자동으로 만드는 최소 백업과 다릅니다. 이미 보관한 원본 덤프·앱 백업은 별도 저장장치에도 보관하는 편이 좋습니다.
