# 0.9.70 · 시동 OFF 배경 음영 제거

시동 OFF가 확정되면 사진을 원래 색으로 표시하며, 사진 전체를 어둡게 하는 처리와 시계·ODO 주변의 가장자리 그라데이션을 적용하지 않습니다. 종료 요약, 사진 대기 화면과 시동 OFF 상태의 접근 웰컴 라이트에 적용합니다. 선택한 사진·사진 전환·시계/ODO 배치·실제 백라이트와 전원 타이밍은 유지합니다.

시동 OFF 판정 전1초의 유예 구간은 마지막 화면을 그대로 유지합니다. 다시 시동을 켜면 일반 화면의 기존 밝기 설정으로 돌아가며, 시동 ON의 Welcome 화면은 기존 대비를 유지합니다. 연료 경고 팝업의 음영은 그대로입니다.

**앱 데이터를 지우지 않고0.9.70 APK를 덮어 설치**한 뒤 같은 **0.9.70 ZIP**으로 업데이트하세요.0.9.69 설정 목록 오류 수정과 업데이트 전 설정 백업도 포함합니다. Stage6/4에서는 여전히 **UP + O 동시3초** 재시작을 요구할 수 있으며, 이후 재연결하여 결과를 확인하세요. F4 순정5.14/5.16 허용 조건과 Bootstrap 수동 재페어링은 같습니다.

실제 ARM 배경 런타임·EVE 명령 출력, Debug/Release 빌드, APK/ZIP 가져오기·서명·대응 Product 해시를 검증합니다. 실기 화면·차량 테스트는 하지 않았습니다.
