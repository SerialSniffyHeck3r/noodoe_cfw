# 설치 연결 복구 — Companion 0.9.38 / CFW 0.9.35

## 0.9.38: 강제 복구 후 재설치 · 데이터 유지

**APK0.9.38을 기존 앱 위에 덮어 설치하세요.** 대응 ZIP은 CFW0.9.35 그대로입니다.

1. 주행 연동을 중지하고 최신 설치 ZIP을 선택합니다.
2. 문제 해결 마법사 위쪽의 **강제 복구 후 재설치 · 데이터 유지**를 누릅니다. 도움말에도 같은 버튼이 있습니다.
3. 앱이 기기 식별, 현재 부팅 결과, 기록 중인 작업, 본체의 순정 복구본을 확인한 뒤 독립 복구 명령을 보냅니다. 이 과정은 막힌 `0x45 UPDATE STATUS`를 호출하지 않습니다. 미확인 롤백 표시는 증거를 보관하고 별도로 확인 처리합니다.
4. 본체가 실제 순정 화면으로 돌아오면 **본체에서 순정으로 돌아왔어요 · 확인**을 누릅니다.
5. 이어서 **Bootstrap 전송 → 보관 데이터 복원**으로 CFW를 재설치합니다. 설정·사진·정비 기록을 지우는 초기화 경로가 아닙니다.

복귀 요청이 접수됐거나 Bluetooth가 끊겼다는 이유만으로 순정 복귀 완료로 표시하지 않습니다. 실제 순정 응답을 확인해야 다음 설치로 진행합니다. 이전 설치 기록과 진단 자료는 보존합니다. 기존 페어링을 먼저 삭제할 필요는 없습니다.

이 기능은 현재 CFW의 독립 복구 명령을 이용하므로 새 CFW를 먼저 설치하지 않아도 사용할 수 있습니다. 파일을 수신 중이거나 시험 부팅 중이거나 순정 복구본 검사가 실패하면 강행하지 않습니다. 새 파일을 거부 중인 업데이트 큐에 계속 밀어 넣지 않습니다.

독립 복구도 끝나지 않으면 본체에서 **키 OFF → O를 약 1초 누른 채 키 ON → 2초 더 유지 후 놓기**로 복구 화면에 진입합니다. 이 경로도 반응하지 않으면 당시 진단을 보관하세요. 펌웨어 전송을 반복하면 해결되는 상태로 취급하지 않습니다.

앱 회귀시험과 실제 Product 복구 코드의 ARM 모의시험을 수행했습니다. 사용자가 보고한 실기에서 복구에 성공했는지와 업데이트 큐가 정체된 최초 원인은 아직 확인되지 않았습니다. 이번 릴리스는 APK만 변경하며 폰트·Bluetooth 속도·MCU 바이너리는 변경하지 않습니다.

## 이전 앱 변경 내역

아래는 이전 버전의 동작 기록입니다. 현재 STATUS가 계속 거절되는 경우에는 위의0.9.38 복구 경로를 사용하세요.

## 0.9.37 앱: 상태 확인이 재연결 대기로 돌아가는 문제

**APK만 0.9.37로 덮어 설치하세요. 앱 데이터나 페어링을 먼저 지우지 마세요.**
대응 ZIP은 기존 **CFW 0.9.35와 동일**합니다.

주행 연동이 실행 중이면 ‘주행 연동 중지 · 업데이트 준비’를 누른 뒤 ‘CFW 업데이트’를
선택하세요. 이번 앱은 같은 연결에서 이전 설치 결과를 먼저 대조합니다. 이미 확인된
롤백 때문에 별도의 상태 확인과 업데이트 버튼을 반복해서 오갈 필요가 없습니다.
본체에 확인하지 않은 롤백 결과가 남아 있으면 ‘복귀 결과 확인 · 차단 해제’를 사용하세요.

‘연결 복구 → 현재 상태 확인’도 성공한 연결을 닫았다가 다시 열지 않고 계속 사용합니다.
상태 조회가 계속 거절되거나 응답하지 않으면 제한된 조회 뒤 멈춥니다. 이 경우
‘진단 자료 저장·공유’로 로그를 보관하세요. `0x45 BUSY`와 본체 작업 상태가 함께 기록됩니다.
BUSY를 성공으로 간주하거나 미확인 설치를 다시 쓰지 않습니다.

이 수정은 앱의 재접속·조회 루프를 다룹니다. 본체가 계속 BUSY를 반환하는 원인과
실차 복구 성공은 아직 확인되지 않았습니다. 기기 식별 성공만으로 업데이트 가능한
상태라고 판단하지 않습니다. 기록·설정·사진은 보존합니다.

## 롤백 이후 업데이트와 순정 복귀가 모두 차단될 때

0.9.36은 **APK만 수정**한 긴급 배포입니다. 동봉 ZIP은 기존 **CFW 0.9.35와 바이트까지 동일**합니다.
현재 막힌 기기에서 이 문제를 풀기 위해 펌웨어를 먼저 다시 설치할 필요는 없습니다.

1. 앱을 삭제하거나 데이터를 지우지 말고 **0.9.36 APK를 덮어 설치**합니다.
2. 최신 ZIP을 그대로 선택한 상태에서 **현재 기기 확인 → 현재 CFW / 설치 결과 확인**을 누릅니다.
3. 이전 CFW로 복귀한 상태라면 **복귀 결과 확인 · 차단 해제**를 누릅니다.
   본체의 확인 저장 완료까지 기다립니다. 재부팅으로 경고가 이미 사라졌어도 조회할 수 있습니다.
4. **CFW 업데이트** 또는 **순정으로 돌아가기 → CFW 데이터 유지**를 선택합니다.
   Gate 이관이 필요하다는 안내가 있으면 데이터 유지 순정 복귀 경로를 사용합니다.
5. 순정 화면으로 돌아왔으면 **본체에서 순정으로 돌아왔어요 · 확인**을 누릅니다.
   앱은 이전 ZIP의 부팅 대기도 실제 순정 응답과 대조해 정리합니다.

이전 ZIP을 찾아 다시 고를 필요는 없습니다. 실패 기록·사진·설정·정비 기록을 지우지 않습니다.
실제 설치 작업이 진행 중이거나 기기/작업 번호가 맞지 않으면 해제하지 않고 상태를 안내합니다.
본체의 O 버튼으로 경고가 닫히지 않을 때도 앱의 복귀 결과 확인을 사용할 수 있습니다.
앱도 연결할 수 없다면 기존 독립 복구 조작인 **키 OFF → O를 약 1초 누른 채 키 ON → 2초 더 유지**로
본체 복구 화면에 들어가 화면 안내를 따릅니다. 이는 앱의 ZIP 선택 기록과 별개입니다.

**앱 0.9.36과 CFW 0.9.35 ZIP을 사용하세요.** 설정·사진·정비 기록은 유지합니다.
앱이 복구층 이관을 안내하면 데이터 유지 순정 복귀 → 같은 ZIP의 새 Bootstrap →
Gate·CFW 설치 → 정상 실행 확인 순서로 진행하세요. 이미 새 Gate면 일반 업데이트를 합니다.

## 페어링 승인 후 Couldn't Pair가 반복될 때

1. 앱의 **연결 복구 → 이 Noodoe 연결 완전히 다시 설정**을 엽니다.
2. Android Bluetooth 설정에서 **해당 Noodoe만 등록 해제**하고 앱으로 돌아옵니다.
   앱 데이터와 설치 기록은 삭제하지 않습니다.
3. 본체 설치·시험 부팅 연결 화면에서는 **UP**을 누릅니다. 정상 Product에서는
   IGN ON 상태에서 모든 버튼을 놓고 **UP+DOWN+O를 동시에 3초** 유지합니다.
   Settings → Connections → Re-pair phone도 같은 복구 화면을 엽니다.
4. 본체에서 내 폰 또는 **ALL**을 고릅니다. ALL은 본체의 모든 폰 키를 지웁니다.
   **O를 놓았다가 새로 2초 유지**해 승인하고, 저장 중 전원을 유지합니다.
5. 본체가 **Ready to pair on your phone**을 표시하면 앱에서 준비 완료를 선택하고
   **페어링하고 연결 확인**을 누릅니다. Android 승인창은 한 번 승인하고 결과를 기다립니다.
6. 앱이 실제 보안 연결·기기·새 키 저장을 확인한 다음 같은 설치를 이어갑니다.
   검증된 파일은 상태 확인 후 재사용합니다.

PH9가 계기판 조작 위치여도 이 복구를 사용할 수 있습니다. Gate의 ACTION REQUIRED
화면이라면 RETRY로 Product를 시작한 뒤 위 절차를 사용합니다. 순정 실행 중에는 순정의
페어링 조작을 사용하며, 기기 측 CFW 키 초기화는 Bootstrap 이후에 제공합니다.
Android 설정 왕복과 앱 재실행 후에도 복구 단계를 유지합니다. 권한을 요구하면 Android
앱 권한의 주변 기기를 허용하세요. Bluetooth 자체도 켜져 있어야 합니다.

## RETRY와 속도 선택

- **RETRY:** 현재 속도로 Bluetooth를 다시 시작합니다. 키를 지우지 않습니다.
- **TRY STANDARD SPEED:** Product에서 921,600baud로 다시 시작합니다.
- **RESET PAIRING:** 선택한 폰/전체 폰 키 초기화 절차를 엽니다.
- **FIRMWARE RECOVERY:** 독립 Gate에서 RETRY·이전 CFW·순정 복귀를 선택합니다.
- **DETAILS:** 초기화 단계·baud·오류·키 저장 상태를 확인합니다.

Bootstrap은 표준 속도만 사용합니다. Product 고속 검증과 실제 휴대폰 연결은 서로
다른 상태입니다. 고속 통과만으로 무선 전송 속도가 보장되지는 않습니다.

## 대기 시간과 부팅 화면

새 Product 시험 부팅은 **5분**, 정상 실행 검사는 **5초**입니다. 본체의 남은 시간과
앱의 확인값을 따릅니다. 재연결·페어링 복구로 5분이 다시 시작되지 않습니다.
0:00 뒤에는 실제 확정·실패 상태를 확인하세요. 새 Gate는 실패 상태를 남기고 선택을
기다립니다. Gate의 RETRY를 직접 승인하면 이미지를 확인한 뒤 새 시험을 시작합니다.

DEVICE STARTUP은 일반 시작 검사, INSTALLING FIRMWARE는 기록 작업,
RESTARTING DEVICE는 재부팅 인계, RESTORING PREVIOUS/STOCK FIRMWARE는 복원입니다.
정상 재부팅에서도 독립 Gate의 시작 검사는 실행됩니다. 진행 막대는 실제 작업량이며
연결 대기를 가짜 설치 진행률로 표시하지 않습니다.

## 조작까지 막혔을 때

CFW 0.9.34 이상에서 IGN ON: 모든 버튼을 놓고 **UP+DOWN을 함께 10초 유지한 뒤
모두 놓으면** MCU를 강제 재시작합니다. 저장 전 상태를 잃을 수 있습니다. 화면만
복구하는 **UP+O 3초**와는 다릅니다. CPU/I/O 태스크가 실행 중일 때 사용할 수 있습니다.
설치·시험 화면의 데이터 유지 순정 복귀는 **DOWN을 새로 3초** 누릅니다.
