# AK550 벤치 입력 관측: SPEED, 연료 센더, 고정된 조도 단계

2026-09-10. 사용자의 새 관측을 기존 정상 UART 캡처, SR1.5 V5.16 정적 분석, AK550 정비매뉴얼과 대조했다. 이번에는 장치에 접속하거나 신호를 출력하지 않았다. 아래 새 입력 실험에 대응하는 UART 로그는 아직 분석하지 않았으므로 기존 정지 캡처와 구분한다.

> **후속 GAS1/fuel0 캡처 반영:** 실물 5칸 중 1칸은 payload **3=51**, 0칸은 **3=50**이었다. 하위 니블 1·0과 실제 표시 1칸·0칸이 대응했다. 아래에서 먼저 제안했던 payload 2는 두 파일 모두 00 그대로였다. 따라서 연료 입력 대조는 payload 3을 우선 관찰한다. [실제 캡처 분석과 후보 수정](2026-09-10-fromdash-gas1.md).

## 새 관측과 현재 해석

| 사용자 관측 | 지지하는 해석 | 아직 확인하지 못한 것 |
|---|---|---|
| SPEED를 전원 마이너스에 접촉/분리하자 1km/h 표시 | 입력의 에지/펄스를 계기판이 속도로 처리한다는 강한 근거 | 펄스당 거리, 주파수-속도 환산, 입력 전기 정격. 손 접촉의 바운스도 미측정 |
| FUEL 쪽에 12V를 접촉했을 때 스파크와 리셋 | 의도하지 않은 전류 경로 또는 전원 강하 등이 생겼을 가능성 | 정확한 단락 경로, 보호회로 동작, 손상 여부. 이것만으로 저항식을 입증하지 않음 |
| FUEL+와 FUEL−를 직결하자 잔량 표시가 변하다 연료계가 꺼짐 | 연료 입력에 대한 반응 가능성 | 게이지만 꺼졌는지 전체가 재부팅했는지, 범위 밖 입력 처리인지 손상인지 |
| 조도를 바꿔도 A1 단계가 7로 보임 | 송신 캐시가 7인 상태가 지속 | 실제 센서 측정 성공 여부, 원시 lux 변화, 임계값 통과 여부, 센서 고장 |

여기서 연료 입력은 연료의 흐름을 재는 유량계보다 **탱크의 연료잔량 센더**로 부르는 것이 정확하다.

## 저항식 연료 센더의 문서 근거

KYMCO AK550 서비스 매뉴얼의 Fuel Level Gauge Inspection, §6-23은 플로트 위치에 따라 녹색–노랑/흰색 선 사이 저항을 측정하도록 설명한다. §6-24의 규격은 다음과 같다.

| 플로트 위치 | 저항 규격 |
|---|---:|
| Full | 100Ω ±3% |
| Empty | 2,400Ω ±3% |

출처는 제조사 매뉴얼을 재게시한 [§6-23, 웹 페이지 210](https://www.manualslib.com/manual/1968932/Kymco-Ak-550.html?page=210), [§6-24, 웹 페이지 211](https://www.manualslib.com/manual/1968932/Kymco-Ak-550.html?page=211)이다. 공식 KYMCO 오스트리아 PDF의 검색 색인에서도 동일한 표가 확인됐지만, 해당 PDF URL은 현재 404였으며 원본 PDF를 내려받아 육안 검증한 상태는 아니다. 재게시 매뉴얼 본문으로 대조했다.

이는 AK550의 연료잔량 센더가 저항식이라는 문서 근거다. 사용자가 확보한 차량-계기판 핀아웃의 FUEL+/FUEL−가 해당 센더 두 선에 대응하는지는 그 배선도로 연결해야 한다. 이 연구 폴더에서는 그 대응표 원문을 확보하지 못했다. 연료펌프 구동 전원과 잔량 센더 회로는 구분한다.

**FUEL 입력에 외부 12V를 다시 직접 주입하거나 양단을 0Ω으로 직결하는 시험은 중단한다.** 0Ω은 위 센더 정상 범위에도 포함되지 않는다. 표시가 꺼진 것을 바로 '센서 단락 오류 코드'로 해석할 근거도 없다.

센더 두 단자의 대응이 확인되면, 먼저 무부하 단자 사이 전압을 멀티미터의 전압 모드로 확인한다. 연결 변경은 전원을 끈 상태에서 하고, 정상 범위의 큰 값인 2.4kΩ부터 센더 대신 연결해 표시와 LOWERPIN을 함께 기록할 수 있다. 저항 정격은 실제 인가 전압에 대해 P=V²/R로 확인한다. 작은 저항으로 내릴수록 같은 전압에서 전력이 커지므로, 특히 100Ω에 일반 소형 저항을 무조건 쓰지 않는다. 전원이 인가된 회로에 저항 측정 모드를 사용하지 않는다.

스파크/리셋 이후 이상 발열·전류 증가·재부팅이 계속된다면 입력 자극보다 전원 및 입력부 상태 확인이 우선이다. 현재 관측만으로 장치가 손상됐거나 정상이라고 판정하지 않는다.

## UART에서 대조할 위치

기존 LOWERPIN 정상 프레임 116개는 모두 다음과 같았다.

```text
F5 21 09 | 00 00 00 00 7B 8E 00 00 00 | 28
offset      0  1  2  3  4  5  6  7  8
```

| payload offset (0부터) | 현재 해석 | 다음 확인 |
|---|---|---|
| 0 | 속도 정수 km/h. 기존 캡처는 0 | 계기판에 1km/h가 뜨는 동안 00→01인지 확인 |
| 1 | 미확인 상태값 | 특정 입력 하나와 반복적으로 연동되는지 관측 |
| 2 | 잔량 게이지 raw. AK550 연료량 후보 | 정상 센더 저항 변경 시 표시와 이 바이트가 같이 변하는지 확인 |
| 3 | 미확인 상태 니블 두 개 | 연료 단선/정상 전환 시 함께 변하는지도 기록하되 의미를 미리 정하지 않음 |
| 4..7 | LE32 ODO 36,475km | 사용자가 실제 표시와 일치함을 확인 |
| 8 | raw−40으로 처리하는 온도형 값 | 외기/냉각수 등 원천 미확인. raw 0을 실제 −40°C로 해석하지 않음 |

offset 2는 Noodoe에서 `fuel_battery` 공용 잔량 위젯의 6단계 표시에 쓰이는 경로까지 확인됐다. 원시 연료 퍼센트라는 보장은 없으며, 현재의 00이 빈 탱크인지 미연결 상태인지는 정지 캡처만으로 구분되지 않는다. 저항과 잔량 %가 선형이라고도 가정하지 않는다.

이번에는 SPEED, 연료 저항, 조명을 한 번에 바꾸지 않고 하나씩 바꾼 로그가 가장 유용하다. 각 조건의 시작 시각, 실제 표시값, 안정화 후 유지 구간을 남기고 행 경계를 이어 붙인 정상 XOR 프레임 전체를 비교한다. 바뀐 체크섬을 새 데이터 필드로 해석하지 않는다.

## A1의 7 고정: 정적 분석으로 좁힌 원인

대상은 기존 V5.16 OTA BIN이다. 실제 모듈 전체 펌웨어가 이 버전과 동일하다는 보장은 없다. 기존 캡처의 A1 프레임은 다음과 같다.

```text
F5 A1 02 | 01 07 | 50
```

이 07은 Noodoe 자체 조도 분류의 저장된 인덱스다. 원시 lux나 매 프레임 새로 측정한 값이 아니다. UART의 유효 수신 횟수에 따라 송신되는 경로와 조도 센서 갱신 경로가 나뉜다.

이번 추가 분석에서 확인한 조건:

- `0x0804E3A2`는 센서 설정 레지스터 1을 읽고 bit 7을 검사한다. 준비 조건이 충족되지 않으면 `0x0804E3D0`에서 상태 코드 7을 반환한다. I²C 읽기 오류도 상위로 전달한다.
- `0x0803050E..0x08030510`은 읽기 반환값이 0이 아니면 분류와 UART 캐시 갱신을 건너뛴다. **읽기 실패/미준비 시에는 이전 단계가 계속 송신될 수 있다.**
- 위의 **상태 코드 7은 A1의 단계 7로 복사되지 않는다.** A1=7을 '오류 대체값'으로 해석하는 것은 잘못이다.
- 분류 결과가 10 이상이면 `0x08020380` 분기에서 저장을 건너뛴다. 임계치 설정 실패도 분류기에서 10을 반환하므로 이전 단계가 유지될 수 있다.
- 자동/수동 백라이트 모드 조건은 `0x0802038E`에 있으며 단계 저장 뒤에 검사한다. 이 경로에서 수동 밝기 설정이 곧 A1 분류 갱신 중단이라는 뜻은 아니다.
- 10개 분류 임계값의 원천은 `0x0800C040..0x0800C067`이다. OTA에 포함되지 않은 하위 플래시이므로 실제 lux 범위와 현재 단계 7의 경계를 아직 재현하지 못한다.
- GPIO callback → 등록된 조도 callback → 이벤트 subtype 20 → `0x08030506`의 갱신 경로를 확인했다. 이 이벤트가 발생하거나 전달되지 않아도 UART 자체는 기존 캐시를 계속 송신할 수 있다. 복원된 GPIO 비교 mask는 `0x0008`이며, 이것만으로 포트나 커넥터 번호를 정하지 않는다.

따라서 실제 센서 입사광이 같은 분류 구간 안에서 바뀐 경우와, 읽기/이벤트/임계치 갱신 문제로 캐시가 유지되는 경우를 우선 구분해야 한다. 정상 A1 반복만으로 센서가 정상 또는 고장이라고 판단할 수 없다.

물리 센서의 위치가 확인되면 그 위치를 충분히 가린 상태와 밝힌 상태를 각각 수 초 이상 유지해 UPPERPIN과 Noodoe 자체 밝기를 기록한다. 센서로 식별된 OPT3001의 변환 시간은 설정에 따라 100ms 또는 800ms이므로 순간적인 손 움직임보다 유지 구간이 유용하다. 이는 해당 실물의 설정값을 확정한 설명은 아니다. [TI OPT3001 데이터시트](https://www.ti.com/lit/ds/symlink/opt3001.pdf).

이 시험에도 단계가 고정이면 다음 진단 대상은 OPT3001의 원시 결과·상태와 센서 이벤트 경로다. 기존 UART 21의 온도형/미확인 필드를 조도로 임의 재해석하지 않는다.
