# CFW + Companion 0.10.5 beta — language verification and resume

**Install both NoodoeCompanion-0.10.5.apk and NoodoeInstaller-CFW-0.10.5.zip.** Keep app data. The unchanged language archive is NOODOE-LANGUAGE-B-0.10.1.zip; its older resource version is intentional.

Installation now shares the boot verifier’s two-page cache. It processes up to 64 cached records per visit, stops on physical reads and retains every hash/structure/FAT/journal check. Ignition changes pause uncommitted work instead of cancelling it, with the original stationary admission required before continuing. The phone and device show real verification progress. Settings, language preferences, Gate, Bootstrap and pairing behavior remain unchanged.

## 0.10.5: language verification and saving

Install both the 0.10.5 APK and ZIP. Matching-Gate 0.10.x devices use normal CFW-to-CFW update; this resource issue does not require stock return, formatting or deleting app data. Confirm the new CFW UPDATE screen and firmware installation first, then accept the language-resource offer. Already confirmed firmware can use Install / resume language resources.

Remain parked with ignition OFF. Transfer 100% is followed by file hashes, translated strings, glyphs, emoji validation, journaled saving, automatic restart and readiness confirmation. The phone and dashboard show these stages separately. Glyph validation uses actual item counts instead of completed transfer bytes.

Turning ignition ON pauses uncommitted work. Turn it OFF again, or wait for five seconds of fresh valid stationary speed, to resume. Missing speed or movement cannot authorize writes. Five minutes without progress or a lost connection safely stops uncommitted work; use the same resource menu to resume. Once metadata commit begins, the bounded transaction finishes or recovers through Gate before releasing the filesystem. Keep the module powered.

Resume compares physical page hashes and reuses only matching candidate bytes. Firmware completion and resource completion remain separate. Wait for automatic restart and multilingual-ready confirmation. An explicitly enabled English only preference remains enabled; turn it off and select Follow app or the desired language, then confirm restart. Matching installed packs are reused.

## 0.10.5: 언어팩 마지막 검증·저장

0.10.2~0.10.4에서 언어팩 전송 뒤 `Verifying and saving`에 오래 머물렀거나 IGN을 켠 뒤 영어로 돌아갔다면, **APK와 ZIP을 모두 0.10.5로 업데이트**하세요. 같은 Gate의 0.10 계열에서는 일반 CFW→CFW 업데이트를 사용합니다. 이 문제 때문에 순정 복귀·초기화·앱 데이터 삭제를 할 필요는 없습니다.

본체의 `CFW UPDATE` 확인과 설치 확정이 끝나면 언어 자원 설치 질문에서 설치를 선택하세요. 이미 업데이트를 완료했다면 설치 페이지의 **언어 자원 설치 / 이어가기**를 사용할 수 있습니다. 주행 연동을 중지하고 정차·IGN OFF 상태에서 진행하세요. 전송 100% 뒤에도 파일 해시 → 번역·글리프·이모지 검사 → 저장 → 자동 재시작 → 자원 확인이 남습니다. 앱과 본체가 현재 검사 단계를 표시합니다. 글리프 검사는 실제 항목 수로 표시되며 전송 바이트와 구분합니다.

검증 도중 IGN을 켜면 즉시 취소하지 않고 쓰기를 대기합니다. IGN을 다시 끄거나 유효한 속도 데이터로 정지가 5초 확인되면 이어갑니다. 속도가 없거나 주행 중이면 기록하지 않습니다. 5분간 작업이 진행되지 않거나 연결이 끊기면 안전하게 중단하고 같은 메뉴에서 재검사·재개하세요. 이미 메타데이터 게시를 시작한 짧은 구간은 복구 가능한 상태까지 마치거나 Gate에서 복구합니다. 이때 배터리·모듈 전원을 분리하지 마세요.

중단 전에 기록한 후보 데이터는 실제 페이지 해시가 맞는 부분만 재사용합니다. 펌웨어 설치 완료와 언어 자원 완료는 별개입니다. 자동 재시작 후 앱에서 다국어 준비 완료를 확인하세요. 직접 켠 `English only` 설정은 업데이트로 끄지 않습니다. 한국어가 필요하면 이 옵션을 끄고 언어에서 `Follow app` 또는 `Korean`을 선택한 뒤 재시작을 확인하세요. 정상 팩이 이미 있으면 다시 전송하지 않습니다.

## Limits

Software validation only; no physical scooter, radio timing or power-cut qualification was performed. 0.9.x/older-Gate devices still require the documented keep-data stock return and reinstall. The previously accepted legacy stock-return power-interruption limitation remains; automatic recovery in that old-code interval is not guaranteed.
