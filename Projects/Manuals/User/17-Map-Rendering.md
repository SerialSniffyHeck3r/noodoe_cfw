# 0.9.28 지도 표시·경고·Bluetooth 확인

지도는 폰에서 계속 벡터로 전송합니다. 누도는 받은 도로와 지형을 투명 이미지로 준비하고, 화면에는 완성된 한 장만 합성합니다. 퀵 세팅·알림과 지도가 겹칠 때 도로마다 EVE 명령을 반복하던 부담을 줄인 변경입니다. 배경 슬롯·시계/ODO 제외 영역·상하 그라데이션과 기존 음영 값은 유지합니다.

## 고속 Bluetooth가 실제로 켜졌는지 보기

O+DOWN으로 퀵 세팅을 열고 O를 길게 눌러 **Settings → Debug**로 들어갑니다.

- **BT speed / probe**의 `3686400 / probe 6/6`: 고속 초기화와 응답 검증 완료.
- `921600 / fallback ...`: 고속 경로 실패 후 표준 속도 사용. 뒤의 값은 복귀 원인 코드입니다.
- `Not ready / phase ...`: 아직 준비 완료가 아닙니다.
- **SPP measured KiB/s**: 누도 기준 RX는 폰→누도, TX는 누도→폰입니다. 약1초 구간의 실제 전송량이며 대기 중0은 정상입니다. 이 항목을 계속 보고 있어야 측정이 갱신됩니다.

baud는 MCU와 Bluetooth 칩 사이 속도입니다. 앨범아트는 폰의 읽기·인코딩·큐 대기·전송도 거치므로 baud 수치와 표시까지 걸리는 시간은 다릅니다.

## 함께 바뀐 점

연료 경고는 검정 음영으로 시계·ODO·링까지 덮고 그 위에 연료 아이콘과 문구를 표시합니다. TRIP 표지판과 오토바이 사이 점 세 개를 복원했습니다. 답장 기능이 없는 알림은 `No Reply Action`이라고 표시합니다.

설치 후 정상 실행 확인은5초입니다. 화면 확인·같은 펌웨어 확인·앱 연결과 실패 롤백은 그대로 필요합니다. APK와 대응 ZIP을 함께 업데이트하며, 기존 CFW에서 순정 복귀나 Gate 교체는 필요 없습니다.
