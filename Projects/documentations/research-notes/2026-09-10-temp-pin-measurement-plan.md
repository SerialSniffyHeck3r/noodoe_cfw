# 센서 없이 TEMP+/TEMP− 입력을 특성화하는 측정 순서

> **현재 보류:** 사용자가 가변저항으로 TEMP 전압을 바꿔도 UART 프레임이 변하지 않았다고 보고해 이 입력의 활용 우선순위를 낮췄다. 아래 절차는 참고용으로 보존하며 현재 추가 시험 요청이 아니다. [관측과 작업 결정](2026-09-10-temp-input.md).

2026-09-10 사용자 정정: **순정 온도 센서를 발견한 것이 아니다. 계기판 TEMP+/TEMP− 두 단자만 있으며 센서 품번·실물·규격은 없다.** 아래는 제안한 측정 절차이고 실행 결과가 아니다. 계기판은 차량과 분리된 벤치에서 기존에 확인한 전원·점화 배선으로 정상 기동한다.

> 후속 사용자 관측: 한 핀 약 5V, 다른 핀 약 0V. 103 가변저항의 와이퍼를 −, 바깥 단자를 +에 연결하고 +핀 전압을 관찰하니 회전에 따라 전압이 내려갔다. 이는 두 단자 저항 부하에 대한 반응이다. 실제 저항/전압 대응과 UART 변화는 아직 확보하지 않았다. [관측 기록](2026-09-10-temp-input.md).

목표는 (1) 각 핀의 기준 전위, (2) 바이어스의 DC/펄스 여부, (3) 제한된 저항 부하에서의 전압·전류 특성, (4) UART 반응을 확인하는 것이다. +/−라는 명칭으로 NTC·극성·정격을 확정하지 않는다.

## 1. 전원 OFF 참고 측정

계기판 전원과 USB 등 다른 전원을 분리하고 잔류 전압이 없는지 먼저 확인한다. 멀티미터의 저항 모드로 TEMP− 대 확인된 계기판 전원 GND를 측정한다. 테스트 리드끼리 붙였을 때의 저항도 기록한다.

리드를 바꾼 두 방향에서 값이 비슷하고 리드 저항 수준인지, 수십/수백 Ω 이상인지, 시간이 지나며 변하는지 기록한다. 부저 소리만으로 두 핀을 같은 GND라고 판단하지 않는다. PCB 내 저항·보호소자·축전기 경로를 읽을 수 있으므로 측정값이 곧 센서 규격이나 내부 풀업 하나의 저항은 아니다. 전원이 켜진 상태에서는 저항/연속성 측정을 하지 않는다.

## 2. 아무 저항도 연결하지 않은 상태의 전압

계기판을 기존 정상 전원 조건으로 기동한다. DMM DC 전압 모드로 다음을 기록한다.

| 이름 | 빨간 리드 | 검은 리드 |
|---|---|---|
| V+ | TEMP+ | 확인된 계기판 전원 GND |
| V− | TEMP− | 확인된 계기판 전원 GND |
| Vopen | TEMP+ | TEMP− |

기동 직후와 안정된 후의 값, 사용한 전원 전압을 함께 기록한다. Vopen≈V+−V−인지도 확인한다. 핀에 외부 3.3V/5V/12V를 인가하거나 DMM 전류 모드로 두 단자를 연결하지 않는다. 전류 모드는 이 단계에서 사실상 단락 부하가 될 수 있다.

TEMP−가 약 0V, TEMP+가 안정된 양전압이면 센서 입력용 바이어스 가능성이 있다. 그러나 이것만으로 저항식이라고 확정하지 않는다. 두 핀이 모두 0V여도 미사용이라고 결론 내리지 않는다. 펄스 여기·조건부 활성화·풀다운 입력 등 여러 원인이 가능하다.

## 3. 스코프로 DC인지 펄스인지 확인

가능하면 한 대의 두 채널을 쓴다. **두 채널의 모든 GND 집게는 확인된 계기판 전원 GND에만 연결**한다. CH1 팁은 TEMP+, CH2 팁은 TEMP−다. 필요하면 CH1−CH2로 두 핀의 차이를 본다. TEMP−라는 이름만 보고 스코프 GND를 그곳에 연결하지 않는다. 접지형 벤치 스코프의 채널 접지는 공통이므로 센서 리턴을 강제로 접지해 회로를 바꿀 수 있다. 스코프 보호접지는 해제하지 않는다.

DC coupling, 고임피던스 입력(통상 1MΩ)으로 측정하며 50Ω 종단을 추가하지 않는다. 대략 100ms/div에서 기동·느린 반복을 살피고, 1ms/div와 필요 시 더 빠른 시간축에서 펄스를 확인한다. 초기 수직 범위는 DMM 값보다 여유 있게 잡고, 배율은 실제 프로브/직결선과 맞춘다. 이전 측정처럼 긴 악어클립·점퍼선은 잡음에 영향을 주므로 연결을 짧게 유지하고, 정밀한 에지·잡음 수치보다 큰 전압 변화와 반복 패턴부터 판별한다. 평균값뿐 아니라 최저/최고 전압, 펄스 폭·주기, 기동 후 변화 여부를 남긴다.

참고: [Tektronix 프로빙 자료](https://download.tek.com/document/51W_60161_2_Probing-Techniques_AN.pdf)는 두 단일 종단 프로브의 공통 접지와 채널 차감 측정을 설명한다. 두 채널 차감의 정밀도는 채널·프로브 일치도에 의존한다.

## 4. 큰 저항으로 제한 부하를 걸기

첫 시도는 **관측된 TEMP 양단 전압이 안정된 DC이며 절댓값 15V 이하**인 경우로 제한한다. 15V는 계기판 핀의 확인된 허용 정격이 아니라 여기서 제안하는 저항 부하 시험의 조건이다. 큰 펄스·극성 변화가 있으면 그 파형을 먼저 해석하고 평균 DC값에 이 절차를 그대로 적용하지 않는다.

전원을 끄고 TEMP+와 TEMP− 사이에 **100kΩ, 1/4W** 고정 저항 하나를 연결한다. 다른 전원에는 연결하지 않는다. 실제 저항값은 회로에 연결하기 전에 측정한다. 정상 기동한 뒤 같은 조건에서 세 전압과 파형, 정상 UART 프레임을 기록한다. 이상 발열·리셋·예상 밖 전압 변화가 있으면 부하를 더 낮추지 않는다.

안정적인 경우 47kΩ, 그다음 10kΩ으로 바꾸어 반복할 수 있다. 교체는 매번 전원 OFF에서 한다. 개방 상태로 되돌렸을 때 원래 전압·UART 상태로 돌아가는지도 확인한다. 가변저항을 끝까지 돌려 0Ω이 되는 시험은 하지 않는다. 10kΩ보다 작은 부하는 측정된 바이어스와 전류를 검토한 뒤 별도로 결정한다.

부하에 흐르는 전류는 별도 전류계를 직결하지 않고 **I=|Vloaded|/Rload**로 구할 수 있다. 양단 15V 조건에서 100kΩ은 최대 0.15mA, 10kΩ은 최대 1.5mA이고, 저항 손실은 각각 최대 2.25mW/22.5mW다. 실제 전압은 부하에 따라 떨어질 수 있다. 이 계산이 모든 미확인 회로에서의 무조건적인 안전 보장은 아니다.

## 5. 저항식 바이어스 모델과 맞는지 보기

안정된 DC이고 개방/부하 측정 때 계기판 상태와 계측기 연결이 같다면, 다음 근사식을 사용할 수 있다.

```text
Rth ≈ Rload × (Vopen / Vloaded − 1)
```

예를 들어 개방 시 5.0V, 10kΩ 연결 시 2.5V이면 Rth≈10kΩ이다. 다른 저항에서도 비슷한 Rth가 나오면 해당 범위에서 선형 바이어스 회로처럼 동작한다는 근거다. **내부에 그 값의 풀업 저항 하나가 있다고 확정한 결과는 아니다.** DMM/스코프의 입력저항도 영향을 주므로 초기 특성화는 근사로 취급한다.

Vloaded가 Vopen과 거의 같거나 0에 가까우면 계산 오차에 민감하다. 주기적 여기, 상태 전환, 비선형 보호회로·전류 제한 등이 있으면 단일 Rth 모델이 맞지 않을 수 있다. 저항 변화에 따라 전압이 거의 비례하고 I가 일정하면 전류원 바이어스도 후보이며, 측정만으로 바로 특정 센서 종류를 확정하지 않는다.

온도 센서에 바이어스 저항과 분압 ADC를 쓰는 일반 구조의 1차 자료: [TI NTC 센싱 회로](https://www.ti.com/tool/CIRCUIT060002). 이 자료의 부품값은 AK550의 규격이 아니다.

## 6. 전기 반응과 UART를 함께 기록

| 연결 저항 | V+ 대 GND | V− 대 GND | 양단 Vloaded | DC/펄스와 범위 | 정상 CMD21 payload 전체 |
|---|---|---|---|---|---|
| 없음 | | | Vopen= | | |
| 100kΩ | | | | | |
| 47kΩ | | | | | |
| 10kΩ | | | | | |
| 다시 없음 | | | | | |

각 조건의 기동 후 같은 경과 시간과 수 초 이상의 안정 구간을 기록한다. UART는 기존 115200/8N1 수신 배선을 유지하고 새 저항 외의 조건을 바꾸지 않는다. 행을 연결하고 XOR가 맞는 프레임만 비교한다.

payload 8은 기존 raw−40 연산 때문에 우선 관찰할 후보지만, 전체 payload와 다른 명령도 함께 비교한다. 저항을 바꾸면 다른 상태 필드나 유효성 표시가 먼저 변할 수 있다. 정적인 한 값 또는 무반응만으로 그 핀이 미사용이라고 판정하지 않는다.

이 실험으로 저항→전압→UART 값 관계를 구할 수 있다. **원래 센서가 NTC인지 PTC인지, 정확한 R25/B값과 온도 정확도까지는 센서 규격이나 독립적인 온도 기준 없이 확정되지 않는다.**
