# B / 6 — 설치 확정 전 자원 검사

`opcode 67`은 COMMIT, `result 11` 또는 `Code B`는 확정 결과 불명확입니다. 이 Product 화면의 `phase 6`은 실패 상태이며 플래시 6번 섹터라는 뜻이 아닙니다.

0.9.44는 새 자원 검사가 끝나기 전에 COMMIT이 들어오는 순서 오류를 고칩니다. APK가 기존 본체에서도 검사 완료를 기다리므로 APK를 먼저 업데이트하세요. 같은 서명으로 덮어 설치하며 앱 데이터·설치 기록을 유지합니다.

1. 이미 오류 화면이면 현재 진단 자료를 저장합니다.
2. 위+O 시스템 재부팅을 지원하는 Product에서는 두 버튼을 함께 3초 유지해 재부팅합니다. Bootstrap 조작과 혼동하지 마세요.
3. 기존 CFW의 일반 주행 화면으로 돌아오면 앱의 ‘현재 CFW / 설치 결과 확인’을 실행합니다.
4. 정상 확정·설치 후보 없음·빈 업데이트 상태가 확인되면 과거 시도를 보관하고 새 업데이트를 진행할 수 있습니다. 대응 0.9.44 ZIP을 선택하세요.

후보가 남았거나 본체가 아직 실패 작업을 보유하고 있으면 그 상태를 강제로 풀지 않습니다. 진단 자료로 실제 상태를 확인해야 합니다. `11`은 실제 저장 실패에도 쓰이므로 숫자만으로 원인을 단정할 수는 없습니다. 현재 장치에서의 설치 성공은 실기 확인이 필요합니다.
