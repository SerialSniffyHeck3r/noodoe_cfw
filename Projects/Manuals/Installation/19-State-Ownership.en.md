# 0.9.41 installation state and work diagnostics

Controls remain the same as 0.9.40: UP+O for 3 seconds restarts the MCU.
DOWN+O opens quick settings; long UP recovers the display, long DOWN enables
Super Nite.

A confirmed rollback with no active write/commit permits another ZIP. The old
failure stays in history. Short O dismisses its notice immediately; dismissing
information does not cancel storage or confirm an installation.

Check current state reconciles the actual role, running image, boot result and
installation records. Read-only inspection has a 5-second queue / 60-second
total bound. Diagnostics distinguish the work owner, stage, blocker and age
since real progress. Storage waiting is not Bluetooth authentication failure.

Unknown work stays unknown. Preserve diagnostics and use the existing connection
recovery/Gate route. A new APK alone cannot replace the input code in an older
unit that cannot accept firmware.

A compatible 0.9.40 Gate uses normal Product update. Earlier Gates retain the
explicit keep-data migration path. Use the APK and ZIP from the same release.
