# Noodoe 전체 내부 플래시 A/B 검증 — 2026-09-11

## 결론

사용자가 새 ST-LINK로 읽고 저장한 A/B 파일은 각각 524,288바이트(512 KiB)이며 전체 바이트 비교에서 차이가 0개다. 두 파일의 SHA-256도 같다. 내부 플래시 주소 0x08000000–0x0807FFFF에 해당한다.

실물 덤프의 앱 부분은 기존 정적 분석에 사용한 SR1.5 V516 OTA 바이너리와 완전히 일치한다. OTA에 포함되지 않은 최초 64 KiB도 이번 파일에 포함되어 있다.

원본 파일은 수정하지 않았으며 이 검증에서는 하드웨어에 접근하지 않았다. 파일 두 개의 바이트 일치와 OTA 대조를 검증한 것이며, GUI에서 각각 어떤 조작으로 파일을 생성했는지는 이 오프라인 검사만으로 재현하지 않는다.

## 기존 OTA와 앱 비교

기준 OTA:

`artifacts/ota-archive/2026-08-31-full/blobs/firmware/1657088080998-s1-SR1.5_ota_V516.bin`

- 비교 길이: 458,748바이트(0x6FFFC).
- 덤프 오프셋: 0x10000–0x7FFFB.
- MCU 주소: 0x08010000–0x0807FFFB.
- A와 OTA 사이의 다른 바이트: 0개. A와 B가 전체 일치하므로 B에도 같은 결과가 적용된다.
- OTA SHA-256: `3b64673054ca84b9cf504f4cc7ebcb2e6615b9fbf59df79a37a92dcf14f037ca`.
- 덤프의 마지막 4바이트(0x0807FFFC–0x0807FFFF): `FF FF FF FF`. 이 4바이트는 OTA 파일에 없다.
- 동일 OTA 폴더의 나머지 8개 BIN과는 일치하지 않았다.

이 결과는 기존 UART·GPIO·USB·업데이트 정적 분석에 사용한 해당 앱 바이너리가 실제 모듈의 앱 영역과 같다는 직접적인 근거다. 앱 영역 일치가 별도의 부트로더 구현까지 입증하는 것은 아니다.

## 벡터 확인

| 위치 | 초기 MSP | Reset 벡터 |
|---|---|---|
| 0x08000000 | 0x2000FA08 | 0x080004C5 |
| 0x08010000 | 0x20025318 | 0x08076719 |

두 초기 스택 포인터는 SRAM 주소이며 Reset 벡터는 각 플래시 영역 안의 Thumb 주소다. 부트 벡터의 일부 예외 핸들러는 SRAM 주소를 가리킨다. RAM 복사·실행 여부는 부트 코드 분석으로 별도 확인할 사항이다.

## 보존 범위와 남은 작업

이번 검증은 내부 플래시 512 KiB에 한정된다. OTP·잠금 바이트, UID, 옵션 바이트, 공장 ROM의 별도 백업 여부는 이 두 파일로 확인할 수 없다.

외부 SPI5 NOR의 USB 노출 127.5 MiB는 기존에 두 이미지의 일치를 확인했다. 기존 펌웨어 분석상 USB에서 제외되는 NOR 끝 512 KiB는 별도 보존 대상이다. 자세한 근거는 [USB 수집 기록](../../docs/2026-09-09-noodoe-usb-acquisition.md)을 참고한다.

검증 도중 메모리 쓰기, 지우기, 보호 설정 변경은 수행하지 않았다.
