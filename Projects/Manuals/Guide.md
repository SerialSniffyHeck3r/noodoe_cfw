## 0.15.11 — 정보 줄과 앱 날씨·지도

앱 빌드 160과 본체 펌웨어 0.15.11을 함께 사용합니다. APK는 기존 앱 위에 설치하며 데이터 삭제가 필요하지 않습니다.

- MAP 정보 줄은 HOME의 수동/AUTO 설정과 선택 항목을 따릅니다. 안내 중 MAP과 전체 TBT에서는 기존처럼 목적지 거리·남은 시간 / 목적지 거리·도착시각 두 장만 10초마다 순환합니다.
- 정보 항목에 **TRIP**을 추가했습니다. TRIP 페이지에서 선택한 **A / B / F(주유 후) / T(오늘)**의 거리와 주행 시간을 표시합니다. 시간은 시:분이며 값이 없거나 표시 범위를 넘으면 대시가 나옵니다. 기존 숫자 서체를 사용합니다.
- 한 줄 정보는 통화 연결 시 녹색 통화 칸을 우선 표시합니다. 시간은 `00:00'00"`이며 구분기호만 깜빡입니다. **수동:** 위/아래 길게로 다른 항목을 선택하면 유지합니다. **AUTO:** 잠시 다른 항목을 본 뒤 20초 후 통화 칸으로 돌아갑니다. 통화 종료 후 기존 정보로 복귀합니다. 안내 중 MAP/TBT의 목적지 정보는 유지합니다.
- 두 줄 HOME은 음악 재생 중 음악 정보를 유지합니다. 곡·음악 정보 변경은 페이지 전환 애니메이션 없이 표시합니다. 수동/AUTO 전환은 각각 팝업으로 알려 줍니다.
- 긴 본체 토스트는 `...`로 자르지 않고 자동으로 가로 스크롤합니다. 마지막 문구를 읽을 시간을 확보하고, 자주 나오는 긴 안내는 짧게 다듬었습니다.
- 앱 HOME의 날씨 줄을 누르면 날씨를 엽니다. 본체와 같은 웃는 해/Meteocons 아이콘과 부드러운 두 색상 바를 사용합니다. 위는 날씨 상태, 아래는 강수량이며 현재~12시간 후를 나타냅니다. API가 실제 제공한 시간별 자료만 표시합니다.
- 앱 내비게이션 탭에 지도와 현재 안내, 현재 위치·전체 경로·지도 파일 버튼이 함께 표시됩니다. 기존 전체 화면 지도도 사용할 수 있습니다. 지도 파일과 위치 권한이 필요하며 탭을 닫아도 실행 중인 안내를 중단하지 않습니다.
- **지금 날씨 갱신**은 오토바이에 연결되지 않아도 가능합니다. API 키·실제 최근 위치·인터넷 연결이 필요하며 수동 갱신은 60초 간격입니다. 화면을 여는 것만으로는 API를 호출하지 않습니다. 자동 조회는 본체 연결 완료 후 한 번, 이후 본체 날씨 페이지에서 1시간 또는 30km 조건을 따릅니다. 미연결 중에는 자동 조회하지 않습니다.
- 본체에 날씨가 없으면 슬래시 구름 아이콘과 커진 대기 문구가 나옵니다. 날씨는 RAM에서 표시하며 NOR에 기록하지 않습니다.

## 0.15.10 hotfix1 — 앱 버튼과 연결 시 날씨

앱 빌드 159를 기존 앱 위에 설치하세요. 본체 0.15.10 펌웨어와 내장 자원은 동일하여 본체를 다시 업데이트할 필요가 없습니다. 자동 연결 중 날씨·지도·사진 선택 버튼이 눌리지 않거나 앱으로 돌아온 뒤 비활성화되는 문제를 수정했습니다.

날씨를 켠 상태에서 NewDoe와 실제 연결이 완료되면, 최근 위치와 API 키가 준비되는 즉시 한 번 조회하여 본체 RAM으로 전송합니다. 이후 자동 조회는 본체 날씨 화면에서 마지막 조회 후 1시간 또는 30km 이동 시에만 합니다. 미연결 중 자동 조회는 중단하지만, 사용자가 누른 수동 갱신은 가능합니다. 위치가 없으면 기다리며 임의 위치로 조회하지 않습니다.


## 0.15.10 — 연결·화면·조작 정리

앱과 본체를 함께 업데이트하세요. 기존 앱 위에 APK를 설치하면 설정과 데이터를 유지합니다. 기기를 선택하고 필요한 권한을 허용하면 자동으로 연결하며, 별도의 주행 연동 시작·중지 버튼은 없습니다. 연결한 상태에서도 설정 전송, 사진 전송, 업데이트를 시작할 수 있습니다. 설치 확인 뒤 앱이 통신 작업을 순서대로 전환하며, 진행 중인 쓰기나 결과가 불명확한 설치를 무시하지 않습니다.

- **HOME:** 위/아래 짧게로 1줄 → 2줄 → 속도 → 선택한 시계 → TBT → 날씨를 고릅니다. 정보 줄이 있는 일반 보기에서 **O 길게**는 수동/AUTO 전환, **위/아래 길게**는 정보 넘기기입니다. AUTO에서 넘긴 정보는 20초 뒤 원래 순환으로 돌아갑니다. 선택값은 키 OFF에 저장합니다. 날씨의 O 길게 예보 조작은 그대로입니다.
- **지도:** HOME 지도는 없애고 전용 MAP에 정보 줄을 넣었습니다. 안내 중 MAP·전체 TBT는 거리＋남은 시간 / 거리＋도착시간을 10초마다 순환합니다. 안내가 없으면 MAP은 HOME의 수동/AUTO 설정과 정보 선택을 따릅니다. 지도 버튼 조작은 유지합니다.
- **TBT:** 두 번째 안내는 제거했습니다. 둥근 카드 안에서 왼쪽 화살표, 오른쪽 고정 폭 거리, 그 아래 외부 앱 도로명을 표시합니다. 내장 BRouter는 도로명을 만들지 않습니다. 500m 이내 강조는 **미니 안내의 숫자만** 노란색으로 점멸하며, 테두리·번짐·전체 TBT 글자 점멸은 없습니다. 전체 TBT에는 미니 안내를 중복 표시하지 않습니다.
- **축척:** 안내 중 넓게 보기는 500m 축척까지 허용하되 회전 500m 이내 접근 중에는 최대 50m로 좁힙니다. 기존 속도 기반 AUTO와 사용자가 고른 축척은 유지합니다. 밀집 지도의 화면 전환에서는 표시 중인 그래픽 자원을 덮어쓰지 않습니다.
- **날씨:** 날씨를 켠 상태에서 NewDoe와 실제 연결이 완료되면, 최근 위치와 API 키가 준비되는 즉시 한 번 조회하여 본체 RAM으로 전송합니다. 이후 자동 조회는 본체 날씨 화면에서 마지막 조회 후 1시간 또는 30km 이동 시에만 합니다. 미연결 중 자동 조회는 중단하지만, 사용자가 누른 수동 갱신은 가능합니다. 위치가 없으면 기다리며 임의 위치로 조회하지 않습니다. 갱신 중 로딩 아이콘, 완료 후 경과 시간과 부드러운 예보 바를 유지합니다.
- **음악·전화:** 같은 곡으로 음악 페이지에 돌아오면 앨범 이미지를 재사용합니다. 로딩 아이콘과 Media Off 화면을 구분하며, 언어 설정에서 음악과 알림의 폰 렌더링을 각각 선택할 수 있습니다. 통화 중 스마트폰 첫 페이지에는 부재중 전화 수 대신 통화 시간을 표시합니다. 숫자는 고정하고 시간 구분기호만 깜빡입니다. 분·초 기호는 숫자 윗부분에, 콜론은 가운데에 표시합니다.
- **연료·ODO:** 맨 아래에는 ODO와 예비연료 거리만 표시합니다. 다른 트립 기록은 트립 페이지에 유지합니다. 연료가 0칸에서 1칸 이상으로 5초간 안정되면 예비연료 기록을 초기화하고 ODO로 돌아갑니다. 키 ON 뒤 새 유효 연료값을 받기 전에는 이전 값으로 연료 부족을 경고하지 않습니다. 연료 부족 문구와 아이콘은 제자리에 두고 아이콘만 깜빡입니다.
- **시동·설정:** 속도로 화면을 강제 복귀하거나 설정·전화 항목을 막지 않습니다. 조작은 정차 후 진행하세요. 키 OFF의 별도 배경과 상단 표시, 키 ON의 라이더 인사는 제거했습니다. 키 OFF 사용 중에는 회색 링으로 구분하고 STOP 시간을 늘리지 않습니다. 초기 설정 완료 때는 이전 편집 문구 없이 재시작 안내를 표시합니다.
- **밝기:** 자동 밝기에서 O＋아래 짧게를 누르면 퍼센트 대신 자동 밝기 수준을 조절합니다. 수동 밝기는 퍼센트를 조절합니다.
- **진단:** 일반 펌웨어에는 전체 NOR 백업 명령이 없습니다. 파일 읽기와 기존 복구는 유지하며, 전체 백업은 별도 진단 펌웨어에서만 사용합니다. 일반 업데이트를 위해 진단 펌웨어를 설치할 필요는 없습니다.
- **폰 지도:** 안내 시작 전에도 현재 위치를 표시하고, 큰 지도와 현재 안내를 함께 봅니다. 경로 파일 관리와 일반 안내 화면은 분리합니다.

아래는 실제 ARM/LVGL/EVE 코드의 소프트웨어 렌더링입니다. 실차 LCD·무선 검증 사진이 아닙니다. 오래된 버전의 설명과 사진은 해당 버전의 기록이며, 현재 조작은 이 절과 아래 사용법을 따르세요.

### 진단 모드와 일반 펌웨어 복귀

일반 펌웨어가 정상 설치·부팅된 뒤 앱은 기존 비활성 펌웨어 슬롯에 진단 이미지를 준비합니다. 최초 준비에는 앱이 필요하지만, 준비 완료 뒤에는 **본체 설정 → 시스템 → 진단 모드**로 폰 없이 들어갈 수 있습니다. 앱에서도 진단 모드를 실행할 수 있습니다. 별도 NOR 파일을 만들거나 Gate를 교체하지 않습니다.

진단 화면은 **Return to normal firmware(일반 펌웨어로 돌아가기)**가 기본 선택입니다. 검증 완료 뒤 **O 짧게**를 누르면 진단 진입 전의 일반 펌웨어를 다시 설치하고 재부팅합니다. 설정·트립·사진·보충 폰트·페어링을 초기화하지 않습니다. 앱의 **일반 펌웨어로 돌아가기**도 같은 동작입니다. 재부팅이므로 화면의 일시적 RAM 내용은 다시 생성하며, 날씨·음악·안내 정보는 연결 후 폰에서 다시 받습니다.

- **NOR backup to phone:** 키 OFF 상태에서 선택하고 O를 누릅니다. 페어링된 폰에서 NewDoe를 열어 두면 전체 128MiB를 읽기 전용으로 저장합니다. 진행률은 양쪽에 표시합니다. O 3초 또는 키 ON으로 중단하면 부분 파일을 남기고 기존 재시작 절차를 따릅니다.
- **Send diagnostic log:** O를 누르면 연결된 NewDoe 앱이 진단 로그를 휴대폰에 저장합니다. 전화 연결이 없으면 앱 연결 대기를 표시합니다.
- 나머지 항목은 Bluetooth 시작·페어링·컨트롤러 점검, 조도 센서 측정·ID·주소 확인입니다. 시험 결과와 오류 코드를 표시하며, 큐에 들어갔다는 사실을 성공으로 표시하지 않습니다.
- **Back to stock**은 원래 KYMCO 펌웨어 복구용 별도 항목입니다. 일반 NewDoe 복귀는 **Return to normal firmware**를 사용합니다.

전환은 즉시 실행되는 NOR 부팅이 아니라 기존 Gate의 검증·내부 플래시 복사입니다. 일반 업데이트 중에는 비활성 슬롯을 후보·롤백용으로 사용하고, 새 일반 펌웨어의 정상 부팅이 확인된 후에만 진단 이미지로 다시 준비합니다. 반환 이미지가 검증되지 않으면 복귀를 시작하지 않습니다. 진단 부팅 초기에 반환 기록을 만들기 전 전원이 끊기면 기존 Gate 복구 화면에 머무를 수 있습니다. 이 구간까지 자동 정상 복귀가 검증됐다고 주장하지 않습니다.

![NOR 백업 진행](images/guide-0.15.10/diagnostic-backup.png)

진단 이미지는 실제 ARM/EVE 명령으로 배치를 검증한 소프트웨어 렌더링입니다. EVE ROM 글자의 윤곽은 대체 폰트이며, 배치는 캡처한 ROM 치수를 사용합니다.

## 0.15.9 — 목적지 정보 하단바와 통화 표시

전체 TBT의 위쪽 카드에는 현재 회전과 거리를 표시하고, Google Maps·OsmAnd에서 받은 도로명을 거리 아래에 표시합니다. 내장 BRouter 경로 파일에는 도로명이 없어 해당 줄을 비웁니다. 이전의 두 번째 안내 영역은 비워 두고 목적지까지의 정보는 기존 HOME 하단바에 표시합니다.

- 안내 중 **전체 TBT / HOME 지도 / MAP**에서는 하단바가 **남은 거리 + 남은 시간**, **남은 거리 + 도착 예정 시각** 두 항목만 10초마다 순환합니다. 이 화면에서는 O 길게 누르기로 다른 정보를 선택하지 않습니다. 다른 HOME 모드와 안내 OFF의 정보 선택은 그대로 유지됩니다.
- 남은 시간은 `102.4 km / 00'34"`(분·초), 한 시간 이상은 `102.4 km / 3:52'`(시·분)입니다. **구분기호만 0.5초 간격으로 깜빡이고 숫자는 고정**됩니다. 도착 예정 시각은 `102.4 km / 15:42`로 계속 표시됩니다. 기존 하단바 숫자 서체와 크기를 사용합니다.
- 내장 BRouter 안내는 경로의 예상 소요시간과 현재 경로 진행 위치를 사용합니다. 도착 시각은 휴대폰 현지 시각 기준이며 실제 도착을 보장하는 값은 아닙니다.
- Google Maps는 현재 안내 알림에 실제 포함된 목적지 거리·남은 시간·도착 시각만 가져옵니다. 알림 버전·언어에 따라 일부 값이 없을 수 있으며, 없는 값은 `--.- km / --:--`로 표시합니다. 거리 단위가 마일이면 `--.- mi`로 표시합니다. Wear 앱을 추가 설치할 필요가 없습니다. OsmAnd의 시간 정보는 이번 변경에서 추가하지 않습니다.
- 재탐색·연결 끊김·오래된 안내에서는 이전 시간 정보를 최신 값처럼 유지하지 않습니다. 통화 중 상단 전화기 아이콘은 **1Hz(0.5초 표시 / 0.5초 숨김)**로 깜빡이고, 통화가 끝나면 기존 Bluetooth 표시로 돌아옵니다.

![도착 예정 시각 — 고정 표시](images/guide-0.15.9/arrival.png)

위 이미지는 실제 ARM/LVGL/EVE 코드의 소프트웨어 렌더링입니다. 실차 및 실제 Google Maps 알림 조합의 확인은 별도로 필요합니다. Gate·기존 NOR 파일 이름과 크기·설정 저장 형식은 변경하지 않습니다.

## 0.15.8 — 내비 축척 제한·다음 회전·빠른 답장

이 절의 두 번째 TBT 카드 설명·그림은 0.15.8 당시 기록입니다. 현재 배치와 축척은 위의 0.15.10 안내를 따릅니다.

- 안내 중 누도 지도는 **50m 축척까지만** 축소됩니다. 더 넓게 설정했어도 화면에는 50m와 **NAV**가 표시되며, 안내 종료 후에는 저장된 축척을 다시 사용합니다. 20m 확대는 유지됩니다. 작은 도로는 밀집도에 따라 줄이고 주요 도로와 보라색 경로를 우선합니다. 휴대폰의 큰 지도 확대·축소는 그대로 사용할 수 있습니다.
- HOME TBT의 **위쪽 둥근 카드**는 현재 회전, **아래쪽 작은 카드**는 그 다음 회전입니다. 아래 거리는 **현재 회전 지점에서 다음 회전 지점까지**의 거리입니다. 다음 회전이 없으면 아래 카드는 표시하지 않습니다. 도로명 자리에 내비 사용 중이라는 문구는 넣지 않으며, 회전교차로 출구 번호는 유지합니다.
- 재탐색 중에는 글자 대신 **원형 화살표 아이콘**을 표시합니다. 이전 회전은 숨기고 경로는 흐리게 남습니다. 상단 메뉴가 5초 뒤 사라지면 **전체 TBT 화면을 제외한 TRIP·음악·알림·MAP 등 주행 화면**에 미니 TBT가 나타납니다. 설정·전화 등 우선 화면의 기존 가림 규칙은 유지합니다.
- 지도 방향은 **북쪽 위 / 진행 방향 위** 두 가지입니다. 별도 대형 나침반은 제거했습니다. 안내가 꺼진 HOME TBT는 **내비게이션 비활성**을 표시하며, 하단 정보 줄의 작은 나침반은 유지합니다.
- 답장 가능한 알림에서 빠른 답장을 열면 **목적지 / 도착 예정 공유** 항목을 선택할 수 있습니다. 폰이 현재 목적지·남은 거리·예상 소요시간과 도착시간을 작성해 기존 답장 기능으로 보냅니다. 오래된 위치나 안내 없음 상태에서는 보내지 않습니다. 이 항목은 현재 내장 안내에 적용되며 Google Maps/OsmAnd의 목적지나 ETA를 추측하지 않습니다. 본체가 자동으로 보내지는 않습니다.
- Google Maps/OsmAnd는 현재 알림 연동에서 **그 다음 회전 방향**을 신뢰할 수 있게 제공하지 않으므로 현재 안내만 표시합니다. OsmAnd 알림의 추가 거리만으로 다음 화살표를 만들지 않습니다.

## 0.15.7 — 휴대폰 지도·재탐색 표시·날씨 배치

- **내비 → 안내 지도 보기**에서 큰 지도, 현재 위치, 보라색 전체 경로, 다음 회전과 목적지 잔여거리를 함께 봅니다. 자체 안내를 시작하면 이 지도가 열립니다. 지도를 끌면 위치 따라가기가 멈추며 **현재 위치**를 누르면 다시 따라갑니다. **전체 경로**는 목적지까지 한눈에 보여줍니다. 뒤로 가거나 앱 화면을 바꿔도 기존 주행 연동과 누도 안내는 계속됩니다. **안내 종료**를 확인하면 안내만 종료합니다.
- 본체의 문구는 **내장 내비게이션 사용 중**으로 바뀌었습니다. 경로 이탈 후 재탐색 중에는 휴대폰과 본체 TBT 영역에 재탐색 상태를 표시합니다. 이때 이전 회전 화살표를 현재 안내처럼 표시하지 않으며 경로는 흐리게 남습니다. GPS가 오래되거나 연결이 끊겨도 마지막 거리를 최신 안내로 표시하지 않습니다.
- 넓게 축소한 지도는 필요하면 세부 도로를 줄여 표시합니다. 경로 계산은 원본 경로로 수행하며, 본체에 보내는 주변 경로만 단순화합니다. 휴대폰의 전체 경로는 유지됩니다.
- HOME에서 **1줄/2줄 정보 스트립만 표시하는 모드**는 사진을 밝게 보여줍니다. 속도·지도·TBT·시계·날씨가 있는 모드는 기존의 진한 음영을 유지합니다.
- HOME 날씨에서 **O를 길게** 누른 뒤 **위·아래**로 **+1~3시간 / +4~6시간**을 전환합니다. 상세 화면은 시간별 세 칸이며 최고/최저·페이지 문구는 없습니다. 온도와 도 기호를 아이콘에서 떨어뜨렸고 강수량은 푸른 숫자로 표시합니다. **O**로 개요에 돌아갑니다. [날씨 조작법](User/38-Solar-Weather.md).

## 0.15.5 — 화면 안정성·초기 설정·TBT·날씨 수정 (빌드 150)

APK를 기존 앱 위에 설치한 뒤 **기기 → 현재 상태 확인 → 설치 계속 / 언어 확인**으로 진행하세요. 앱에는 해당 버전과 일치하는 펌웨어가 포함됩니다. 안내되는 언어와 업데이트 내용을 확인하고 시작하세요. 기존 미완료 작업이 있으면 결과 확인을 먼저 진행합니다.

- 실제 순정 자원에서 확인된 `files` / `allFiles` 두 목록 형식을 읽도록 앱과 본체를 수정했습니다. 구형 CFW 식별은 루트·FAT·자원 헤더만 읽으며 사진 하위 폴더 전체를 훑지 않습니다. 이 단계는 읽기 전용입니다. 쓰기 전 전체 저장소 검사, Gate 호환 검사와 사용자 데이터 보존은 유지합니다.
- **Unknown stock font profile**은 무조건 B로 처리하지 않습니다. 지원하지 않는 ID, 손상·모순·읽기 실패는 쓰기를 멈추며 실패 이유와 숫자형 식별 정보가 진단에 남습니다. 해당 사용자의 헤더 자체는 기존 진단에 없어 그 차량의 모든 원인이 해결됐다고 단정할 수는 없습니다.
- **기기 → 날씨 → 날씨 API → Basic API 2.5**를 선택하면 One Call 없이 현재 날씨와 3시간 간격 예보를 사용합니다. 선택만으로 조회하지 않으며 **키 확인 · 날씨 조회**를 누르면 됩니다. 기존 One Call 선택은 그대로 보존합니다.
- Basic은 오늘 최고·최저를 제공하지 않아 앱에는 `—`, 본체에는 `--`가 나옵니다. 예보 바는 3시간 구간을 근사하며 강수량은 구간 평균 mm/h입니다. 실제 시간별 예보가 필요하면 One Call을 사용하세요. API를 바꾸면 이전 자료와 인증 결과를 지우고 새로 확인합니다.

- 내비·날씨에서 다른 화면으로 넘어간 뒤 숫자가 빠지거나 깨지던 EVE 캐시 경로를 수정했습니다. TBT의 두 자리 거리는 고정 칸의 오른쪽에 정렬하고, 목적지 거리·일출·일몰에는 숫자 전용 서체를 사용합니다. HOME AUTO 정보는 내용만 바뀌며 페이지 전환 애니메이션을 다시 시작하지 않습니다.
- HOME 사진 음영을 속도 화면과 통일했습니다. 시계와 날씨에도 적용하며 날씨의 사각 카드는 제거했습니다. 키 OFF의 마지막 확인 ODO를 유지하고, 요약의 정비 계산도 보존된 ODO를 사용합니다. 한 번도 확인하지 못한 값은 만들지 않습니다.
- 초기 설정의 모든 단계는 검은 배경입니다. 이전 HOME·버튼 안내·일반 팝업이 섞이지 않으며, 시간대는 `UTC+09:00`처럼 표시합니다. 위·아래로 15분씩 조절하고 O로 확정하세요. `UTC-03:30`, `UTC+05:45` 같은 시간대도 설정할 수 있습니다.
- TBT 노란 강조는 실제 남은 거리가 **500m 이하**일 때 켜집니다. 자체 안내의 선택적 올림은 **10m 단위**입니다. 예: 91m → 100m, 101m → 110m. 연결 단절·오래된 안내는 강조하지 않습니다.

날씨 자료·새 API 키를 공개할 필요는 없습니다. 소프트웨어 시험과 화면 렌더링으로 검증했으며 실차 연결과 실제 계정 날씨 조회는 별도 검증입니다. Gate 바이너리·복구 로직·NOR 파일 배치는 변경하지 않습니다. 기존 순정 복귀 구간의 전원 차단 제한은 그대로입니다.

본체가 이미 0.15.4이면 **APK만 기존 앱 위에 설치**하세요. 펌웨어·Gate·NOR 파일은 바뀌지 않으며 이전 핫픽스도 포함됩니다.

- **내비게이션 → 지도에서 목적지 선택**을 누르면 바로 큰 지도가 열립니다. 지도를 끌거나 확대해 중앙 표시를 목적지에 맞춘 뒤 **이 위치 선택 → 오프라인 안내 시작**을 누르세요. 현재 위치로 돌아가기와 지도 파일 관리 버튼도 있습니다. 마지막으로 보던 지도 영역을 기억하며, 새 GPS 위치가 있으면 처음 열 때 현재 위치를 보여줍니다. 지도 선택 결과는 원래 내비 화면으로 돌아옵니다.
- 차량 연결 판정은 기기 탭에서 선택한 누도와 실제 주행 연결을 사용합니다. 구형 화면의 선택값 때문에 연결된 차량을 거절하던 오류를 수정했습니다. 페어링만 된 상태에서는 상단 ▶로 주행 연결부터 시작하세요. 다른 차량·지원하지 않는 펌웨어·끊긴 연결은 안내 시작이 계속 제한됩니다.
- **기기 → 날씨**에서 API 키의 미등록·저장됨·승인됨·인증 거절·확인 실패 상태와 마지막 확인 시각, 실제 HTTP 응답 코드를 볼 수 있습니다. 키 자체는 표시하거나 진단에 기록하지 않습니다.
- **키 확인 · 날씨 조회**는 현재 휴대폰 위치로 직접 1회 조회합니다. 본체 연결 중에만 가능하며, 위치 권한과 위치 서비스가 필요합니다. 현재 날씨·기온·오늘 최고/최저와 +0~+12시간 예보를 텍스트로 표시합니다. 저장된 키만으로 인증 성공이라 표시하지 않습니다. HTTP 401/403이면 키 또는 One Call 이용 권한을, 429이면 제공업체 할당량을 확인하세요. 통신 실패는 키가 틀렸다고 단정하지 않습니다.
- 날씨를 켠 상태에서 NewDoe와 실제 연결이 완료되면, 최근 위치와 API 키가 준비되는 즉시 한 번 조회하여 본체 RAM으로 전송합니다. 이후 자동 조회는 본체 날씨 화면에서 마지막 조회 후 1시간 또는 30km 이동 시에만 합니다. 미연결 중 자동 조회는 중단하지만, 사용자가 누른 수동 갱신은 가능합니다. 위치가 없으면 기다리며 임의 위치로 조회하지 않습니다. 수동 재시도는 60초 간격입니다. 예보는 RAM에만 보관합니다.

이번 검증은 자동 시험과 Android 화면 렌더링입니다. 실제 휴대폰·차량의 Bluetooth 및 스크롤 체감, 사용자 키로 OpenWeather 실조회는 별도로 확인해야 합니다.

## 0.15.4 Hotfix 4 — 날씨 전송 중 연결 종료 수정 (빌드 148)

**content / 0x9D / IllegalArgumentException / VisualTransfer** 오류가 나면 Hotfix 4 APK를 기존 앱 위에 설치하고 다시 연결하세요. 현재 날씨 패킷은 256바이트인데 앱의 전송 검사에는 과거 크기가 남아 있었습니다. 날씨 OFF나 API 키 미등록 상태의 ‘표시 지우기’ 패킷도 이 검사에 걸릴 수 있었으며, 이를 수정했습니다. 화면의 0x9D는 직전 통신 명령으로, 이 Java 예외의 발생 원인은 날씨 패킷 크기 검사였습니다.

본체가 0.15.4로 정상 부팅한다면 **APK만 갱신**하면 됩니다. 이 오류를 해결하기 위해 API 키를 등록하거나, 앱 데이터를 삭제하거나, 재페어링·순정 복귀할 필요는 없습니다. 날씨 조회에는 여전히 별도 API 키가 필요하며, 조회 주기와 표시 방식은 그대로입니다. 이전에 미완료된 설치 기록이 있다면 그 결과는 별도로 확인하세요. 이전 핫픽스의 수정도 모두 포함합니다.

## 0.15.4 Hotfix 3 — 업데이트 준비·연결 상태 표시 (빌드 147)

Hotfix 3 APK를 기존 앱 위에 설치한 뒤 **현재 기기 상태 확인**을 누르세요. 연결 후에는 복구·폰트 확인, NOR 원본 확인, 저장된 언어 확인을 구분해 표시하고, 실제 기기 응답을 받을 때마다 응답 시간을 갱신합니다. 읽기 전용 확인 실패를 펌웨어 설치 실패로 표시하지 않습니다. 이전 미완료 작업이 있다면 그 결과는 여전히 확인해야 합니다.

완료된 구버전 설치 파일만 남아 있으면 **설치 계속 / 언어 확인**에서도 최신 패키지 준비로 안내합니다. 아직 진행 중인 설치는 원래 파일과 기록을 유지합니다. 준비 완료 후 언어와 업데이트 내용을 확인하고 직접 설치를 시작하세요. 최신 APK와 일치하지 않는 구버전 본체는 업데이트해야 주행 연동이 시작됩니다.

이미 본체가 0.15.4이면 APK만 갱신하세요. Hotfix 1·2 수정도 포함하며 펌웨어·Gate·NOR 배치는 바꾸지 않습니다. 계속 실패하면 기기를 초기화하지 말고 진단 ZIP을 저장하세요. 새 ZIP에는 앱 빌드, 두 번째 확인 단계 및 응답이 없던 명령 번호도 포함됩니다. 실차 Bluetooth 재시험은 아직 하지 않았습니다.

## 0.15.4 — 시계 음영과 초기 설정 개선

앱과 본체 펌웨어를 함께 업데이트하세요. 앱의 **앱에 포함된 패키지 사용**에서 실제 기기 상태와 설치 언어를 확인한 뒤 진행합니다. 기존 Gate와 NOR 파일 배치는 유지하며, 정상 기기는 Product 업데이트를 사용합니다. 기존 사용자를 자동 초기화하거나 초기 설정을 강제로 다시 실행하지 않습니다.

### 처음 설치했을 때

1. 초기 설정 실행이 예약되어 있으면 일반 키 ON 호 채움·축소 연출을 건너뛰고 첫 설정 화면으로 바로 시작합니다. 검은 화면 중앙에 **WELCOME! / NEWDOE**와 깜빡이는 **Press Any Key To Continue**가 나오면 위·아래·O 중 아무 버튼을 누르세요. 다음 **차량을 멈춰 주세요 / O를 눌러 계속하세요** 안내에서 정차 후 O를 누르면 설정을 시작합니다. 시간 경과로 자동 진행하지 않습니다.
2. **언어 → 일출·일몰 기준 지역 → 실제 연료 칸수 → 연료량 인식 사용 여부 → 단위 → 시간대 → 속도 호의 최대값** 순서입니다. 위·아래로 값을 고르고 O로 저장하며 진행합니다. 언어는 영어와 설치된 언어 중 고릅니다.
3. 연료 칸수는 원래 계기판의 0~5칸을 입력하세요. 시동 ON에서 안정된 UART 수신값과 비교합니다. 일치하면 연료량 인식 ON, 불일치하거나 지원되지 않는 값이면 OFF를 권장합니다. 위·아래로 권장값을 바꿀 수 있으며 O를 눌러야 저장합니다. 값이 오지 않거나 아직 안정되지 않았다면 기다리거나 **Skip**을 선택하세요. 수신 실패만으로 미지원이라고 단정하지 않습니다.
4. 저장을 마치면 본체가 재시작합니다. 저장 실패 때는 완료로 넘어가지 않으므로 표시를 확인하고 재시도하세요. 휴대폰이 연결돼 있으면 현재 단계의 설명과 조작법이 앱에 자동 표시됩니다. 이 안내는 본체의 설정이 진행되는 동안 닫을 수 없으며, 재연결하면 현재 단계로 돌아옵니다.
5. 나중에 **설정 → 시스템 → 초기 설정(재시작)**으로 다시 실행할 수 있습니다. 마법사와 무관한 설정은 유지합니다. 별도 **시스템 설정 초기화**는 확인 후 시스템 환경설정을 초기화하므로 두 기능을 구분하세요. 트립·정비·사진·페어링은 보존합니다.

### 날씨 사용

날씨는 기본 OFF입니다. 휴대폰 앱의 **날씨**에서 본인의 **선택한 OpenWeather API 사용이 가능한 키**를 저장하고 켜세요. 별도 서비스 계정·이용 조건 및 요금이 적용될 수 있으며, NewDoe가 공용 키를 제공하지 않습니다. 키가 없으면 날씨를 끈 채 다른 기능을 사용할 수 있습니다.

#### OpenWeather 등록부터 첫 표시까지

1. [OpenWeather 계정 만들기](https://home.openweathermap.org/users/sign_up)에서 본인 계정을 만들고 이메일을 인증합니다. 계정의 [API keys](https://home.openweathermap.org/api_keys)에서 본인 키를 확인합니다. 새 키는 활성화에 시간이 걸릴 수 있습니다. [공식 가입·키 안내](https://openweathermap.org/faq)
2. **날씨 API**를 선택합니다. **Basic API 2.5**는 현재 날씨와 5일/3시간 예보를 조회해 +12시간 구간을 사용하며 One Call 가입이 필요하지 않습니다. 한 번 갱신에 현재·예보 요청 2회를 사용합니다. 오늘 최고·최저는 제공되지 않습니다. **One Call 3.0**은 시간별·일별 정보를 제공하며 별도 이용 권한이 필요합니다. 현재 계정의 한도·요금을 확인하세요. 키가 맞아도 선택한 서비스 권한이 없으면 401이 나올 수 있습니다. [기본 예보 API](https://openweathermap.org/forecast5) · [One Call 안내](https://openweathermap.org/api/one-call-3)
3. NewDoe 앱의 **기기 → 날씨 → 키 저장**을 눌러 입력 창을 열고, 본인 키를 붙여 넣어 저장합니다. 키는 비밀번호처럼 가려지며 저장한 키를 다시 표시하지 않습니다. 키를 Discord나 오류 사진에 공개하지 마세요. NewDoe 공용 키는 없습니다.
4. **날씨 사용**을 켜고, 휴대폰의 인터넷·위치 서비스와 NewDoe 위치 권한을 확인합니다. 날씨 위치는 휴대폰의 현재 GPS 위치이며, 초기 설정에서 고른 일출·일몰 기준 도시와 별개입니다.
5. 휴대폰과 본체를 연결하면 위 조건에 따라 첫 조회와 전송이 진행됩니다. 본체 **HOME → 위·아래 → 날씨**에서 결과를 확인하세요. 앱의 **키 확인 · 날씨 조회**도 본체 연결 중에만 사용할 수 있습니다. 폰 화면을 열기만 해서는 조회하지 않습니다.
6. 앱에 **예보 준비 완료**와 갱신 시각이 나오면 본체의 현재 온도와 두 예보 바(One Call이면 오늘 최고·최저도)를 확인합니다. 본체 단위 설정에 따라 온도를 변환하며 숫자 옆에는 도 기호만 표시합니다. 위의 시계와 ODO는 날씨 화면 밖의 기존 위치를 유지합니다.

#### 조회 시점과 오류 확인

연결 직후 첫 조회 뒤에는 본체 날씨 화면이 열려 있을 때에만 **마지막 조회로부터 1시간 또는 마지막 조회 위치로부터 30km** 조건으로 다시 요청합니다. 30km는 주행거리 누적값이 아니라 두 위치 사이의 거리입니다. 이후 정기 조회는 다른 화면에서 하지 않으며, 화면 재진입만으로 제한을 초기화하지 않습니다. 실제로 전송된 실패 요청에도 자동 조회 간격을 적용합니다. **키 확인 · 날씨 조회**로 수동 재시도할 수 있으며, 키를 새로 저장하면 이전 키의 대기를 초기화합니다.

| 앱의 상태 | 확인할 것 |
|---|---|
| 키 필요 / 키 저장 오류 | 키 전체를 다시 확인하고 저장합니다. 키를 타인에게 보내지 않습니다. |
| HTTP 401/403 | 표시된 API와 키 활성화·오타·계정 권한을 확인합니다. One Call만 거절되면 Basic API 2.5를 직접 선택할 수 있습니다. 자동 전환하지 않습니다. |
| 위치 대기 | GPS·위치 권한을 확인하고 새 위치가 들어올 때까지 기다립니다. |
| 조회 한도 | 업체의 한도·사용량을 확인합니다. 반복 누르기로 우회하지 않습니다. |
| 네트워크 / 데이터 오류 | 연결 상태를 확인합니다. 다음 요청도 화면·시간·거리 조건을 따릅니다. |
| 오래된 예보 / 본체 자료 없음 | 갱신 시각을 확인하고 본체 날씨 화면에서 다음 허용 조회를 기다립니다. |

예보는 휴대폰과 본체의 RAM에만 둡니다. 재부팅·앱 프로세스 종료 뒤에는 다시 받아야 하며, 본체 NOR에 주기적으로 저장하지 않습니다. 날씨 사용을 끄면 자동 조회와 본체 표시를 멈춥니다. 폰의 **키 확인 · 날씨 조회**는 직접 누른 경우에만 따로 동작합니다. 날씨는 선택 기능이므로 등록하지 않아도 나머지 기능을 사용할 수 있습니다.

연결된 본체의 HOME에서 위·아래로 **Weather**를 선택합니다. 웃는 해 또는 Meteocons 날씨 아이콘 옆에 현재 온도를 크게 표시하고, 그 아래에 선명한 빨강으로 최고 온도, 파랑으로 최저 온도를 표시합니다. 현재 온도는 세 자리 고정 폭이며 앞에 0을 붙이지 않습니다.

아래 화살표 바 두 줄은 **현재 시간대부터 +12시간까지**의 예보를 보여줍니다. 왼쪽이 현재, 오른쪽이 +12시간입니다.

### 연료 측정 오류 표시

지속된 연료 측정 오류는 GPS 위치에 **대각선이 그어진 붉은 연료 아이콘**으로 표시합니다. 깜빡이는 Fuel Measurement Error 문구와 전체 화면 애니메이션은 제거했습니다. 정상 연료 프레임이 돌아오거나 연료량 인식을 OFF로 하면 GPS 아이콘으로 돌아옵니다. 연료 부족·위험 수준 경고는 기존 동작을 유지합니다.

## 2. 버튼과 전원부터 알아두세요

![UP O DOWN 버튼](images/guide-0.11.15/buttons-ko.svg)

- **O**는 가운데 확인 버튼입니다. 숫자 0이 아닙니다.
- **짧게**는 눌렀다 바로 놓기, **길게**는 누른 채 유지하기입니다. ‘2초’나 ‘3초’ 안내가 있으면 그 시간만큼 유지하세요.
- **IGN ON**은 차량 키/전원 스위치를 켜기입니다. **엔진을 걸라는 뜻이 아닙니다.**
- **IGN OFF**는 키/전원 스위치를 끄기입니다. **배터리나 누도 전선을 빼라는 뜻이 아닙니다.**
- 버튼을 누도/일반 계기판으로 전환하는 스위치가 있다면 **누도 쪽**에 놓습니다.

설명서의 **Bootstrap**은 첫 설치 때 나오는 설치 도구, **CFW**는 평소 쓰는 NewDoe 펌웨어, **Recovery/Gate**는 본체 시작·복구 메뉴입니다.

## 3. 설치 전에 준비하기

### APK 하나만 받으세요

[다운로드 페이지](https://github.com/SerialSniffyHeck3r/noodoe_cfw/releases/latest)에서 **NewDoe-0.15.0.apk**를 받으세요. 언어별 누도용 펌웨어와 필요한 글꼴은 앱 안에 포함돼 있어요. 일반 설치에서는 ZIP을 따로 받거나 고르지 않습니다.

**앱과 본체 펌웨어는 0.15.0입니다.** 앱에서 시스템 언어를 고르면 기기에 맞는 펌웨어와 자원을 준비합니다. APK를 설치하는 것만으로 본체 펌웨어가 바뀌지는 않습니다.

### 출발 전이 아니라, 주차한 상태에서 시작하세요

1. 안전하게 주차하고 엔진을 끕니다. 차량과 휴대폰의 배터리가 충분한지 확인합니다.
2. 새 APK를 열어 설치합니다. 이미 NewDoe 앱이 있으면 **그 위에 업데이트**하세요. 앱이나 앱 데이터를 삭제하지 않습니다.
3. Android에서 설치 허용을 물으면 직접 받은 APK인지 확인하고 허용합니다. 설치가 끝나면 NewDoe를 엽니다.
4. Bluetooth를 켜고 차량 가까이에 폰을 둡니다. 설치 중에는 NewDoe 앱을 앞에 띄워 둡니다.
5. 다른 Noodoe 앱이 연결 중이라면 그 연결을 끕니다.

**설치·순정 복귀 중에는 배터리와 누도 전선을 연결한 채 유지하세요.** 스타터를 돌리거나 전선을 분리하지 마세요. 이미 심하게 방전된 차량은 먼저 충전·점검을 받으세요.

### 설치 전 다섯 안내를 확인하세요

각 카드의 **다음**은 3초 뒤 활성화됩니다. 시간이 지나도 자동으로 넘어가지 않습니다. 다섯 번째 안내의 키 OFF 허용은 **CFW 설치 프로세스가 시작된 뒤**를 뜻합니다. 순정에서 설치 도구를 처음 전송하는 동안에는 키 ON을 유지하세요. 키 OFF는 배터리·상시 전원을 끊어도 된다는 뜻이 아닙니다.

설치 버튼을 누르면 그림을 한 장씩 읽고 **확인했습니다**를 누릅니다. **취소**하면 설치를 시작하지 않습니다. 같은 설치가 Bootstrap으로 이어질 때는 반복하지 않지만, 다른 기기·파일이나 새 설치에서는 다시 확인합니다.

1. 배터리 단자와 누도 전선을 분리하지 마세요.
2. 키 OFF 상태에서 **UP + O**를 동시에 누르지 마세요.
3. 스타터 버튼을 누르지 마세요.
4. 배터리 전압이 **11.5V 이상**인지 직접 확인하세요. 앱이 전압을 측정하는 것은 아닙니다.
5. 가능한 단계에서는 키 OFF를 권장합니다. **순정에서 설치 도구를 처음 보낼 때는 키 ON이 필요합니다.** 이후에는 화면 안내를 따르세요.

<img src="images/guide-0.15.4/ko-safety-0.png" alt="앱의 배터리 분리 금지 확인 화면" width="330">
<img src="images/guide-0.15.4/ko-safety-4.png" alt="첫 전송은 키 ON, 이후 가능한 단계에서 OFF 안내" width="330">

설치 중에는 진행 상태 아래에 다섯 그림이 계속 나옵니다. 다시 누르는 버튼이 아니라 주의사항을 알려주는 표시입니다.

### 순정에서 처음 설치한다면 마법사를 선택할 수 있어요

처음 앱을 열면 사용 경험을 고르고 버튼 안내를 볼 수 있어요. **기기/상태 → 현재 기기 상태 확인**을 누르세요. 실제 기기가 순정으로 확인되면 **설치합니다**로 바로 진행하거나 **단계별 안내로 설치**를 선택합니다. 잘 모르겠다면 단계별 안내를 사용하세요.

마법사는 순정에서 시작하는 설치에만 선택할 수 있습니다. 기존 CFW를 업데이트할 때는 일반 업데이트 화면을 사용합니다. 전송·검증이 시작되면 한 작업이 끝날 때까지 기다리세요. 안내 화면을 다시 여는 것만으로 설치가 시작되지는 않습니다.

## 4. 순정에서 처음 설치하기

### ① 폰에서 내 누도를 고르기

<img src="images/guide-0.11.15/ko-device.png" alt="앱의 기기 페이지: 페어링과 권한 준비" width="330">

1. **[누도]** 키를 ON으로 켭니다. 엔진은 걸지 않습니다.
2. **[폰]** 앱의 **기기** 페이지로 갑니다. 좌우로 넘기거나 아래의 기기 버튼을 누릅니다.
3. 처음 연결한다면 **누도 페어링하기**를 눌러 Android Bluetooth 설정으로 갑니다. 순정 누도를 페어링 대기 상태로 만들고 내 Noodoe를 선택합니다. 이미 등록돼 있으면 다시 등록하지 않습니다.
4. NewDoe 앱으로 돌아와 내 기기를 선택합니다. 안 보이면 기기 목록을 새로고침합니다.
5. **권한·연동 준비**에서 Bluetooth/주변 기기 권한을 허용합니다. 음악·전화·위치 권한은 [설치 뒤 설정](#phone)에서 추가할 수 있습니다.
6. **현재 기기 확인**을 누릅니다. 앱이 **순정 Noodoe**라고 표시하는지 확인합니다.

### ② 내장 파일로 설치 도구 보내기

1. **[폰] 현재 기기 상태 확인**이 끝나면 **앱 버전 / 내장 펌웨어 / 준비된 펌웨어**를 볼 수 있습니다. 파일은 자동으로 준비됩니다.
2. 순정 기기라면 **설치합니다**를 누르거나 **단계별 안내로 설치**를 선택합니다.
3. 설치 전 주의 화면을 한 장씩 읽고 확인하세요. 취소하면 설치 명령을 보내지 않습니다.
4. 전송과 확인이 끝날 때까지 기다립니다. 처음 순정 전송 중에는 미리 키를 끄지 마세요.

### ③ Bootstrap 메뉴를 본 뒤 ‘현재 상태 확인’ 누르기

<img src="images/guide-0.13.0/ko-bootstrap-wait.png" alt="Bootstrap 전송 완료 후 현재 상태 확인 버튼" width="360">

1. **[폰]** 위 안내가 나오면 순정 화면 안내에 따라 **키를 OFF**로 합니다. 배터리는 연결한 채 둡니다.
2. **[누도]** 설치가 끝나고 아래 **NewDoe Bootstrap** 메뉴가 나올 때까지 기다립니다. 중간의 **NOODOE INSTALLER** 화면은 아직 이 메뉴가 아닙니다.
3. Bootstrap 메뉴가 나오면 **키를 ON**으로 합니다.
4. **[폰] 현재 상태 확인**을 누릅니다. 이 버튼을 누르는 단계입니다. Bootstrap 파일을 다시 보내지 마세요.

처음 3초는 NEWDOE 워드마크만 표시합니다. 확인 작업은 뒤에서 계속됩니다. 이후 아직 진행 중이면 워드마크 위에 현재 확인 항목, 아래에 가로 막대가 나오고, 이미 끝났다면 바로 메뉴로 넘어갑니다.

### ④ 누도에서 Install CFW 선택하기

1. **[누도]** UP/DOWN으로 **Install CFW**를 고르고 **O**를 누릅니다.
2. 아래 **Reset Bluetooth?** 질문이 나오면, 연결에 문제가 없을 때는 **기본 선택 No → O**를 누릅니다.
3. 이후 설치는 폰에서 이어집니다. 폰의 다른 설치 시작 버튼을 추가로 찾을 필요는 없습니다.

<img src="images/guide-0.11.16/bootstrap-reset-no.png" alt="Reset Bluetooth? 기본 선택 No" width="360">

**Yes는 저장된 페어링을 지웁니다.** 실제 연결 문제가 있을 때만 선택하세요. ‘연결할 수 없음’이 나오면 [재페어링 순서](#connection)를 따릅니다. 이 질문에는 자동 선택 시간이 없습니다.

기존 CFW 데이터를 발견했다고 물으면, 기존 설정·트립·사진을 이어 쓰려는 경우 **보관 데이터 복원**을 선택합니다. **새로 시작**은 새 환경으로 시작하려는 경우에 고릅니다. 처음 설치라면 이 질문이 없을 수 있습니다.

- **위의 연한 막대:** 설치 전체 진행입니다.
- **아래의 진한 막대:** 지금 하는 작업의 진행입니다. 다음 작업으로 넘어가면 다시 처음부터 찰 수 있습니다.
- 글씨는 받고 있는 파일이나 현재 작업을 알려줍니다. 숫자는 예시와 달라도 됩니다.

전원과 폰 연결을 유지하세요. 느리다는 이유로 강제로 껐다 켜지 마세요. 취소가 필요하면 화면 안내에 따라 **O를 새로 3초** 누르고, 멈췄다는 안내가 나올 때까지 기다립니다.

### ⑥ Everything is ready → 최종 설치

<img src="images/guide-0.11.16/bootstrap-confirm.png" alt="최종 INSTALL CFW 확인: Back과 Install CFW" width="360">

이제 파일 준비가 끝났습니다.

- 바로 설치: **Install CFW → O**.
- 그대로 기다리기: **30초 뒤 자동으로 설치**합니다.
- 돌아가기: UP/DOWN을 눌러 카운트다운을 멈춘 뒤 **Back → O**.

설치가 시작되면 본체가 다시 시작됩니다. 잠깐 연결이 끊어지거나 시작 화면이 보여도 앱을 닫지 마세요.

## 5. 이미 NewDoe를 쓰고 있다면

**기존 사용자는 기기 상태를 확인하고 원하는 시스템 언어를 고른 뒤 0.15.5로 업데이트하세요.** 호환되는 Gate는 유지하고 정상적인 기존 B 글꼴을 재사용합니다.

1. 기존 앱 위에 최신 `NewDoe-0.15.5.apk`(hotfix1, 빌드 151)를 설치합니다. 앱 데이터와 페어링은 유지하세요.
2. 주행 연동을 켜 둔 상태에서도 기기 페이지의 **현재 기기 상태 확인**을 누를 수 있습니다. 앱이 기존 연결을 정리하고 상태 조회용 연결로 전환합니다. 이 조회는 펌웨어를 설치하지 않습니다.
3. 필요하면 **언어 설정 → 다른 언어 설치**를 고른 뒤 **업데이트합니다**를 누릅니다. 경고 5장을 각각 3초 이상 읽고 확인합니다. 마지막 확인 전에는 설치를 시작하지 않으며, 여기서 취소하면 진행 중인 주행 연동을 유지합니다. 마지막 확인 후 앱이 주행 연결을 종료하고 설치 연결로 자동 전환하므로 별도의 중지 버튼을 누를 필요가 없습니다.
4. 전원을 연결한 채 전송·검증·재시작이 끝날 때까지 기다립니다.
5. 누도의 **CFW UPDATE** 화면을 앱에서 확인합니다. 추가 글꼴 준비가 나오면 최종 설치 완료까지 기다립니다.

**hotfix1은 앱의 연결 전환 수정입니다. 본체가 이미 0.15.5이면 APK만 덮어 설치하면 됩니다.** 내장 펌웨어와 설치 ZIP은 0.15.5와 동일합니다. 다른 설치·복구·NOR 백업 작업이 진행 중이면 끝난 뒤 업데이트하세요. 차량 정차 등 기기의 기존 설치 조건은 유지합니다.

### 0.14.1에서 설정 저장·복원 오류로 업데이트가 막힌다면

본체 HOME이 열려도 설정 복원이 완료되지 않을 수 있습니다. **현재 기기 상태 확인**은 상태만 읽습니다. 이 버튼으로 설정 복원이나 설치를 다시 실행하지 않습니다.

1. 새 APK를 기존 앱 위에 설치합니다. 앱 데이터는 지우지 말고 **진단 자료 저장**으로 기록을 보관합니다.
2. 상태를 확인합니다. **펌웨어 부팅 확정**과 **설정 복원 미완료**가 따로 나오면 두 상태를 함께 확인하세요. 같은 작업의 **설치 계속**으로 복원을 다시 시도할 수 있지만, 0.14.1 설정 오류가 계속되면 다음 경로를 사용합니다.
3. 앱의 **데이터 보존 재설치** 안내를 엽니다. 폰이 실제로 연결되지 않으면 [본체 버튼으로 복구 메뉴](#recovery)를 열고 **Back to stock**을 선택합니다. **CFW 데이터 유지**를 사용하며 **완전 삭제**는 고르지 않습니다.
4. 순정 화면이 나온 뒤 앱에서 **본체에서 순정으로 돌아왔어요 · 확인**을 누릅니다. 앱이 실제 순정 상태를 확인하면 이전 작업 기록을 보관하고 재설치를 준비합니다.
5. 앱에서 원하는 설치 언어를 고르고 [처음 설치](#first-install)를 진행합니다. Bootstrap에서는 **보관 데이터 복원**을 선택합니다. 설정·TRIP·정비·사진·페어링을 보존하는 경로입니다.
6. 본체 화면과 앱의 최종 결과를 확인합니다. 필수 데이터 파일이 없거나 손상됐다는 안내가 나오면 자동 초기화하지 않습니다. 진단 자료를 저장하고 중단하세요.

**정상적으로 설정을 저장하고 업데이트 준비를 마치는 기기는 순정 복귀가 필요 없습니다.** 오류 메시지에서 확인하지 못했다고 표시한 데이터는 보존 완료로 판단하지 마세요. 취소해도 이미 완료된 단계가 되돌아가지는 않습니다.

### 앱에서 새 복구 시스템이 필요하다고 안내한다면

0.11.x나 다른 구형 Gate에서는 먼저 **순정 복귀 → CFW 데이터 유지**로 진행합니다. 순정 화면이 나오면 **본체에서 순정으로 돌아왔어요 · 확인**을 누르고 앱의 내장 파일로 [처음 설치](#first-install)를 진행하세요. **보관 데이터 복원**을 선택하고, 완전 삭제는 고르지 마세요.

설정·트립·정비 기록·사진은 유지됩니다. **순정 복귀·설치 중 전원을 분리하지 마세요. 구버전 순정 복귀 도중 전원이 끊기면 별도 장비를 이용한 수리가 필요할 수 있습니다.**

## 6. 시스템 언어 선택과 변경

**설치 전에 앱에서 언어를 고릅니다.** 영어 전용으로 설치하거나, 영어와 원하는 언어 하나를 함께 설치할 수 있습니다. 필요한 파일은 APK 안에 들어 있습니다.

### 처음 선택하거나 다른 언어로 바꾸기

1. 차량을 세우고 앱의 **현재 기기 상태 확인**을 누릅니다. 앱이 실제 기기의 A/B 자원을 확인합니다.
2. **언어 설정 → 다른 언어 설치**에서 원하는 언어를 고릅니다. 기기에 맞는 선택지만 표시됩니다.
3. **설치합니다 / 업데이트합니다**를 누르고 안전 안내를 확인합니다.
4. 전송·검증·재시작과 **CFW UPDATE** 확인을 마칩니다. 추가 글꼴 준비가 나오면 앱의 완료 안내까지 기다립니다.
5. 누도 메뉴의 언어를 확인합니다. 앱에는 **설치 언어**와 **표시 언어**가 따로 표시됩니다.

**언어만 바꾸려고 순정으로 복귀할 필요는 없습니다.** 정상적인 언어 변경은 펌웨어와 기본 자원을 함께 업데이트하며, 이미 정상인 추가 글꼴은 다시 보내지 않습니다.

준비용에서는 **FONT PREPARATION** 화면만 표시하며 HOME·음악·지도 기능은 사용할 수 없습니다. 정차한 상태에서 앱으로 설치를 계속하세요. `Font preparation complete`는 글꼴 준비가 끝났다는 뜻이며, **선택한 최종 펌웨어까지 설치해야 주행 화면으로 돌아갑니다.** 연결 도움이 필요하면 대기 화면에서 위 버튼을 짧게 눌러 기존 페어링 도움말을 열 수 있습니다. 페어링을 자동으로 삭제하지 않습니다.

- CJ를 생략하면 완료 화면과 언어 설정에 **설치 완료 — CJ 미설치**가 남습니다. 나중에 설치하려면 다시 용량 검사와 확인을 진행합니다.

## 전문가용 설정과 중단된 설치

일반 설치는 **현재 기기 상태 확인 → 설치합니다 / 업데이트합니다**만 사용하세요. 수동 ZIP 설치, 진단, 복구, 백업은 **기기/상태 → 전문가용 설정**에 있습니다. ZIP 직접 설치를 누르면 주의 화면이 나오며, 파일을 선택한 뒤 실제 설치할 때도 주의사항을 확인합니다. ZIP 선택만으로 설치하지 않습니다. 기본 경로로 돌아가려면 **앱에 포함된 패키지 사용**을 누르세요.

앱 업데이트나 연결 끊김이 있었다면 기기 상태부터 확인하세요. 끝나지 않은 설치는 원래 파일과 작업 기록으로 이어갑니다. 새 앱에 다른 버전이 포함돼 있어도 진행 중인 작업을 새 파일로 바꾸지 않습니다. 파일이 없거나 손상됐다는 안내가 나오면 전문가용 설정에서 **처음 사용한 ZIP**을 다시 가져오세요. 다른 버전으로 대신 진행하지 마세요.

설치 파일과 기록은 앱 전용 저장소에 보관합니다. **앱 삭제·데이터 삭제를 하면 함께 사라집니다.** 먼저 전문가용 설정에서 **백업·작업 기록 저장**을 사용하세요. 공간이 부족하면 다른 불필요한 파일을 정리한 뒤 다시 시도하세요. 앱은 복구 자료나 진행 중인 파일을 임의로 삭제하지 않습니다. 복원 중 확인되지 않은 작업은 실제 기기 확인 없이 다시 보내지 않습니다.

## 7. 연결할 수 없다고 나올 때

### Bootstrap에서 ‘Couldn’t pair’가 뜨면

파일 기록 중이라면 먼저 끝날 때까지 기다립니다. Bootstrap 메뉴나 연결 대기 화면에서 아래를 진행하세요.

1. **[폰] 접속이 안 되나요? / Bootstrap 연결 도움말**을 엽니다.
2. **Bluetooth 설정 열기**를 누르고 Android에서 **내 Noodoe만 등록 해제**합니다. 앱 데이터는 지우지 않습니다.
3. **[누도]** 이미 **Reset Bluetooth? → Yes**를 골랐다면 화면 안내를 따릅니다. 아직 초기화하지 않았다면 연결 대기 화면의 **UP**으로 페어링 메뉴를 열고 해당 폰을 고릅니다. O를 놓았다가 **다시 2초** 눌러 삭제합니다. ALL은 모든 폰을 삭제합니다.
4. **PAIR YOUR PHONE**이 나오면 Android에서 Noodoe를 다시 검색하고 페어링합니다.
5. NewDoe 앱으로 돌아와 같은 기기를 고르고 **현재 상태 확인**을 누릅니다.
6. 누도에서 **Install CFW**를 선택합니다. 이어가기 화면이 보이면 **마지막 작업 상태 조회 → 검사 후 설치 이어가기**를 따릅니다.

### 일반 화면에서 연결이 끊기면

**0.14.1은 연결 중 갱신된 Bluetooth 인증키를 다음 연결에도 사용할 수 있도록 저장합니다.** 기존 앱 위에 새 APK를 설치하고 **현재 기기 상태 확인 → 업데이트**로 본체도 업데이트하세요. APK만 바꾸면 본체의 수정은 적용되지 않습니다.

앱 상단의 주행 연결이 일시정지돼 있지 않은지, Bluetooth·주변 기기 권한이 있는지 확인합니다. Android의 NewDoe 배터리 사용 설정에서 백그라운드 실행을 허용하세요. 앱을 강제 종료했다면 다시 열고 연결을 시작합니다. 카메라 등 다른 앱을 쓰다가 끊겼다면 NewDoe로 돌아와 연결 상태를 확인하세요.

이미 재페어링으로 연결을 복구했다면 그 연결로 본체를 업데이트하면 됩니다. 이후에도 연결할 수 없다면 재시작·재페어링 전에 앱의 진단 ZIP과 본체·앱 버전을 저장해 보내 주세요. 앱 데이터는 유지하세요. 설정 저장·복원 오류로 업데이트가 막히면 위의 [0.14.1 재설치 안내](#update)를 따르세요.

**복구 메뉴에는 Bluetooth가 없습니다.** 해골이나 Recovery 메뉴에서 폰 연결을 계속 시도하지 말고 [본체 버튼으로 복구](#recovery)하세요.

| **ODO ------ / 속도 미수신** | 차량 키가 ON인지 확인합니다. 계속되면 차량 모델과 화면을 보내 주세요. |

### ‘Please manually reset’이 나오면

1. 화면의 코드와 문구를 사진으로 남깁니다.
2. 버튼을 모두 놓은 뒤 **UP + O를 함께 3초** 누르고 놓습니다.
3. 키가 OFF라면 화면이 꺼진 채일 수 있습니다. 버튼을 놓고 **키를 ON**으로 합니다.
4. 같은 기기와 ZIP으로 다시 상태를 확인합니다. CFW UPDATE면 폰에서 확인하고, 복구 메뉴면 다음 절차를 따릅니다.

이 조작은 **본체가 요청할 때** 하세요. 진행이 느리다는 이유로 기록 중인 본체를 강제로 끄지 않습니다.

## 9. 폰 없이 복구하거나 순정으로 돌아가기

### 복구 메뉴 열기

- 본체가 새로 시작하며 NewDoe 로고를 표시할 때 **DOWN을 약 1초** 누릅니다.

## 12. 누적 거리·트립·정비

0.15.1부터 **오일 교환주기는 ODO 거리만** 사용합니다. 모든 정비 항목에서 시동 시간 계측·수명 반영을 제거했습니다. 기존 교환 후 거리는 유지하며 과거 시간값은 거리로 환산하지 않습니다. 시간 주기만 사용했다면 정비 설정에서 거리 주기를 지정하세요. 벨트·정기 점검의 날짜 기준과 주행시간·평균속도 통계는 유지됩니다.

<img src="images/guide-0.11.15/ko-trip.png" alt="한국어 트립 컴퓨터 화면" width="360">

**ODO는 차량 계기판에서 받은 누적 거리**입니다. 값이 없으면 `------`로 표시합니다. 누도의 ODO를 따로 보정하거나 과거 값을 불러오는 메뉴는 없습니다.

트립 A/B·오늘·이번 주행·오일·벨트·정비 기록은 별도로 유지됩니다. **정비 메뉴**에서 교체 주기와 교체 후 주행거리를 확인하고, 실제 교체 기록에 맞게 초기화하거나 조정하세요. 이 조작은 차량 계기판의 원래 ODO를 바꾸지 않습니다.

오일의 남은 비율은 **30% 이하 노랑 → 15% 이하 빨강 → 5% 이하 빨강 점멸**입니다. 이번 주행의 최고·평균 속도가 5km/h를 넘으면 속도 링에 표시합니다.

HOME의 **위/아래 짧게**는 **1줄 → 2줄 → 속도 → 시계 → TBT → 날씨**입니다. 일반 정보 줄에서 **O 길게**로 수동/AUTO를 바꾸고 **위/아래 길게**로 정보를 넘깁니다. AUTO의 수동 변경은 20초 뒤 원래 순환으로 돌아갑니다. 안내 중 TBT·MAP은 목적지 정보 두 장만 10초마다 순환합니다. 선택값은 RAM에 두고 **키 OFF 때** 저장합니다. 날씨의 예보 버튼은 기존대로입니다.

**설정 → 화면 → 시계 스타일**에서 아날로그 또는 디지털을 선택합니다. HOME에는 선택한 시계 한 종류만 나옵니다. 디지털 시계에서는 상단 작은 시계만 숨깁니다. 사진의 검은 음영, 기존 바늘 길이·속도 호·ODO·하단 정보 위치는 유지합니다.

하단 순환에는 **일출 / 일몰**도 있습니다. 본체 **설정 → 표시 → 일출 / 일몰** 또는 폰의 **기기 설정 → 일출·일몰 기준 도시**에서 가까운 도시를 고르세요. 본체가 날짜·UTC 시차와 선택한 도시로 간단히 계산해 분 단위로 표시합니다. GPS는 기준 도시를 자동 변경하지 않습니다. 여행 시 도시와 UTC 시차를 확인하고, 서머타임도 시차에 반영하세요. 기존에 저장한 위치는 **이전에 저장한 위치**로 재사용할 수 있습니다. 저장 위치가 없는 새 설치에서는 도시를 직접 선택해야 하며, 위치·날짜를 모르면 `--:-- / --:--`입니다. 산·건물·고도·날씨는 반영하지 않는 대략적인 시각입니다.

| 아날로그 시계 | 디지털 시계 |
|---|---|
| <img src="images/guide-0.15.4/analog.png" alt="아날로그 시계와 하단 자동 정보" width="280"> | <img src="images/guide-0.15.4/digital.png" alt="작은 초 표시가 있는 디지털 시계" width="280"> |

키 OFF에서는 이번 부팅 중 마지막으로 받은 ODO를 본체와 폰 대시보드에 유지합니다. 키를 다시 ON으로 하면 새 차량 값을 받아야 합니다. 재부팅하면 임시 ODO는 사라지며, 예전에 저장한 ODO를 복원하지 않습니다. 트립·정비 카운터는 별도로 보존합니다.

0.12.1에서는 **키 OFF 후 10분간 사용**하는 모드에서도 마지막 ODO를 유지합니다. 잠깐의 수신 오류로 정상값이 즉시 사라지지 않으며, 키 ON에서 통신이 계속 끊기면 알 수 없음으로 표시합니다. 트립과 정비 기록은 그대로 유지하며, 보관한 ODO로 주행거리를 늘리지 않습니다.

**SINCE REFUEL:** 연료량 인식이 ON일 때, 이전보다 두 칸 이상 높은 연료 상태가 3초간 이어지면 주유 후 기록을 새로 시작합니다. 2칸에서 주유한 뒤 4·5칸이 오가도 감지합니다. 수신이 끊겼거나 연료값이 불명확하면 확정될 때까지 기다립니다. TRIP A/B와 정비 기록은 지우지 않습니다.

주유한 뒤 키를 켜고 정상 연료값이 몇 차례 수신될 때까지 기다리세요. 두 칸 이상 늘어난 상태가 안정적으로 유지되면 주유로 기록합니다. 수신이 빠진 것만으로 주유로 판단하지 않습니다. 키 OFF 주행 요약의 오일 비율은 이번 부팅에서 마지막으로 받은 ODO로 계산합니다.

**설정 → 차량 → 연료량 인식 사용(Fuel recognition)**을 OFF로 설정하면 연료 경고, 자동 주유 감지, 예비연료 모드를 모두 중단합니다. 계기판이 유효한 연료값을 보내지 않는 차량에서 사용하세요. **SINCE REFUEL 화면에서 O를 길게 누르면** 주유 후 거리를 0부터 직접 시작합니다. 아직 `--`여도 사용할 수 있으며 다른 트립과 정비 기록은 유지됩니다. 주유할 때마다 직접 초기화하세요. 다시 ON으로 켜면 새 연료 기준값을 잡으며, OFF 이전 값과 비교해 주유로 처리하지 않습니다.

문제 상황을 전달할 때는 **진단 설정 → Fuel RAW P2 / P3**와 **UART RX first 16 bytes**를 촬영해 주세요. 차량 계기판이 실제로 보낸 값을 확인하는 항목입니다. 연료량 인식을 꺼도 이 정보는 확인할 수 있습니다.

## 13. 음악·전화·알림

- **음악:** 폰에서 음악을 재생하고 알림 접근을 허용합니다. 음악 페이지에서 UP 짧게는 재생/일시정지, DOWN 짧게는 다음 곡, UP 길게는 이전 곡입니다.
- **볼륨:** 음악 페이지에서 O를 길게 누르면 볼륨 팝업이 열립니다. UP은 미디어 볼륨 한 단계 올리기, DOWN은 내리기, O 짧게는 팝업 닫기입니다. 전화·경고 화면이 우선하며 폰이 연결돼 있어야 합니다.

![음악 볼륨 전용 팝업](images/guide-0.12.1/music-volume.png)


- **스마트폰 페이지:** UP으로 최근 전화, DOWN으로 최신 알림을 엽니다. 상세 화면에서는 화면의 버튼 안내를 따릅니다. 전화 팝업 닫기와 실제 통화 종료는 다른 조작입니다.
- **새 알림:** 상단 아이콘이 약 2초 깜빡입니다. 여러 메시지가 이어지면 최신 내용을 표시하며, 준비 중에는 Updating...이 보일 수 있습니다.
- **빠른 답장:** 1–7번은 저장 문구, 8번은 위치+이번 주행 정보+음악, 9번은 위치, 10번은 음악입니다. 8–10번에는 서명이 붙습니다. 상대와 전송할 내용을 확인하고 보내세요.
- **계기판 깜빡임:** 알림·경고 때 계기판 밝기가 잠시 변합니다. 원하지 않으면 설정 → Display → **Dash blink alerts**를 끕니다.

## 14. 지도와 축척

앱의 지도 메뉴에서 사용할 지역의 **.map 파일**을 가져옵니다. GPS·위치 권한을 허용하고 기기를 선택해 연결하세요. 지도 파일이 없으면 이동 격자와 궤적 선으로 표시합니다.

| 지도에서 | 조작 |
|---|---|
| **UP 길게** | AUTO / MANUAL 전환 |
| AUTO에서 **UP/DOWN** | −2 가까이 ~ +2 넓게 보기 선호도 |
| MANUAL에서 **UP/DOWN** | 축척 직접 변경 |
| **O 길게** | 북쪽 위 / 진행 방향 위 전환 |

처음 보는 지역은 지도를 준비하는 시간이 필요합니다. 안내 OFF에서는 지도·위치·주행 궤적만 표시합니다.

안내를 켜지 않았을 때는 기존처럼 지도·현재 위치·주행 궤적을 표시합니다. 별도의 목적지 설정은 필요하지 않으며, 트립과 ODO는 그대로 사용할 수 있습니다.

### 안내 중의 HOME·지도·음악

앱 하단은 **기기 / 홈 / 꾸미기 / 내비** 네 탭입니다. 이번 빌드의 자체 오프라인 안내는 **BRouter만** 사용합니다. 휴대폰이 경로를 계산하고, 본체에는 TBT와 지도 위 경로를 표시합니다.

**내비 → BRouter 경로 파일 → 다운로드**에서 공식 `.rd5` 파일을 받은 뒤 **.rd5 파일 가져오기**로 넣으세요. 서울은 `E125_N35.rd5`이며 필요한 주변 구역도 함께 받으세요. 표시용 Mapsforge `.map` 지도는 기존 지도 화면에서 별도로 받습니다. 지도 중앙 표시를 목적지에 맞추고 **이 위치 선택**을 누르거나 즐겨찾기·최근 목적지를 선택해 안내를 시작합니다. 주소·상호 검색과 Valhalla 국가 팩 설치는 이번 빌드에 없습니다.

기존 다운로드 지도·국가 팩 파일과 저장된 목적지는 삭제하지 않습니다. 저장된 목적지는 사용자가 안내 시작을 누르면 BRouter로 새로 계산합니다. 도로명 자리는 비워 두며 회전교차로 출구 번호는 표시합니다. Google Maps·OsmAnd 외부 TBT는 계속 해당 앱이 제공한 도로명을 사용합니다.

안내 중 MAP에는 **검정·흰색 테두리를 가진 보라색 경로**와 목적지까지의 남은 거리가 표시됩니다. 현재 위치가 경로 위에 그려집니다. 목적지 거리도 하단 순환에 참여합니다. 안내 OFF에서는 안내 경로·목적지 항목이 사라지고 기존 지도·궤적 동작으로 돌아갑니다.

안내 중 메뉴가 숨으면 전체 TBT를 제외한 일반 페이지에 **왼쪽 화살표 + 오른쪽 거리**의 미니 안내가 나옵니다. 전체 TBT에는 두 번째 안내가 없으며, 현재 화살표·거리·외부 앱 도로명과 하단 목적지 정보를 표시합니다. 안내를 끄면 HOME TBT에 비활성 문구를 표시합니다. 시작만으로 페이지를 바꾸지 않습니다.

내비 탭의 **자체 안내 거리 10m 올림**은 기본 OFF입니다. 켜면 자체 미터 안내를 10m 단위로 올립니다. 예를 들어 91m는 100m, 101m는 110m로 표시합니다. 목적지 잔여거리, mi/ft, Google Maps·OsmAnd의 외부 TBT 거리는 바꾸지 않습니다. 기존 올림 선택은 유지됩니다. 외부 TBT는 실험 기능이며 기존 우선순위를 유지합니다. 오래된 GPS·연결 단절 상태에서는 `--`로 대기하고 경로를 흐리게 표시합니다.

안내 중에는 모든 주행 페이지의 메뉴가 5초 뒤 사라진 다음 미니 안내가 나타납니다. 메뉴 조작 시 역순으로 전환합니다. 안내가 없으면 기존 메뉴 정책을 유지합니다. 회전까지 실제 남은 거리가 **500m 이하**이면 미니 안내의 숫자만 2Hz로 노란색과 흰색을 번갈아 표시합니다. 테두리와 전체 TBT 글자는 깜빡이지 않습니다. 표시 거리의 반올림·올림과 무관하며, 안내가 없거나 오래되면 강조하지 않습니다.

| 미니 안내 | 전체 TBT | 서울 경로 예시 |
|---|---|---|
| ![미니 안내](images/home-navigation/02-manual-mini.png) | ![TBT](images/guide-0.15.5/eve-tbt-90-m.png) | ![서울 경로](images/home-navigation/06-map-route.png) |

큰 TBT 거리는 `000 m / 00.0 km / 000 km` 고정 폭을 사용합니다. 선행 0을 붙이지 않고 짧은 숫자를 오른쪽에 맞추므로 90m는 십·일의 자리에 표시됩니다. 단위는 고정 위치를 유지합니다.

위 이미지는 실제 LVGL/EVE 코드의 PC 렌더링입니다. 차량 LCD 사진은 아닙니다.

앱 테마의 **배경화면** 모드는 Android 시스템 배경화면을 투명 창 뒤로 표시합니다. 앱 배경 음영과 비네팅을 조절할 수 있으며, 문자 대비를 위한 최소 음영은 유지합니다.

### 궤적 색상 바꾸기

누도에서 **설정 → 화면 → 궤적 색상(Trail color)** 을 여세요. 휴대폰에서도 **기기의 모든 설정 → 궤적 색상** 에서 바꿀 수 있어요. 빨강·주황·노랑·초록·청록·파랑·하양 중 하나를 고르거나 **속도에 따라(By speed)** 를 선택하세요. 기본값은 기존 빨강이며, 적용하면 재부팅 없이 바뀝니다.

속도 모드는 그 구간을 지날 때의 계기판 속도를 기억합니다. 낮은 속도는 파랑, 속도가 높아지면 청록·초록·노랑·주황을 거쳐 빨강이 됩니다. **설정 → 차량 → 호 최대값(Ring maximum)** 이 빨강의 기준입니다. 예를 들어 최댓값이 200 km/h이면 100 km/h는 초록, 150 km/h는 노랑, 200 km/h 이상은 빨강입니다. 단위를 mph로 바꿔도 같은 실제 속도에는 같은 색이 표시됩니다. 속도를 받지 못한 구간은 회색입니다.

궤적 색상 설정은 저장되지만 주행 궤적은 기존처럼 현재 세션의 기록입니다.

## 15. 폰의 홈·꾸미기·기기 화면

<img src="images/guide-0.11.16/ko-maintenance.png" alt="앱 홈의 속도와 ODO, 트립 및 원형 정비 게이지" width="330">

**기기 · 홈 · 꾸미기**는 좌우로 넘기거나 아래 버튼으로 이동합니다.

- **홈:** 지도·속도·ODO, 트립, 오일·벨트의 남은 km와 정기 점검의 남은 %를 원형 호 세 개로 봅니다. **트립 표시 영역 자체를 눌러** 다음 정보로 넘깁니다. 순정 누도에 연결하면 아래 영역은 순정 정보로 바뀝니다.
- **꾸미기:** 배경 사진·알림 앱·팝업·빠른 답장·전화 즐겨찾기를 고릅니다.
- **기기:** 설치·업데이트·현재 상태·시스템 언어·설명서를 엽니다.

**UI 테스트 모드**에서는 연결하지 않은 상태로 원하는 속도·ODO·CFW/순정 화면을 미리 볼 수 있습니다. 실제 차량 값은 바뀌지 않습니다. 사용을 마치면 테스트 모드를 끄고 연결하세요.

**Bluetooth가 꺼져 있어요:** 연결 버튼을 잠그고 HOME에서도 켜 달라는 안내를 표시합니다. Bluetooth 설정 열기로 켜세요. 기기를 선택하면 자동으로 다시 연결합니다. 미완료 설치 기록은 실제 결과를 확인한 뒤 처리합니다. 설치를 임의로 다시 시작하지는 않습니다.

<img src="images/guide-0.11.16/ko-bluetooth-off.png" alt="Bluetooth OFF" width="330">

처음 새로 설치하면 배경 1에 검은 480 × 480 사진과 중앙 NEWDOE 워드마크가 들어갑니다. 다른 사진으로 바꾸면 워드마크도 완전히 사라집니다. 데이터 보존 재설치·일반 업데이트에서는 기존 사진을 유지하고, 배경 2·3은 바꾸지 않습니다.

## 16. 키를 끈 뒤와 장기 주차

키를 끄면 **Ride Summary**를 보여준 뒤 기존 배경과 절전 순서로 넘어갑니다. 별도 키 OFF 배경은 없습니다. O를 누른 채 키를 끄고 놓으면 키 OFF 후 최대 10분 동안 사용할 수 있습니다.

**설정 → 시스템 → 전원 순서 → 장기 주차 전원 끄기**에서 **끄기 / 2일 / 3일 / 7일**을 고릅니다. 기본값은 2일이며, 이전에 바꾼 값은 업데이트해도 유지됩니다.

설정한 시간이 지나 전원이 종료되면 폰 접근에 따른 재연결·웰컴 라이트도 멈춥니다. 다시 키를 켜면 시작 화면부터 켜집니다. 오랫동안 세워둘 때 이 설정을 확인하세요. 배터리가 이미 방전됐거나 전압이 크게 낮아졌다면 먼저 배터리·차량 점검을 받으세요.

### NewDoe 사진과 순정 사진 고르기

누도에서는 **설정 → 화면 → 사진 출처**를 엽니다. 폰에서는 연결 후 **기기 설정 → 사진 출처**를 엽니다.

1. CFW 전용 사진 세 장을 쓰려면 **NewDoe**, 순정 앨범에 이미 있는 사진을 쓰려면 **KYMCO**를 고릅니다.
2. **사진**에서 **1·2·3번** 중 하나를 고르고 적용합니다. 번호는 선택한 출처 안의 슬롯 번호입니다. 별도의 키 OFF 사진 선택은 없습니다.
3. 선택은 누도에 저장됩니다. 폰과 누도 설정은 같은 값을 바꿉니다.

![사진 출처 선택 화면](images/guide-0.12.2/photo-source.png)
![사진 슬롯 선택 화면](images/guide-0.12.2/photo-slot.png)

순정 앨범은 읽기만 하며 덮어쓰기·삭제·자동 수리를 하지 않습니다. 새 사진을 업로드하면 언제나 **NewDoe 슬롯**에 저장됩니다. KYMCO 사진을 사용 중이었다면 NewDoe로 바꿔서 올린 사진을 선택하세요. 새로 설치할 때는 NewDoe 1번에 NEWDOE 워드마크가 들어가며, 업데이트·데이터 보존 재설치는 기존 사진을 유지합니다.

**빈 슬롯**은 해당 순정 슬롯에 JPEG가 없다는 뜻입니다. **읽기 오류**는 파일·폴더를 읽을 수 없거나 JPEG가 손상됐거나 지원하지 않는 형식·크기라는 뜻입니다. 오류에 슬롯 번호가 함께 표시됩니다. 실패한 슬롯 선택은 저장되지 않으므로 다른 슬롯을 고르거나 NewDoe로 돌아가세요. 순정 파일은 바뀌지 않습니다. 아직 사진을 불러오는 중이라면 잠시 기다린 뒤 다시 선택하세요.

![특정 슬롯을 읽지 못했을 때의 안내](images/guide-0.12.2/photo-error.png)

처음 설치 중 사진 진행률이 끝까지 찬 뒤 **0x00050005 / CFWPIC.DAT**에서 멈췄다면 **현재 기기 확인**부터 진행하세요. 이 문제는 내장 펌웨어 패키지 0.12.2에서 수정됐습니다. 이전 Bootstrap에서 같은 오류가 반복된다면 상태 확인 후 순정으로 돌아가 내장 파일로 재설치하세요. 순정 앨범을 지우거나 앱 데이터를 초기화하지 마세요.

## 오프라인 내비게이션 — BRouter

이번 빌드는 BRouter만 포함하며, Valhalla 네이티브 엔진·국가 팩 설치·차량 분류 선택은 제외합니다. 기존 데이터는 보존합니다.

1. **BRouter 경로 파일 → 다운로드**에서 [공식 경로 파일](https://brouter.de/brouter/segments4/)을 받습니다. 파일 하나는 위도·경도 5° 구역입니다. 서울은 `E125_N35.rd5`이며, 여러 구역을 지나는 경로는 주변 파일도 필요합니다. 원래 파일명을 유지하고 가능하면 같은 날짜 자료를 사용하세요.
2. **.rd5 파일 가져오기**에서 필요한 파일을 선택합니다. 같은 구역의 기존 파일은 새 파일 검증 후 교체하며, 실패 시 이전 파일을 유지합니다. 중단되면 다시 선택하세요.
3. 표시용 Mapsforge `.map`은 기존 지도 화면에서 받습니다. `.rd5`에는 표시용 지도나 주소 검색 데이터가 없습니다.
4. 지도 중앙 표시를 목적지에 맞추고 **이 위치 선택**을 누르거나 즐겨찾기·최근 목적지를 사용합니다. 본체와 연결하고 GPS 위치가 들어오면 안내를 시작할 수 있습니다.
5. 본체는 화살표·회전까지 거리·목적지 잔여거리와 보라색 경로를 표시합니다. 도로명 자리는 비워 두며, 회전교차로 출구 번호는 유지합니다. 이탈하면 폰에서 재탐색합니다.
6. 재개는 자동 실행되지 않습니다. 저장된 목적지를 확인하고 안내 시작을 누르면 BRouter로 새로 계산합니다. 기존 Google Maps·OsmAnd 외부 TBT의 우선순위와 도로명 표시는 유지합니다.

안내는 Android 8.0 이상에서 사용합니다. 기본 오토바이 프로필은 OSM 통행·일방통행·회전 제한을 사용합니다. 국가·배기량별 특수 규칙은 별도로 검증하지 않았으므로 도로 표지를 따르세요. 음성·과속카메라·차선 안내는 포함하지 않습니다. 본체 Bluetooth·NDCP·Gate·NOR 구조는 변경하지 않습니다.

현재 표시 방식은 이 설명서 맨 위의 **0.15.9** 안내를 기준으로 합니다.

### BRouter 처음 준비하기 — 지도와 경로 파일은 별개

1. 휴대폰을 인터넷에 연결해 앱 **내비 → BRouter 경로 파일 → 다운로드**를 엽니다. 연결되는 [BRouter 공식 파일 배포처](https://brouter.de/brouter/segments4/)에서 주행 구역의 `.rd5`를 받습니다. NewDoe용 국가 ZIP이나 API 키는 필요하지 않습니다. 서울 근거리는 `E125_N35.rd5` 구역에 들어갑니다. 구역 경계를 넘는 경로는 인접 파일도 필요합니다.
2. 파일명을 바꾸지 말고 **.rd5 파일 가져오기**에서 받은 파일을 선택합니다. 여러 개를 선택할 수 있습니다. 목록·용량을 확인한 뒤 가져오기를 누르고 **가져오기·검증 완료**를 기다립니다. 다운로드 폴더에 두기만 하면 NewDoe에 등록되지 않습니다. 가져온 앱 전용 사본만 안내에 사용합니다.
3. **표시용 지도**는 별도입니다. 기존 지도 화면에서 해당 지역의 Mapsforge `.map`을 받아 선택하세요. `.map`은 보이는 도로 지도이고 `.rd5`는 길찾기 데이터이므로 서로 대신할 수 없습니다. [BRouter 공식 오프라인 설명](https://brouter.de/brouter/offline.html)
4. 정차 상태에서 **내비 → 지도에서 목적지 선택**으로 지도를 열고 지도를 움직여 중앙 표시를 도로 근처의 목적지에 맞춘 뒤 **이 위치 선택**을 누릅니다. 확인 창에서 위치를 확인하고 **안내 시작**을 누릅니다. 즐겨찾기 또는 최근 목적지에서도 고를 수 있습니다. 이번 빌드에는 주소·상호 검색이 없습니다.
5. 실제 GPS가 확보되면 폰에서 경로를 계산합니다. 근거리 첫 시험은 출발지와 도착지가 같은 `.rd5` 구역이고 도로 위에 있는 곳으로 고르세요. 인터넷을 끊어도 가져온 데이터로 계산할 수 있지만, 위치 수신과 본체 Bluetooth 연결은 계속 필요합니다.
6. 본체 **MAP**에는 검정·흰 윤곽선의 보라색 경로가 표시됩니다. **HOME TBT**에는 왼쪽 화살표, 오른쪽 다음 회전까지 거리, Google Maps·OsmAnd의 도로명은 거리 아래에 표시합니다. 두 번째 회전 안내는 없습니다. 목적지 잔여거리는 목적지 아이콘과 HOME 하단 순환 항목에서 구분해 표시합니다. 안내 시작만으로 화면을 강제로 넘기지 않습니다.
7. 작은 TBT는 TRIP을 포함한 모든 주행 페이지에 표시됩니다. 안내 중 상단 메뉴는 5초 후 숨고 작은 TBT가 나타납니다. 설정·전화 등 우선 화면의 기존 가림 규칙은 유지합니다. 길을 벗어나면 폰이 재탐색하며, 위치·연결이 오래되면 최신 안내처럼 표시하지 않습니다.
8. 종료는 앱 **안내 종료**입니다. 앱 재실행 후에는 **안내 재개**에서 저장된 목적지를 확인하고 다시 시작합니다. 다른 차량에 저장된 목적지를 조용히 적용하지 않습니다. 경로 파일 갱신은 먼저 안내를 종료하고 새 `.rd5`를 가져오세요. 오류가 나면 실패한 파일은 기존 파일을 유지하며, 부분 성공 목록을 확인한 뒤 빠진 파일만 다시 고릅니다.

**Google Maps / OsmAnd 외부 TBT (실험적):** 내비에서 외부 TBT를 켜고 **알림 접근 권한**에서 NewDoe를 허용합니다. 해당 앱에서 실제 길 안내를 시작하고 안내 알림이 나오는지 확인하세요. 앱을 단순히 열거나 목적지만 검색한 상태는 안내 수신이 아닙니다. 지원 안내를 받으면 자체 BRouter 안내보다 우선하며, 외부 TBT 사용 중에는 자체 경로 안내를 시작할 수 없습니다. 외부 TBT는 그 앱이 제공한 도로명을 표시하지만 전체 경로선을 가져오는 기능은 아닙니다. 알림 형식·언어·앱 버전에 따라 인식되지 않을 수 있고, 해당 지역에서 원본 앱의 길 안내가 제공되지 않으면 NewDoe가 대신 만들지 않습니다.

| 문제 | 조치 |
|---|---|
| 경로 파일 없음 / 구역 누락 | 출발지·목적지와 중간 경로가 지나는 `.rd5`를 가져옵니다. |
| 지도만 보이고 길찾기 실패 | `.map`과 `.rd5`가 모두 준비됐는지 구분해서 확인합니다. |
| GPS 대기 | 휴대폰 위치 권한·위치 서비스를 확인합니다. 가짜 위치로 주행 안내를 검증하지 않습니다. |
| 경로 없음 | 목적지를 실제 도로 가까이 다시 지정하고 데이터 구역을 확인합니다. |
| 외부 TBT 대기 | Google Maps/OsmAnd의 실제 안내 알림과 NewDoe 알림 접근 권한을 확인합니다. |
| 본체 안내 대기 / 연결 끊김 | 기존 연결 절차로 다시 연결하고 폰 안내 상태를 확인합니다. 자동 재페어링·초기화는 하지 않습니다. |

기본 오토바이 프로필의 OSM 통행·일방통행·회전 제한을 사용합니다. 국가·배기량별 특수 규칙을 모두 검증한 차량 내비게이션은 아닙니다. 실제 도로 표지를 따르세요. 음성·과속카메라·차선 안내와 Valhalla 국가 팩은 이번 빌드에 없습니다.


### 시계와 키 OFF 속도 표시

아날로그·디지털 시계 모두 사진에 검은 음영을 적용합니다. 시계 바늘·숫자, 속도 호, ODO와 하단 정보 줄은 어두워지지 않습니다. 시계 종류는 표시 설정에서 선택합니다. 키 OFF로 정차 사용 중인 디지털 속도 칸은 `--- km/h`(마일 단위는 `--- mph`)이며 마지막 주행 속도를 현재값처럼 남기지 않습니다. 날씨 온도 옆의 시간대별 위·아래 삼각형은 표시하지 않습니다.
