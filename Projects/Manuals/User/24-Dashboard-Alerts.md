# 계기판 점멸 알림 · 0.9.62

[English](24-Dashboard-Alerts.en.md) · [사용 설명서](README.md)

기본값은 **ON**입니다. 본체 **SETTINGS → Display → Dash blink alerts**, 또는 휴대폰 앱의 **기기 설정 → 계기판 점멸 알림**에서 ON/OFF를 선택합니다. OFF는 진행 중인 점멸을 끝내고 기존 조도·밝기 보정 설정으로 돌아갑니다. 저장된 선택은 재부팅과 일반 업데이트 후에도 유지됩니다. 예전 저장 파일에 항목이 없으면 ON으로 시작합니다.

| 상황 | 계기판 밝기 동작 |
|---|---|
| 전화 수신·휴대폰 알림·일반 경고 팝업 | 최고 → 최저 → 최고 → 최저, 각0.5초, 총2초 |
| 연료 부족 팝업 | 최고/최저를8단계, 각0.5초, 총4초 |
| 실행 중 CFW 업데이트 | 최저/최고를1초마다 전환 |
| 해당 업데이트 오류 | 최저/최고를0.5초마다 전환 |
| 새 Bootstrap의 Install CFW? 승인 대기 | 최저/최고를0.5초마다 전환, 승인/취소하면 정상 복귀 |
| AUTO 등 짧은 토스트 | 점멸 없음 |

이 기능은 **UART로 연결된 차량 계기판의 밝기**를 바꿉니다. 누도 LCD 백라이트, 연료 아이콘 애니메이션, 배경 음영은 바꾸지 않습니다. 팝업을 닫아도 시작한2초/4초 알림은 끝까지 진행하며, 설정을 OFF로 바꾸면 취소됩니다. 같은 팝업을 다시 그리는 것만으로 반복하지 않습니다. 연료 경고 도중 일반 알림이 와도 연료 알림을 짧게 자르지 않습니다.

새 Product가 실행된 뒤부터 적용됩니다. **구버전에서0.9.62로 올리는 첫 업데이트는 구버전 동작**이며, 새 점멸을 소급 적용할 수 없습니다. 새 ZIP에는 최초 설치용 Bootstrap도 포함하지만, 일반 CFW 업데이트는 기존 Bootstrap/Gate를 교체하지 않습니다. 순정 최초 설치에는 저장된 CFW 설정이 없으므로 ON입니다.

ON/OFF·시간 경계·UART 프레임·저장값 복원은 소프트웨어 시험으로 검증했습니다. 실제 차량 계기판의 광학 밝기, 무선 설치와 점멸 주기는 아직 실기 검증하지 않았습니다.
