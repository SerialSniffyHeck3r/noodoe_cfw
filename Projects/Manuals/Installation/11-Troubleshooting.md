## 0.11.14: 언어 준비와 설치 상태 확인

**NewDoe-0.11.14.apk와 NewDoe-CFW-0.11.14.zip을 함께 사용하세요.** 같은 Gate의 0.11.4 이상에서는 기존 CFW 업데이트로 진행합니다. Gate와 B 언어팩 0.11.2는 바뀌지 않았습니다. 정상 언어팩은 다시 전송할 필요가 없습니다. ODO·UART 수정과 트립·정비 기록 보존도 유지합니다.

언어를 고르고 기존 재시작 안내를 확인하면, 부팅할 때 저장된 선택 언어의 문구·글꼴을 준비한 다음 홈 화면을 엽니다. 준비 중에는 SYSTEM STARTUP 안내가 표시됩니다. 앱 버튼을 누르거나 IGN을 오래 껐다 켤 필요가 없습니다. 차량 통신·트립 계산·정상 부팅 확정은 준비 중에도 계속됩니다. 자원이 없거나 손상됐거나 RAM 확보가 실패하면 기존 영어 표시로 돌아갑니다. 영어 전용 선택과 언어 선호도는 보존합니다.

펌웨어 확정 이후 언어 상태 조회 중 Bluetooth가 끊기면 동일 기기·Product·확정 상태를 다시 확인해 저장된 팩과 메뉴 준비 상태를 조회합니다. 이 과정에서 펌웨어나 팩을 자동 재전송하지 않습니다. 전송량이 끝나도 인덱스·폰트 검사와 메뉴 준비가 남을 수 있습니다. 마지막 준비 완료 안내까지 기다리세요. 계속 미확인이면 연결을 복구한 뒤 **언어 자원 설치 / 이어가기**를 누르세요. 펌웨어 재설치나 순정 복귀는 필요하지 않습니다.

새 Bootstrap은 설치 중 재사용 파일을 검사할 때도 설치 화면을 유지합니다. 전체 바는 파일별 전송·검증·NOR 기록·재검사 작업을 한 번씩 합산하며, 아래 바는 현재 작업을 나타냅니다. 검사 단계에서 아래 바가 다시 시작해도 전체 바는 뒤로 가지 않습니다. 순정 → Bootstrap의 수동 현재 상태 확인, 기본 No인 Bluetooth 초기화 질문, 마지막 설치 승인과 기록 안전 조건은 유지됩니다. Bootstrap 화면 변경만을 위해 순정 복귀하지 마세요.

휴대폰이 잠깐 바쁠 때 이미 받은 정상 응답을 시간 초과로 버리던 경로를 고쳤고, 주행 응답 대기를 3초에서 10초로 늘렸습니다. 실제 소켓 종료는 즉시 감지해 기존 재연결을 수행합니다. 카메라 실행 중 끊김은 차량이 센터에 있어 실기 재현을 완료하지 못했습니다. 해결이 확인됐다고 보장하지 않습니다.

소프트웨어 검증 빌드입니다. 모듈의 상시 전원을 유지하세요. 기존 구형 코드에서 순정 복귀 도중 전원이 끊길 경우 자동 복구를 보장하지 못하는 제한은 그대로입니다.

## 0.11.13: 개발자 메시지 정렬과 Bootstrap 수동 연결 확인

**NewDoe-0.11.13.apk와 NewDoe-CFW-0.11.13.zip**을 함께 사용하세요. Product도 **0.11.13**으로 업데이트해야 ODO·UART 수정이 적용됩니다. 같은 Gate를 쓰는 0.11.4 이상은 기존 CFW 업데이트 경로로 진행합니다. Gate와 B 언어팩은 그대로입니다. Bootstrap 표시 수정은 새 ZIP으로 순정에서 설치할 때 적용되므로, 그 화면만 바꾸려고 순정으로 돌아갈 필요는 없습니다.

0.11.13부터 ODO 자체 저장·보정과 이전 값 대체를 제거했습니다. 계기판 UART의 현재 유효값을 그대로 표시합니다. 수신이 끊기면 알 수 없음으로 표시하고 정상 수신 시 다시 표시합니다. 키 OFF 화면의 마지막 값은 이번 실행 중 RAM에만 남습니다. TRIP A/B·오늘/이번 주행·오일·벨트·정비 기록과 설정 보존은 유지합니다. ODO check 메뉴는 없어졌으며 예전 보정 기록은 읽거나 다시 쓰지 않습니다.

순정에서 Bootstrap 전송 검증이 끝나면 앱은 연결을 닫고 기다립니다. 상시 전원은 유지하고 순정 화면 안내에 따라 IGN을 끈 뒤, NewDoe Bootstrap 메뉴가 뜨면 IGN을 켜세요. 앱의 **현재 상태 확인**을 누르고 누도에서 **Install CFW**를 선택하세요. **Reset Bluetooth?**는 기본 **No**로 기존 페어링을 유지합니다. 앱은 같은 연결에서 이 선택을 기다렸다가 준비·검증·설치를 이어갑니다. 이제 세 번째 앱 버튼을 다시 누르지 않아도 됩니다. 이미 설치 화면에 있으면 실제 권한과 준비 상태를 확인한 뒤 곧바로 이어갑니다. 기존의 보관 데이터 복원 선택 경로는 유지하며, 이미 선택한 복원 정책도 보존합니다.

전송 검증 완료는 CFW 설치 완료가 아닙니다. 마지막 본체 설치 확인·카운트다운과 Product 정상 실행 확인은 그대로 거칩니다. 연결 실패나 미확정 설치 기록을 이유로 Bootstrap을 자동 재전송하거나 새 설치로 덮어쓰지 않습니다. 페어링이 안 되면 기존 선택형 Bluetooth 복구 안내를 따른 뒤 기기 상태를 다시 확인하세요.

개발자 메시지 원문과 페이지 조작은 그대로이며 EVE의 정렬 비트를 바로잡았습니다. 진행 표시에는 이전 기기 작업 값 대신 확인된 최신 전송량을 반영합니다. 내부 작업은 250ms 간격으로 조회하고 앱은 200ms 간격으로 표시합니다. 진행률 갱신만으로 변경 없는 설정 UI를 반복 구성하지 않습니다. 실제 Bluetooth 지연을 보장하는 수치는 아닙니다.

이번 검증은 소프트웨어 시험이며 실물 LCD·무선·설치는 시험하지 않았습니다. 모듈 전원을 유지하세요. 사용자가 앞서 수용한 구형 코드의 순정 복귀 도중 전원 중단 제한은 그대로 남아 있습니다.

## 설치가 멈춘 것처럼 보일 때

앱의 전체 단계·현재 작업 바이트·마지막 응답·파일/섹터/offset과 본체 화면을 함께 봅니다. 전송·해시 계산·NOR 소거·순정 설치기·후보 부팅은 별도 작업입니다. 퍼센트만으로 남은 시간이나 벽돌 여부를 판단할 수 없습니다.

| 표시 또는 증상 | 의미와 다음 행동 |
|---|---|
| 전송 전 호환성 확인에서 중단 | [지원 범위](07-Compatibility.md)의 HW 0·BL 0.10~0.19·순정 5.16 및 APK/ZIP 조합 확인. 모델명·PCBA는 제한하지 않음. 이 검사에서 멈췄다면 아직 Bootstrap을 보내지 않음 |
| `The current operation cannot continue` / `Installation success or cancellation not confirmed` | 이전 변경 작업의 결과가 미확인. 같은 기기·ZIP으로 마지막 작업을 먼저 조회 |
| Stage 6/8 · Code 6 / Phase 4 · `Paused` / `See Phone Help` | 코드만으로 성공·벽돌을 단정할 수 없음. 화면과 로그를 보관하고 [설치 정지 복구](10-Recovery.md) 확인. 0.9.66 오류 화면에는 UP+O 3초 안내가 표시됨 |

0.9.59에서 사용자가 순정→CFW 설치와 연료 경고 음영 정상 동작을 확인했습니다. 이는 모든 CFW→CFW 이관이나 Code 6 / Phase 4의 원인이 같다는 증거가 아닙니다. 이전 버전에서 시작한 업데이트는 첫 재시작까지 구버전 동작을 따릅니다.

## 기록을 유지하며 복구

앱의 연결 상태 초기화는 소켓·임시 선택을 정리합니다. 본체 ABORT/RESET을 자동으로 보내거나 미확인 작업을 취소 완료로 표시하지 않습니다. 앱 데이터 삭제·NOR 포맷·다른 ZIP·다른 기기 식별로 기록을 우회하지 않습니다. [복구 경로](10-Recovery.md)를 실제 화면에 맞춰 사용합니다.

`진단 자료 공유`로 ZIP을 내보내고 다음을 함께 적으세요: **차량 모델, 모듈 HW/PCBA/부트로더/순정 버전(확인 가능할 때), 이전·새 APK/CFW 버전, 기기 문구·Stage·Code/phase, IGN 상태와 누른 버튼, 마지막 파일/섹터/offset**. 민감한 기기 식별값은 공개 글에 그대로 올리지 마세요.

일반 이벤트 로그에는 알림 본문·곡명·정밀 좌표·페어링 비밀키를 기록하지 않지만 복구 증거에는 기기 정보가 포함될 수 있습니다. 폰 내부 원본은 보존됩니다. 필수 저널을 저장할 공간도 필요합니다. 일반 APK는 앱에서 내보내기 기능을 사용하고, 개발용 APK의 `run-as` 절차와 구분하세요.
