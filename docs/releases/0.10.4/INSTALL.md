# 0.10.4 beta — full settings access without vehicle speed

Install **both NoodoeCompanion-0.10.4.apk and NoodoeInstaller-CFW-0.10.4.zip**. Updating only the APK does not change the device setting gate. Keep app data.

With confirmed IGN ON and missing vehicle speed, the full settings menu now remains accessible, locally and from the phone. Open quick settings with O+DOWN, release both, then hold O. You can reach Connections → Re-pair phone without first using the ten-minute key-OFF mode. Pairing deletion still needs local confirmation; no keys are automatically deleted. Valid moving speed still locks settings, and valid stationary speed still requires the existing dwell. Unknown IGN does not grant access. Speed/ODO validity, odometer application and firmware/language installation admission are unchanged.

This fixes inaccessible settings and recovery controls. It does not establish why the reported phone initially disconnected or prove that the affected Xciting now receives vehicle telemetry. The 0.10.2 vehicle-link correction is retained. No speculative Bluetooth reset/retry changes were added.

0.10.x with matching Gate: ordinary CFW-to-CFW update. 0.9.x / old Gate: keep-data stock return and reinstall. Gate, Bootstrap, stock, diagnostic, uninstall, fixed resources and the B language archive are unchanged. An already installed matching language pack is reused. The 0.10.3 explicit post-confirmation language offer, automatic download and optional pairing guide remain.

## Without a phone: return to stock

1. While parked, turn the key OFF.
2. Hold only O (centre), turn the key ON without starting the engine, and keep O held for at least two seconds after ON.
3. Release O when RECOVERY MODE appears. Use UP/DOWN to select **Back to stock** and press O.
4. At the confirmation screen, release O, then hold O again for two seconds.
5. Wait until the original dashboard has fully started. Keep the battery/module connected; do not crank the engine or interrupt restoration.

This works without Bluetooth and retains CFW data for a compatible reinstall. The old-code stock-return power-interruption limitation remains; automatic recovery is not guaranteed in that legacy interval. If recovery does not appear, release the buttons and retain a photograph of the screen.

## 한국어

**APK와 본체 ZIP을 모두 0.10.4로 업데이트하세요.** 본체가 0.10 계열이고 Gate가 일치하면 CFW→CFW로 업데이트할 수 있습니다. 0.9 계열은 데이터 유지 순정 복귀 후 재설치합니다.

시동 ON이 확인됐지만 차량 속도를 받지 못해도 전체 설정을 열 수 있습니다. O+DOWN → 두 버튼 놓기 → O 길게로 들어가세요. 휴대폰 설정도 같은 정책입니다. 속도가 정상 수신되면 기존 정차 대기·주행 잠금이 적용됩니다. 속도/ODO 값을 정상으로 꾸미거나 ODO 적용·설치 검사 조건을 풀지는 않았습니다. 재페어링은 여전히 본체에서 별도로 승인해야 합니다.

폰 없이 순정 복귀: 키 OFF → O 유지 → 키 ON 후 최소 2초 유지 → 복구 화면에서 놓기 → Back to stock 선택/O → 확인 화면에서 O를 놓았다가 다시 2초. 순정 화면이 완전히 켜질 때까지 전원을 유지하고 시동 모터를 돌리지 마세요.

이미 설치된 언어팩은 그대로 재사용합니다. 이번 수정은 설정 접근 문제의 해결이며, 해당 차량의 통신·최초 Bluetooth 단절 원인이 실기에서 해결됐다는 의미는 아닙니다.
