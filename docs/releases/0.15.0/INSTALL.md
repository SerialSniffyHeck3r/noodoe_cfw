# NewDoe 0.15.0

## 한국어

기존 앱 위에 **NewDoe-0.15.0.apk**를 설치하세요. 펌웨어·글꼴은 앱에 포함돼 있습니다. APK만 설치해도 본체가 자동 업데이트되는 것은 아닙니다.

1. 차량을 세우고 Bluetooth를 켭니다. 앱에서 기존 기기를 선택합니다.
2. **현재 기기 상태 확인**을 누릅니다. 이 버튼은 상태만 읽으며 설정 복원·설치·재시작을 실행하지 않습니다.
3. **언어 설정**에서 설치할 메뉴 언어와 글꼴 상태를 확인합니다. **업데이트** 또는 **설치**를 선택하고 각 안전 안내를 읽습니다.
4. 정상 기기는 기존 Product 업데이트를 진행합니다. 폰트 준비용이 필요한 경우 실행 이유와 최종 Product 설치 순서를 확인한 뒤 진행합니다.
5. **CFW UPDATE** 확인과 앱의 마지막 결과까지 확인합니다. 펌웨어 부팅 확정과 설정 복원 완료는 따로 확인됩니다.

**0.14.1에서 설정 저장·복원이 막히는 경우:** 새 앱으로 상태와 진단을 저장한 뒤 **데이터 보존 순정 복귀 → 재설치**를 사용하세요. Bluetooth가 실제로 연결되지 않으면 본체에서 **키 OFF → O를 누른 채 키 ON → 2초 이상 유지 → 복구 메뉴에서 손을 뗌**으로 Gate를 열고 **Back to stock**을 선택합니다. **CFW 데이터 유지**를 선택하며 완전 삭제는 고르지 마세요. 순정 화면이 나온 뒤 앱의 **본체에서 순정으로 돌아왔어요 · 확인**을 누르고 재설치 시 **보관 데이터 복원**을 선택하세요. 필수 데이터 파일이 없다는 오류가 나면 초기화하지 말고 진단을 저장하세요.

**CJ 공간 부족:** 확인 화면에서 멈춥니다. 메뉴가 CJ 없이 동작할 때만 **CJ 없이 계속 설치 / 취소**를 선택할 수 있습니다. 필수 메뉴 글꼴이 없으면 **다른 언어 선택 / 취소**가 필요합니다. 미지원 음악·알림 문자는 휴대폰 렌더링이 필요하며, 사용할 수 없을 때 표시가 제한될 수 있습니다. 취소해도 완료된 작업은 되돌아가지 않습니다. 준비용 Product가 남아 있으면 앱 데이터와 설치 기록을 유지해 나중에 재개하세요.

배터리 단자·누도 배선을 분리하지 말고 스타터를 누르지 마세요. 배터리 11.5V 이상을 확인하세요. 키 OFF가 가능한 단계는 OFF를 권장하지만, 순정에서 설치 도구를 처음 보낼 때는 키 ON이 필요합니다. 키 OFF 상태에서 UP+O를 함께 누르지 마세요. **기존 순정 복귀 코드가 실행되는 동안 전원이 끊기는 제한은 해결된 것이 아닙니다. 이 구간의 전원 차단은 별도 장비를 통한 복구가 필요할 수 있습니다.**

## English

Install **NewDoe-0.15.0.apk** over the existing app. Firmware and fonts are included. Installing the APK alone does not update Noodoe.

1. Park, enable Bluetooth and select your existing device.
2. Tap **Check current device**. This is read-only: it does not restore settings, install or restart.
3. Open **Language settings**, check the selected menu language and fonts, then choose **Update / Install** and read each safety screen.
4. Healthy devices use the normal Product update. If a font preparation Product is needed, read its purpose and the return to the final Product before accepting.
5. Complete **CFW UPDATE** confirmation and read the final app result. Product boot confirmation and settings restoration are reported separately.

**Settings blocked on 0.14.1:** Save status/diagnostics and choose **data-preserving stock return → reinstall**. If Bluetooth cannot connect, open Gate using **key OFF → hold O while turning key ON → hold at least two more seconds → release at recovery** and choose **Back to stock**. Keep CFW data; do not choose complete removal. After the stock screen appears, tap **I have returned to stock · check** in the app and choose **Restore retained data** during reinstallation. Do not initialize a missing required data file; save diagnostics instead.

**Insufficient CJ space:** Installation waits for your choice. **Continue without CJ / Cancel** is available only when the selected menu can work without CJ. Missing mandatory fonts require **Choose another language / Cancel**. Unsupported music/notification text needs phone rendering and may not display without it. Cancelling does not undo completed steps. If the preparation Product remains installed, keep app data and the operation record to resume.

Keep battery terminals and wiring connected. Do not press the starter. Check at least 11.5V. Key OFF is recommended where the current step allows it; the first transfer from stock needs key ON. Do not press UP+O together with the key OFF. **The existing stock-return power-interruption limitation remains: losing power while that older code runs can require external recovery equipment.**

Expert ZIP installation remains available with warnings and compatibility checks. Normal users should use the included packages. Keep app data and the original installation record after an interrupted operation. Unknown outcomes are not proof of either success or failure.
