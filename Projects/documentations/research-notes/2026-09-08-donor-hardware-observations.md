# 2017 AK550 계기판·Noodoe 세트: 실물 관찰 현황

> **후속 관찰:** 2026-09-09에는 USB Mass Storage 연결과 볼륨 읽기가 확인됐다. [새 실물·USB 관찰 기록](2026-09-09-donor-hardware-usb-observations.md)을 함께 읽는다. 아래의 USB 미식별 내용은 전날의 관찰이다.

기록일: 2026-09-08 KST

출처: 소유자의 대화상 설명. 새 보드의 사진, 배선도, 측정 원시값을 직접 검증한 결과가 아니다.
기존 SR1.5 V5.16 분석을 새 보드에 자동 적용하지 않는다.

## 구입 대상과 장치 구분

- 연구용 구입품은 **2017년식 AK550 차량 계기판과 Noodoe 모듈의 세트**다.
- 소유자의 실차는 **2018년식 AK550**이다.
- 차량 계기판과 Noodoe는 별도 장치다. 두 장치의 커넥터, 전원, 신호를 혼동하지 않는다.

```text
차량 ↔ 차량 계기판 ↔ Noodoe 모듈
     핀아웃 확보     핀아웃 전혀 미확인
```

## 소유자가 보고한 상태

- **차량 ↔ 계기판 핀아웃은 완전하게 확보**했다. 본 대화에서 그 원문을 검토하지는 않았다.
- **계기판 ↔ Noodoe 핀아웃은 전혀 파악하지 못했다.**
- 소유자는 두 장치가 UART로 통신한다고 강하게 확신한다. 개별 TX/RX 위치와 측정 조건은 본 대화에서 확인하지 않았다.
- 배선도와 사용자용 설명서로 일부 기능을 추산할 수 있다. 추산과 실측 확정은 구분한다.
- Noodoe의 핀과 테스트 패드는 예상보다 많다. SWD라고 식별한 접점은 아직 없다.
- 더미 핀 또는 공장용 핀이라는 해석은 현재 추정이다.
- 다수 테스트 패드에 컨포멀 코팅이 있다고 보고했다. 접촉 불량과 실제 비활성 신호는 아직 구분하지 못했다.
- 일반 아두이노 점퍼선이 맞지 않는 넓은 핀이 있고 맞는 커넥터를 받지 못했다고 보고했다. 커넥터 규격과 해당 연결 구간은 미확인이다.
- 큰 IC 패키지는 핀이 160개 이상으로 보인다고 보고했다. 정확한 핀 수, 칩 마킹, MCU 여부와 패키지는 미확인이다.
- Noodoe 내부 USB-B를 이 PC에 연결했으나 화면·백라이트 등 동작 징후가 없다. USB 단독 전원 공급 범위, 정상 기동 조건, 데이터 기능은 미확인이다.

## PC에서 수행한 읽기 전용 확인

2026-09-08 대화 중 Windows Get-PnpDevice -PresentOnly로 현재 USB 및 Ports 장치를 조회했다.
Noodoe라고 식별할 이름이나 USB 직렬·DFU 장치는 보이지 않았다. 표시된 COM3는 Intel AMT SOL이었다.

연결 전후 비교를 수행하지 않았으므로 이 조회만으로 Noodoe가 USB에 전혀 열거되지 않았다고 단정하지 않는다.
USB 단독 연결에서 외부 동작 징후가 없다는 보고도 내부 모든 전원 레일이 무전압이라는 측정 결과는 아니다.

## 후속 작업에서 유지할 판단 경계

1. SWD 접점을 아직 식별하지 못한 상태다. SWD 부재·비활성·읽기 보호 여부는 미확인이다.
2. 핀이 많다는 사실만으로 각각을 더미, 공장용 또는 SWD로 분류하지 않는다.
3. 확보한 차량 ↔ 계기판 핀아웃을 계기판 ↔ Noodoe 핀아웃으로 인용하지 않는다.
4. 계기판의 입력 전압을 Noodoe 모듈의 입력 전압으로 자동 적용하지 않는다.
5. 기존 펌웨어에서 추정한 MCU·주변장치 설정은 새 보드와 대조할 기준이다. 새 보드의 물리 핀을 이미 확인했다는 증거가 아니다.
6. 출발점은 확보한 차량 측 핀아웃과 순정 세트 구조다. 정상 전원·기동 조건을 확인한 뒤 USB와 내부 신호를 관찰한다. SWD 위치 확인은 별도의 배선 추적 과제다.
