# NewDoe 0.11.10 beta — dashboard, stock view and UI preview

- OpenNoodoe-style numeric font and dim leading zeros; map/speed/ODO, trip and maintenance cards.
- Large oil gauge, separate belt/service pill bars, average/maximum icons.
- Stock KYMCO read-only speed/ODO/vehicle information instead of CFW-only counters.
- Manual distance since oil/belt/service on the device and phone; existing durable ride storage, total ODO unchanged.
- Personalize → UI test screen: disconnected-only, editable sample values/modes, no Bluetooth writes or riding records.
- Supplied NEWDOE white/red wordmark in the header and splash branding.

Install the matching APK and firmware ZIP. From 0.11.4–0.11.9 use normal CFW update; Gate, Bootstrap and language resources are unchanged. Do not resend a working language pack. Existing old-Gate stock-return/reinstall routing is unchanged. The previously accepted power-loss limitation in already-installed old stock-return code is not fixed by this release.
