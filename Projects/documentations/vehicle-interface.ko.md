# 차량 인터페이스: 버튼·시동·계기판 정보

AK 550 본체 계기판에는 이미 숫자 속도계가 있다. 누도 CFW의 바깥 **속도 링**과 중앙 정보는 그 옆에서 동작한다. 속도·ODO·연료 상태는 계기판 쪽 UART에서 받고, 음악·알림·통화·GPS 궤적은 휴대전화에서 받는다. 속도는 무조건 휴대폰 속도를 우선해서 쓰며, GPS 속도는 본 시스템에서 사용하지 않도록 한다. [English](vehicle-interface.md)

## 조사한 AK550 용 SR1.5 / V5.16 차량 UART

순정 코드와 양방향 관찰에서 차량 순정 대시보드와 Noodoe 시스템이 데이터를 전송할 떄 쓰는 UART5는 **115200 baud, 8N1**이며 프레임은 다음 구조다.

| 순서 | 필드 |
|---|---|
| 1 | 시작 바이트 F5 |
| 2 | 명령 바이트 1개 |
| 3 | 길이 바이트 1개 |
| 4 | 길이만큼의 페이로드 |
| 5 | F5부터 마지막 페이로드 바이트까지의 XOR 검사값 |


| 방향·명령 | 확인된 해석 | CFW에서의 취급 |
|---|---|---|
| 계기판→누도 21, 9바이트 / 22, 11바이트 | 페이로드 0은 현재 속도, 4–7은 little-endian ODO, 8은 온도 계열 후보이지만 확실하지 않음. 22에는 의미가 닫히지 않은 16비트 값이 추가된다. | 프레임 검사와 최신성 확인 후 화면·트립 모델에 적용한다. |
| 위 프레임의 3번 바이트 | 실측 0칸·1칸 연료 사례에서 하위 니블이 0→1로 바뀌고 상위 니블은 5였다. 순정 계기판에는 5칸의 연료 칸이 있고 0칸부터 5칸까지의 의미를 가진다. 순정 계기판은 연료량을 저항으로 추산하며 Short / Open 시 00이 수신된다. | 연료 칸으로 해석하여 1칸 남았을 시 퓨얼 로우, 0칸 남았을 시 퓨얼 크리티컬 모드로 간다. |
| 위 프레임의 2번 바이트 | 그 의미를 알 수 없었다. | 미사용. |
| 계기판→누도 41 / 42 | 각각 250바이트·71바이트의 큰 상태 기록을 순정 코드가 보관·중계한다. | 미사용.  |
| 누도→계기판 A1 | 01과 0–9 밝기 단계로 구성된다. 로컬 조도 기준으로 만든 값이다. | 계기판으로 나가는 밝기 단계와 누도 LCD의 PWM을 별도로 관리한다. |
| 누도→계기판 01 | 재요청·초기화·종료 계통에서 관찰된 제어값이며 잘 모르겠는 값. | 미사용. |

계기판 ODO와 CFW가 속도를 적분해 계산한 트립은 샘플 간격·반올림 때문에 소수 첫째 자리에서 다를 수 있다. 누도는 차량 ODO를 새로 만들어 계기판에 쓰지 않으며, 그럴 경로조차 없다.

실제 대한민국에서 보고된 AK550의 사례로써 계기판 ODO가 초기화되는 경우가 발생했기에 이 문제 상황에 대응하고자 추가한 기능이라면, UART ODO가 갑자기 ----나 비현실적인 값으로 변하면 마지막으로 믿을 만한 값을 보존하고 이상 상태를 사용자에게 알리는 기능을 추가했다. 트립·정비 카운터는 CFW 고유 기록이다.

## 세 버튼, PH9 선택 스위치, IGN

| 기능 | MCU 핀 | 조사한 전기·동작 의미 |
|---|---|---|
| 위 | PD12 | 누르면 LOW. 에지 이후 시간 기반 디바운스와 버튼 이벤트 생성. |
| 아래 | PI6 | 누르면 LOW. 같은 이벤트 처리 계층을 통과한다. |
| 가운데 / O | PA15 | 누르면 LOW. 짧게·길게 누르기의 의미는 현재 페이지가 정한다. |
| 계기판/누도 조작 선택 | PH9 | 일반 누도 버튼과는 다른 입력. 조사한 순정 조건에서 IGN ON·PH9 HIGH이면 누도 조작 허용, LOW이면 차단. |
| 시동 신호 | PG13 | 조사한 보드에서 LOW=IGN ON, HIGH=IGN OFF. 모듈 상시 전원 상실과 동일하지 않다. |

BSP는 눌림·뗌·지속 시간을 이벤트로 만들고 미들웨어는 접점 떨림과 PH9/IGN 정책을 적용한다. 버튼을 누르는 중 PH9가 차단 위치로 바뀌면 그 누름은 취소한다. 다시 허용 위치로 돌려도 손을 **뗐다가 새로 눌러야** 조작된다. 일반 UI 차단은 긴급 키+O Gate 진입이나 설치·복구 확인을 막아서는 안 된다. 키 OFF에서는 차단 안내를 띄우기 위해 백라이트를 깨우지 않는다.

## 조도와 전원 정책

OPT3001 조도값은 순정의 공장 보정 임계값 열 개를 거쳐 0–9 단계로 분류되고, 그 단계가 A1 프레임으로 본체 계기판에 전송된다. 누도 자체의 백라이트 PWM, 계기판에 송신하는 밝기 단계, 라이트·다크 화면 색은 각기 다른 제어다. 수신 측 계기판은 자신이 받은 그 프레임에서 이 단계가 특정 숫자 이하이면 낮은 조도 상태로 들어가고, 그 이상이면 높은 조도 상태로 들어간다. 그니까 낮 모드랑 야간 모드 두 가지가 있다는 말을 저렇게 장황하게 한번 해 봤다. 귀차니즘으로 인해 그게 정확히 무슨 시점인지는 시험하지 않았다.

IGN OFF는 마지막 주행 화면을 잠시 유지한 뒤 세션 종료를 확정하고 Ride Summary를 거쳐 설정된 절전 단계로 간다. 빠른 OFF→ON에서는 아직 확정되지 않은 주행 세션을 초기화하지 않게 했다. 내 ADHD로 인한 정서불안은 키를 연속적으로 빠르게 돌리는 데서 만족감을 느끼기 때문에. 화면 유지 상태, 백라이트 OFF, 패널 OFF/Bluetooth 유지, 완전 OFF에서는 MCU 클록·수면 정책과 무선 유지 조건이 각각 다르다는 점을 알아두자.
