# 호환 모델과 설치 조건

**APK / Product 0.9.63 · Manual revision 1 · 2026-10-08**

[설치 목차](README.md) · [English](07-Compatibility.en.md)

## 어떤 누도를 지원하나요?

이 CFW의 대상은 **STM32F4 계열 Noodoe 모듈**입니다. 차량 이름만으로 호환 여부를 결정하지 않습니다. AK550에만 설치하도록 제한하지 않으며, 다른 차량에 연결한 동일 계열 모듈도 아래 조건에 맞으면 설치 대상으로 허용합니다.

| 차량·모듈 | 현재 지원 범위와 확인 수준 |
|---|---|
| 개발자가 사용하는 AK550의 F4 Noodoe | 개발·사용 대상입니다. 사용자가 0.9.62의 안정적 실기 동작을 보고했습니다. Stage 6/4의 수동 RESET 요구는 남아 있습니다. 0.9.63의 실기 검증 결과는 아닙니다 |
| 개발자의 벤치 F4 Noodoe | 개발·시험에 사용한 별도 모듈입니다. 모든 PCB 리비전을 대표하지 않습니다 |
| 다른 KYMCO 모델 또는 다른 차량에 연결한 F4 Noodoe | 아래 설치 조건을 충족하면 모델명으로 차단하지 않습니다. 차종별 배선·계기판 데이터·버튼 전환 신호의 실제 동작은 별도 확인이 필요합니다 |
| 순정 버전이 5.14·5.16 이외인 모듈 | 이번 릴리스의 설치 지원 범위 밖입니다 |

현재 확인 자료만으로 다른 차종 이름을 나열한 ‘실차 검증 완료 목록’을 만들 수는 없습니다. **설치 허용과 실차 기능 확인은 다릅니다.** 다른 차량에서 속도·IGN 정보가 전달되지 않으면 설치의 정차 확인이나 차량 데이터 기능이 제한될 수 있습니다.

## 순정에서 처음 설치할 때

| 항목 | 0.9.63 APK + ZIP 조건 |
|---|---|
| 기기 응답의 HW 값 | **화이트리스트 없음** |
| 순정 부트로더 버전 | **버전 제한 없음**. 실제 원본 식별값을 읽어 보관 |
| 순정 앱 펌웨어 | **5.14 또는 5.16** |
| 모델명 | **SAA1AA, SAA1AA(KR) 등 문자열로 제한하지 않음** |
| PCBA | **SR0701 등 특정 문자열로 제한하지 않음** |
| 휴대전화 | Android **6.0 / API 23 이상**. Android용 APK이며 iPhone 앱은 제공하지 않음 |
| 설치 파일 | 같은 릴리스의 APK와 설치 ZIP. 예전 ZIP은 예전의 더 좁은 검사를 유지할 수 있음 |

설치 허용은 순정 펌웨어 버전으로 판단하며 HW·부트로더 버전·모델·PCBA로 차단하지 않습니다. 이것이 모든 MCU나 PCB에서 동작을 검증했다는 뜻은 아닙니다. 화이트리스트를 없앴어도 실제 기기 식별, 부트로더 캡처, 이미지 무결성, 지원 표시부 설정과 저장소 검사는 계속 수행합니다.

앱에서 기기를 식별해 HW·부트로더·순정 버전을 확인하세요. 호환성 검사에서 중단되면 표시된 수치와 진단 자료를 보관합니다. 다른 기기의 식별값이나 덤프를 대입하지 마세요. 현재 설치를 이미 시작한 경우에는 ‘호환되지 않음’과 ‘이전 작업 결과 미확인’을 구분해야 합니다.

## 이미 CFW가 설치돼 있다면

위의 **순정 5.14·5.16 조건을 실행 중인 CFW 버전에 적용하지 않습니다.** [일반 CFW 업데이트](09-Update.md)를 사용합니다. 앱이 기존 Gate와 새 패키지를 대조하고, 필요할 때만 데이터 유지 순정 복귀를 통한 복구층 이관을 안내합니다.

## ST-Link와 백업

정상적인 무선 설치 절차에는 ST-Link가 필요하지 않습니다. Bootstrap은 기기별 하위 플래시/부트로더를 두 번 읽어 대조하고 원본 메타데이터와 백업을 보관하며, **패키지에 포함된 순정 5.16 복구 APP을 외부 NOR에 준비·검증**합니다. 이를 ‘내 모듈의 모든 플래시를 통째로 백업했다’고 해석하면 안 됩니다.

별도 [전체 NOR 백업](../User/13-NOR-Backup.md)은 외부 128MiB 저장소 대상이며 MCU 내부 플래시 전체 덤프가 아닙니다. 이미 보유한 원본 덤프와 앱의 백업·진단 자료는 보관하세요. 복구용 이미지가 손상됐거나 MCU가 복구 코드를 실행하지 못하는 경우까지 무선 복구가 보장되는 것은 아닙니다.

**5.14에서 설치해도 순정 복구에는 동봉된 5.16 APP이 사용됩니다. 원래의 5.14 APP을 캡처해 복원하는 방식은 아닙니다.** 정상 응답과 기존 정차·IGN 확인은 계속 필요합니다.
