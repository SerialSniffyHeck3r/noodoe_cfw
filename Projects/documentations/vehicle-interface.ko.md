# 차량 인터페이스: 버튼·시동·계기판 정보

AK 550 본체 계기판에는 이미 숫자 속도계가 있다. 누도 CFW의 바깥 **속도 링**과 중앙 정보는 그 옆에서 동작한다. 속도·ODO·연료 상태는 계기판 쪽 UART에서 받고, 음악·알림·통화·GPS 궤적은 휴대전화에서 받는다. 휴대전화 GPS 속도를 계기판 UART 속도 대신 쓰지 않는다. [English](vehicle-interface.md)

## 조사한 SR1.5 / V5.16 차량 UART

순정 코드와 양방향 관찰에서 UART5는 **115200 baud, 8N1**이며 프레임은 다음 구조다.

| 순서 | 필드 |
|---|---|
| 1 | 시작 바이트 F5 |
| 2 | 명령 바이트 1개 |
| 3 | 길이 바이트 1개 |
| 4 | 길이만큼의 페이로드 |
| 5 | F5부터 마지막 페이로드 바이트까지의 XOR 검사값 |

아래 “계기판→누도”는 논리 방향이며 커넥터 접점 번호를 뜻하지 않는다. 실제 양방향 캡처와 순정 코드의 송·수신 처리를 함께 대조했다.

| 방향·명령 | 확인된 해석 | CFW에서의 취급 |
|---|---|---|
| 계기판→누도 21, 9바이트 / 22, 11바이트 | 페이로드 0은 현재 속도, 4–7은 little-endian ODO, 8은 40을 뺀 온도 계열 후보. 22에는 의미가 닫히지 않은 16비트 값이 추가된다. | 프레임 검사와 최신성 확인 후 화면·트립 모델에 적용한다. 모르는 바이트의 의미를 만들어내지 않는다. |
| 위 프레임의 3번 바이트 | 실측 0칸·1칸 연료 사례에서 하위 니블이 0→1로 바뀌고 상위 니블은 5였다. | 연료 경고·Reserve 조건에는 디바운스를 둔다. 모든 2–5칸 관계를 이 두 사례만으로 확정하지 않는다. |
| 위 프레임의 2번 바이트 | 순정의 일반적인 6단계 표시 입력으로 들어간다. | 이를 바로 정확한 연료 퍼센트라고 표시하지 않는다. |
| 계기판→누도 41 / 42 | 각각 250바이트·71바이트의 큰 상태 기록을 순정 코드가 보관·중계한다. | 각 필드가 닫히지 않았으므로 RPM·TPMS·전압을 전부 제공한다고 주장하지 않는다. |
| 누도→계기판 A1 | 페이로드는 01과 0–9 밝기 단계로 구성된다. 로컬 조도 기준으로 만든 값이다. | 계기판으로 나가는 밝기 단계와 누도 LCD의 PWM을 별도로 관리한다. |
| 누도→계기판 01 | 재요청·초기화·종료 계통에서 관찰된 제어값. | 버튼의 비트마스크로 해석하지 않는다. |

계기판 ODO와 CFW가 속도를 적분해 계산한 트립은 샘플 간격·반올림 때문에 소수 첫째 자리에서 다를 수 있다. 누도는 **차량 ODO를 새로 만들어 계기판에 쓰지 않는다.** UART ODO가 갑자기 ----나 비현실적인 값으로 변하면 마지막으로 믿을 만한 값을 보존하고 이상 상태를 사용자에게 알릴 수 있지만, 실제 차량의 누적거리를 몰래 고치지 않는다. 트립·정비 카운터는 CFW 고유 기록이다.

## 세 버튼, PH9 선택 스위치, IGN

| 기능 | MCU 핀 | 조사한 전기·동작 의미 |
|---|---|---|
| 위 | PD12 | 누르면 LOW. 에지 이후 시간 기반 디바운스와 버튼 이벤트 생성. |
| 아래 | PI6 | 누르면 LOW. 같은 이벤트 처리 계층을 통과한다. |
| 가운데 / O | PA15 | 누르면 LOW. 짧게·길게 누르기의 의미는 현재 페이지가 정한다. |
| 계기판/누도 조작 선택 | PH9 | 일반 누도 버튼과는 다른 입력. 조사한 순정 조건에서 IGN ON·PH9 HIGH이면 누도 조작 허용, LOW이면 차단. |
| 시동 신호 | PG13 | 조사한 보드에서 LOW=IGN ON, HIGH=IGN OFF. 모듈 상시 전원 상실과 동일하지 않다. |

BSP는 눌림·뗌·지속 시간을 이벤트로 만들고 미들웨어는 접점 떨림과 PH9/IGN 정책을 적용한다. 버튼을 누르는 중 PH9가 차단 위치로 바뀌면 그 누름은 취소한다. 다시 허용 위치로 돌려도 손을 **뗐다가 새로 눌러야** 조작된다. 일반 UI 차단은 긴급 키+O Gate 진입이나 설치·복구 확인을 막아서는 안 된다. 키 OFF에서는 차단 안내를 띄우기 위해 백라이트를 깨우지 않는다.

## 조도와 전원 정책

OPT3001 조도값은 순정의 공장 보정 임계값 열 개를 거쳐 0–9 단계로 분류되고, 그 단계가 A1 프레임으로 본체 계기판에 전송된다. 공장 영역의 열 값은 **조도 기준점**이지 TIM5 PWM 퍼센트 열 개가 아니다. 누도 자체의 백라이트 PWM, 계기판에 송신하는 밝기 단계, 라이트·다크 화면 색은 각기 다른 제어다. A1 송신을 확인했다는 것만으로 수신 측 계기판이 정확히 어떻게 밝기를 바꾸는지는 확정할 수 없다.

IGN OFF는 마지막 주행 화면을 잠시 유지한 뒤 세션 종료를 확정하고 Ride Summary를 거쳐 설정된 절전 단계로 간다. 빠른 OFF→ON에서는 아직 확정되지 않은 주행 세션을 초기화하지 않아야 한다. 화면 유지 상태, 백라이트 OFF, 패널 OFF/Bluetooth 유지, 완전 OFF에서는 MCU 클록·수면 정책과 무선 유지 조건이 각각 다르다.
